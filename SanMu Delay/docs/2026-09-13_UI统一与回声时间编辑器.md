# Delay 系列 UI 统一与回声时间编辑器

用户要求在昨日网页 UI 改动上继续完善，与 Comp／Reverb 统一，移除无实际交互的空间回声时序脉冲场。此次保留接手时的未提交工作；本轮开始快照位于 `/tmp/sanmu-delay-before-20260913`，临时目录不作为永久备份。

## 当前界面

- 公共 `reverb.css`、`draw-knob.js`、`icons.js` 与 Comp 文件内容相同。统一连续玻璃面板、引擎色、顶栏、设置入口、功能提示和折叠帮助手册。
- 移除正在使用的网页脉冲场、移动光点与发光柱。新增 `ui/echo-editor.js`：拖动 L／R 时间节点修改真实参数，同步模式按实际音符时值吸附，自由模式为 1～2000 ms。
- 两条轨道共用标尺，右侧给出基础时间毫秒值。LINK 和 Ping-Pong 下右路只读；Cross 可解锁双路。节点表示延迟线间隔，不是音频采样波形或首个可听回声的位置。
- 反馈衰减图可上下拖动，也可用方向键调节。横轴为重复次数，示意采用当前反馈的内部安全比例（百分比 × 0.985）。它不包含滤波、引擎染色和路由后的精确音频响应。
- Freeze 显示循环保持状态并隐藏普通衰减图。视觉显示开关只隐藏衰减示意；时间编辑、音频和电平表继续运行。
- 底部湿声／避让读数使用插件遥测，右侧为最终输出 L／R。浏览器预览默认静音，不伪造实时音频。

## 交互修复

- 原界面没有接受宿主帧中的声音状态，现只在状态变化时刷新，保留正在拖动或编辑的内容。
- 参数写入按手势顺序发送；同一手势结束后接受原生量化值。跨控件即时回显，宿主自动化和预设也能更新专属引擎控件。
- 修复音符索引 0 被当成默认 1/4、宿主 BPM 仍能拖动／输入、切换引擎后旋钮颜色滞后、LINK 固定高亮。
- 时间卡支持键盘与严格单位输入，0.25 s 正确换算为 250 ms；非法文本不写入参数。
- 初始 A 槽显示下复制到 B 现在确实复制当前声音。此修改只涉及状态复制，不涉及音频处理。
- 预览出厂预设现在加载完整参数，不再只改名字；用户预设名称用文本节点显示。

## 预览与复查

从 Delay 项目根目录运行：

```sh
python3 -m http.server 50586 --bind 127.0.0.1 --directory ui
```

打开 `http://127.0.0.1:50586/preview.html`。页面不处理音频，显示的时间与衰减图是可编辑参数模型。

```sh
cmake -S . -B build-test -DSANMU_COPY_PLUGIN_AFTER_BUILD=OFF
cmake --build build-test --target test_delay_ui SanMuDelay_AU SanMuDelay_VST3 SanMuDelay_AAX -j 6
build-test/source/test_delay_ui
```

原生测试会创建临时测试窗口并写入测试首选项；复查时请先备份 `~/Library/Application Support/SanMu Delay/SanMu Delay.settings` 并在测试后恢复。本轮已恢复测试前文件。

浏览器检查：安装 Playwright 后运行 `node tests/test_delay_web.mjs`；可用 `PLAYWRIGHT_MODULE`、`CHROME_PATH` 和 `DELAY_UI_URL` 指定已有依赖及预览地址。
