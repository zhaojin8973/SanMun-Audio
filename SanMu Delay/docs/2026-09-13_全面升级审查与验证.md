# SanMu Delay 全面升级审查与验证

本轮基于已完成的回声时间编辑器继续升级，目标是提高参数语义清晰度、自动化检查可信度和宿主状态同步稳定性。

## 已完成

- `Stereo` 界面名称改为 `Independent`，参数索引和工程状态格式保持不变。
- 提示和手册明确写出 Ping-Pong 的首个回声从左侧开始，并解释 Independent、Ping-Pong、Cross 的反馈路由差异。
- CMake 顶层接入 CTest，注册 `SanMuDelay_DSP` 与 `SanMuDelay_UI` 两项测试。
- 时钟测试不再使用硬编码成功值，实际测量 Free 模式 20ms／40ms 首个回声位置，并检查 BPM 与宿主模式参数来源。
- 原生编辑器 30Hz 帧在声音参数不变时只发送 meter，参数变化时才发送完整状态，降低 WebView 状态序列化开销。
- 历史 `EchoVisualizerComponent.*` 明确标记为未加入构建目标；正式界面是离线 Web 回声时间编辑器。

## 验证结果

- `ctest --test-dir build-test --output-on-failure`：2／2 通过。
- 浏览器回归：时间节点拖动、反馈拖动、键盘、联动、Ping-Pong 只读右路、预设、单位输入、冻结、撤销、144 组布局、5 档缩放均通过，无脚本错误。
- AU、VST3、AAX 构建成功。
- 28 个网页 schema 参数与原生 `editableIds()` 完整一致。

## 边界

- 本轮没有修改四种 Delay 引擎的音频处理实现。
- CTest 证明自动检查可执行，不等于完成 DAW 听感验收。
- 尚未替换系统已安装的 Delay 插件；AAX PACE 发布签名与宿主加载、侧链、Freeze、工程重开仍需在 DAW 中验证。
