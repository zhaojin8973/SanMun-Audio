# SanMu Delay 全面升级与布局决策

日期：2026-09-13

## 本轮调整

- 回声时间编辑器成为唯一的主时间操作区。L/R 节点支持拖动、双击输入和键盘操作；不再保留第二套时间卡。
- Independent、Ping-Pong、Cross 与 LINK 放入编辑器标题区，使用清晰的 ROUTING 分段控件。Ping-Pong 的首个回声从左侧开始仍由处理逻辑决定。
- FREEZE 放在顶栏全局动作区。它冻结已有回声并停止加入新输入，避免被误解为 Feedback 参数的一部分。
- Feedback 作为 Delay 的核心旋钮固定在主控区第二列；Modern 中间区域使用真实的 Mod Amount 旋钮控制 `mod_depth`，也就是 LFO 对延迟时间的调制量。
- 宿主 BPM 改为左侧主旋钮。SYNC 下显示宿主速度并锁定编辑，BPM 模式才允许手动输入；FREE 模式显示但不参与时间计算。

## 追加调整

- 主电平表已移除；Ducking 模块增加独立的 Duck GR 横向电平条，显示当前避让衰减。
- ROUTING 与四种 Delay 引擎同排，置于右侧；选中态使用更高对比度的紫色边框、底色和字重。
- PRECISION 位于编辑器标题右侧，集中放置 SYNC/BPM/FREE 与 LINK；时间操作提示固定在 EDITOR 页脚，不再出现在 BPM 旋钮上方。
- BPM 现在是左侧主旋钮。SYNC 时显示宿主 BPM 并锁定编辑，BPM 模式才编辑手动速度。
- 主控区固定为四列：Host tempo、Feedback、当前引擎专属参数、Mix。Tape 显示 Drive/Wow 两个旋钮，BBD 显示 Warmth，Diffused 显示 Diffusion，Modern 显示 Mod Amount。

## 显示修正

- 修正了引擎选择组宽度继承旧版 `width: 100%` 导致 ROUTING 被挤出可视行的问题；ROUTING 现在固定显示在四个引擎右侧。
- Duck GR 使用独立的固定高度条，避免被 Ducking 参数行的通用 flex 规则挤压或看起来像 Mix 电平。

- 预设窗口按音色类别分组，搜索时保留类别标题；用户预设仍使用原有保存格式。
