# Plate P2：低频和中低频松弛度

2026-09-06。用户反馈P1的低频、中低频振荡还需更稳定，希望中低频更松弛并保留暖感。P1完整保留在`candidates/0906F/`，Hall仍为0906E阶段定稿。

## 当前事实和参考范围

P1输入是12Hz一阶高通，主要处理直流和极低频。面板LowCut位于湿声输出。输入端削减会减少进入反馈网络的低频激励；在当前线性网络中，单独这样做并不能证明反馈共振寿命缩短。因此需要分别测量频带能量和激励停止后的尾声变化。

UA的[EMT140官方手册](https://help.uaudio.com/hc/en-us/articles/33030978351892-EMT-140-Plate-Reverb-Manual)说明其建模原机的输入滤波：原EMT电子线路为80Hz附近、-4／-10／-16dB三档削减；Martech改装为多档频率的低频搁架。此资料支持“板式输入会削减低频”，不把所有原机线路概括为同一个高通电路，也不直接照搬到本插件。

## 修改前的测量与试验设计

固定P1基准参数、100%湿声。先保存和查看40～2800Hz各频带脉冲包络，以及60、80、100、130、160、200、250、315、400、630Hz平滑短音停止后的响应。所有比较使用相同输入、初始化时间线和参数，不改预设补偿，不做响度归一化掩盖增益变化。

分两步试验：

1. 温和提高输入高通截止点，减轻深低频激励；先单独评估能量变化，不能将其当作反馈稳定性修复。
2. 若中低频尾声仍突出，在每段传播损耗内增加平滑、较宽的中低频阻尼，使共振自然早些释放。阻尼按传播时间与Decay标定，避免尺寸变化或循环次数改变时损耗失控。

保持Hall、Room、Chamber、Plate的延迟布局与输出读出、MOD、输出EQ和三个预设参数不变。高频不作提升；不增加由输入幅度驱动的压缩、门限或限幅。

## 交付前边界

- 深低频适度减少，100～350Hz能量变化以温和为目标，避免大面积挖空。
- 单独检查100～350Hz尾声寿命与绝对反弹能量；总电平降低不能作为稳定性改善的唯一证据。
- 700Hz以上尤其高频的电平和衰减尽量保留，不提亮补偿。
- 原Plate密度、立体声、衰减范围、块大小、线性、参数端点和极端运行检查继续通过。
- 新旧真实VST3核对Hall等保留类型，归档后安装，等待用户同素材复听。
