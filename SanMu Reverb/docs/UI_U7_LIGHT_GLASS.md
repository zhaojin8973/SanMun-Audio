# 混响界面 U7 · 浅色通透感与粒子色彩

2026-09-09。用户认可 U6 深色版基本可以定稿，认为浅色变化不明显、粒子颜色不理想，并提出减少白色底板遮挡、加强中央空间轮廓的方向。本轮保留深色，只更新浅色浏览器原型；尚未替换宿主插件界面。

## 浅色调整

板体白色覆盖由上方约 68%、下方约 52% 降为 40%、24%，保持顶部独立玻璃、旋钮和现有排版。中央采用更明确的灰蓝／淡紫渐层，边缘连续消隐。这里的半透明是原型内的材质合成，并不表示已经实现宿主窗口穿透。

粒子继续对应原有频段。浅色显色从整体压暗改为保留较亮主色、压低混杂色，呈现玫瑰粉、蓝紫和青蓝；原声细丝从灰色调整为带频段色彩的浅蓝。湿声颗粒显示直径乘以 1.7，配合原有柔边，使色彩覆盖更连续；不增加粒子数量或改变空间位置。显示系数调整为 1.75，并用柔和上限控制透明覆盖量，避免强信号时产生不透明的硬点。

深色的材质参数、粒子尺寸、色彩和面板样式维持 U6。新增显色仅在浅色开关启用时执行。音频引擎、粒子出生、频段数据、漂移、寿命和 MIX 湿声增益曲线保持原样。

## 核对结果

- 关闭截图过程中的控件过渡后，用同一冻结声场切换 U6 与 U7 的源码及样式进行比较：深色整页和中央声场的像素差均为零。报告与前后截图位于 `prototypes/particle-life/test-results/u7/`。
- `test:glass` 通过双主题、十二组窗口布局、真实背景文字对比、粒子可见度与主题切换状态保持。浅色最低文字对比约 5.03，深色约 7.69。
- 浅色的混响、叠加视图分别验证 MIX 100→25→0→100。隐藏湿声前后的同帧差分随 MIX 下降，MIX 为零时湿声像素差为零，恢复后返回相同声场。粒子出生、位置、原始颜色、透明度和原声透明度数组保持一致。

原始文件与校验值保存在 `audit/2026-09-09/ui-u6-dark-approved/`。当前浅色截图为 `test-results/u7/light-final.png`，100% MIX 截图为 `light-overlay-100-final.png`。深色保持用户认可状态，浅色候选仍由用户判断审美。
