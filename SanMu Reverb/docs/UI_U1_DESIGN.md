## 参考与取舍

已阅读同系列 EQ、Comp、Delay 的界面源码、资料库的 UI 规范，并查看 Delay 现有截图。沿用单面板、细线、功能用色、深浅外观等理念；用户已明确要求全新设计，旧规范中的固定玻璃层数、圆角、旋钮实现不作为本候选的限制。

EQ 的持续指针让方向更清晰；Comp 的部分旋钮仅在悬停时显示弧度，另一类把标题和数值放进盘面，削弱了指针语义。因此本版将参数名称、旋转操作和精确读数分开。

## 视觉设计

- 石墨与霜白两种面板；低饱和功能强调色。全窗为同一操作表面，靠间距、对齐和少量细线分组。
- 中央声场作为贯穿横向的实际动态内容，保留原本暗底与已认可配色。浅色主题同样保留声场的对比度。
- 主区五个参数：预延迟、衰减、尺寸、建立、混合。衰减与混合稍大，其余降低视觉权重，名称与读数基线一致。
- 旋钮为薄边浅浮雕、270 度细轨道、始终可见的短指针。数值位于旋钮外，单位弱化；无装饰光晕。
- 细节区同时可见四组：频段阻尼、扩散、调制、输出滤波。无需切标签即可比较参数。
- 顶栏集中预设、撤销、A/B、复制、外观与旁通；类型和双风格独立成行。
- 电平条的颜色固定对应分贝位置，不随条长缩放。输入／输出峰值保持可清除，输出在监听音量之前测量。

## 交互与声音

旋钮支持纵向拖动、滚轮、Shift 微调、键盘方向键、端点键、双击恢复默认和直接键入数值。拖到边界后反向立即响应，整次拖动对应一条撤销记录。预设名旁的标记表示参数已修改。

当前 23 个工厂预设来自已整理的 `HallPresets.h`、`PlatePresets.h`、`PresetManager.cpp`，没有引入旧架构预设。我的预设仅保存在浏览器本地；A/B 是两份参数快照，带复制操作。类型切换保留参数，预设加载应用完整参数。

四类八模式调用现有六份独立声场头文件，不修改混响音色。新增浏览器适配层保留参数平滑、两份切换状态和等功率淡化；原中央页面使用原 Hall 适配层。两页共用已定稿的粒子模块，原声仍显示输入参考，混响和叠加中的尘埃均受 MIX 控制。

## 验证与边界

`npm run test:studio` 覆盖八模式的 48 kHz 脉冲：浏览器与同适配层原生编译结果逐采样比较，检查有限输出及模式差异；另检查旋钮、单位输入、非法输入、边界回拖、撤销、A/B、保存恢复、类型切换、旁通、MIX、尾音、双主题和六种窗口尺寸。报告与截图在 `prototypes/particle-life/test-results/studio/`。

这是界面候选与本地试听原型，尚未替换 AAX/VST3，不包含宿主自动化、插件预设目录同步或多实例性能验收。八模式原生一致性检查验证的是浏览器移植，不替代宿主完整包装器的回归。四类暂共用已定稿的声场视觉表达。

本轮先由用户判断界面比例、旋钮质感与操作体验；确认后再设计插件嵌入和系列共用组件。EQ、Comp、Delay 的工程本轮仅作参考。
