# 0906F／Plate P1 首稿

2026-09-06。目标为温暖细密、兼顾人声和军鼓。Plate已重建独立内核；Hall保留用户认可的0906E与Cathedral C1，冻结包位于`releases/0906E_Hall/`。

## 现在怎样试听

保存工程并完整退出、重启REAPER，让宿主重新载入VST3。选择PLATE → Classic Steel，面板说明应出现“Plate P1 首稿”。预设菜单新增：

| 预设 | 用途 | Decay／PreDelay／Attack |
|---|---|---|
| 板式 · P1 基准 | 首稿固定对照，温暖且连续 | 2.39秒／15ms／30% |
| 板式 · 温暖人声 | 留出字头间隔，减少中低频积累 | 2.10秒／28ms／35% |
| 板式 · 军鼓短板 | 快速建立，保留鼓身与沙带 | 1.15秒／7ms／10% |

三个预设均为Mix100%，便于先听纯湿；插入使用时按编曲调整Mix，辅助轨通常保持100%。先在EARLY／LATE高扩散时判断连续性、温暖度和密度，再单独改变一个控制。与其他插件比较时先匹配实际湿声音量，旋钮相同并不保证不同算法的每个频段都相同。

EARLY控制初始扩散；LATE主要减少反馈中的重复纹理；Attack把最初的能量铺开，让起音更柔和。在Plate中，Attack不承诺与Hall相同的远近空间关系。EARLY很高时，LATE归零也不会完全消除输入端已形成的扩散。

Modern Silk、Vintage Gold目前共用P1，界面明确标注尚未独立设计。旧Plate预设加“历史”前缀保留，其名称不代表已完成对应材质建模或重新听审。

## 架构边界

四类混响各自拥有引擎与运行状态。Hall和Plate有各自的声场内核、扩散、损耗、调制和读出；本轮Plate没有引用Hall，也没有改Room、Chamber的旧共享运算类。

Room和Chamber目前分别是4线、6线反馈延迟网络（多条延迟相互回送以形成尾声），前端和参数映射不同。它们可以属于同一种数学结构家族，仍然独立设计；不必为了不同名称强行选择不同数学家族。两者都还需要后续专门设计和听审，独立文件不能代替声学完成度。

Plate P1使用六级输入全通扩散（将能量散布到不同到达时间）、非对称的双半环交叉反馈和多点输出。每段有记忆的传播独立计算损耗，包含全通内部的循环。它是算法板式混响，不宣称EMT薄板振动物理复刻。完整设计见[Plate P1设计](PLATE_P1_DESIGN.md)。

## 已完成的验证

主测试为48kHz、2.39秒、15ms、Mix100%、Size100、Attack30、EARLY／LATE100、Rate0.8Hz、Depth20%、HighFreq6000、HighShelf-18、BassFreq300、BassMult1、LowCut20、HighCut9000。

| 检查 | 结果 |
|---|---|
| 高扩散密度，40～120／120～500ms | 0.973／1.000，达到设计前约定门槛 |
| 建立后20ms能量窗口跨度 | 4.45dB，没有旧版超过20dB的空洞 |
| 双声道相同输入的左右能量差 | 0.10dB；单边输入也通过左右平衡检查 |
| 左右相关／单声道功率比 | -0.141／0.430，同时检查宽度和合并后的能量 |
| Attack 0→100 | 前500ms能量质心后移43.8ms，总能量变化约-2.13dB |
| LATE 0→100的周期相关峰 | 0.667→0.245；反馈重复纹理降低，匹配电平后结构仍不同 |
| 平坦损耗1／3／6秒，Size及LATE两端 | 十二组RT60测量误差均小于1% |
| 44.1／48／96／192kHz | 有限输出与扩散密度通过 |
| 运行行为 | 块大小一致、线性叠加、零输入、连续参数变化、异常输入、最长低频衰减均通过 |
| 真实VST3与离线DSP | 最大样本差1.17×10⁻¹⁰；干声端点无误差，24.8%混合误差小于2.1×10⁻⁹ |
| Hall／Room／Chamber保留 | 18组类型与模式检查，加9个Hall预设，样本差全部为0 |

真实参考对照另用Attack50、Rate2.53Hz、Depth38%、LowCut10、HighCut8010，与设计前保留的VintageVerb Plate／1970s使用相同输入、初始化时间线及显示参数；总湿声能量差约-0.05dB。此结果只排查显著电平偏差，不代表人声响度、音色或相似度已经获认可。

五组自动检查通过；三个新预设已通过真实插件参数回读及合成谐波、噪声鼓击渲染。合成素材不等同真实人声或军鼓，本版仍是等待用户听审的首稿。
