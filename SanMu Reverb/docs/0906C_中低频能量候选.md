# 0906C：进一步降低中低频晚期能量

> 后续状态：用户复听仍感觉浑浊，并补充250 Hz附近偏多、要求清晰但保留暖感。当前已安装 [0906D候选](0906D_清晰度与暖感候选.md)，0906C保留为历史对照。

2026-09-06。用户复听0906B后反馈：“现在中低频还是感觉有点浑浊，感觉能量可以再小一点。”本轮沿用先前的人声、Mix=100%听审条件，仅加深晚期音色调整。0906A仍为已认可初稿，0906B与0906C均保留为独立候选。

## 本次改动

晚期读出钟形均衡的中心保持175 Hz、Q保持1.35，中心增益由0906B的-1 dB改为 **-2 dB**。早期支路、反馈结构、Attack、Late、调制、衰减和总输出标定不变。界面标识为“Hall 0906C 候选”。

这是在用户复听反馈后的单项增量调整，没有新增滤波级或动态共振抑制。对应滤波器测试改为明确验证新的-2 dB目标及其带外作用，原有声场、路由及稳定性检查保持原要求。

## 对照上一版的结果

同一输入、同一参考参数、48 kHz、100%湿声、静音预热一秒，脉冲输入后300～3000 ms频带能量相对0906B：

| 频带 | 0906C相对0906B |
| --- | ---: |
| 70～110 Hz | -0.23 dB |
| 150～200 Hz | **-0.94 dB** |
| 250～400 Hz | -0.28 dB |
| 500～1000 Hz | -0.04 dB |

150～200 Hz相对0906A初稿累计约降低1.88 dB，该频带衰减外推仍约5.47秒。钟形曲线平滑延伸到两侧，因此相邻音高也会有所变化；例如125 Hz与250 Hz固定音高的晚期电平比0906B约再低0.54／0.51 dB。厚度是否合适仍需听审。

脉冲与宽带噪声整体电平比0906B约低0.05 dB，能量中位时刻变化不到2 ms，密度与左右相关变化很小；前40 ms逐采样相同。合成谐波短句整体约低0.29 dB，原始及匹配电平版本分别保存。全部均为合成诊断，未宣称已用用户真实人声验证听感改善。
