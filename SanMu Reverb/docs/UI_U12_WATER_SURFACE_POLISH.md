# 混响界面 U12 · 水膜静止态与深色配色

2026-09-09。用户认可水膜方向，希望静止时减弱或移除环形阴影，并指出深色按钮、旋钮刻度和强调色偏白。本轮基于 U11 做小范围视觉收束。

## 调整

- 水膜高度场的基础弧面和表面透明度现在都乘以真实输入／湿声活动量。没有声音或尾音结束后，水面回到平面透明，不会由材质自行留下碗状轮廓。
- 浅色 `--field-atmosphere` 改为 `none`。动态形态只来自水膜自身的坡度、曲率和折光；静止声场不再有 CSS 环形底色。
- 深色主题的次要文字从偏白灰改为蓝灰，刻度、轨道、旋钮边缘和光泽改为青蓝，控制强调改为更饱和的淡紫。主面板明度和布局不改，保证仍是深色玻璃。

## 边界与验证

水膜、输入参考和混响继续使用同一时钟；MIX 为零只隐藏湿声水膜，不清空内部尾音。深色仍显示粒子，浅色仍显示水膜，音频算法和粒子模拟没有改动。

已运行 `test:studio`、`test:glass`、`test:settings`、`test:language`、`test:views`、`node --test tests/water.test.mjs` 和 `npm run build`，全部通过。静止、动态浅色和动态深色截图位于 `prototypes/particle-life/test-results/u12/`。
