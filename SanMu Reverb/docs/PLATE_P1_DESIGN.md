# Plate P1：独立板式混响设计

2026-09-06。Hall阶段定稿，冻结包为`releases/0906E_Hall/`，包含Concert Hall 0906E与Cathedral C1。Scoring Stage仍未独立设计。用户选定Plate首稿目标：温暖细密，兼顾人声和军鼓。

## 当前边界与原始证据

四类引擎在`ReverbProcessor`中各自实例化，状态互不共用。旧Plate为双半环交叉反馈与全通扩散；Room为早期反射加4线反馈延迟网络；Chamber为带宽塑形加6线反馈延迟网络。后三者共享部分原语代码，但各自拥有实例；它们没有调用Hall声场。

分开文件不等于完成声学验证。旧Plate的EARLY、LATE没有被使用，Attack调用的旧原语是直通。实际安装插件的0／100端点输出相对基础逐样本差为零。旧Plate原始脉冲在300ms附近出现明显能量凹陷，与连续尾音目标不符。旧代码注释中的“真实EMT物理建模”“7对拾音抽头”等描述也与实际计算或证据不一致。

原始输入、输出及回读保存在`audit/2026-09-06/plate_p1/`。对照为已安装VintageVerb Plate／1970s，2.39秒、15ms、100%湿声，其他参数逐项记录。曾尝试2.40秒但宿主枚举不支持，未产生参考输出；随后双方统一为可回读的2.39秒。参考仅辅助理解板式音色，不把它的私有结构视为已知。

## 独立内核

新Plate使用自包含`plate/PlateField.h`，不包含`hall/`，不改旧`primitives/`，因此不改变Hall、Room或Chamber。`PlateEngine`只做参数检查、平滑与接口适配。

内核为输入带宽约束、六级短全通扩散、两个非对称交叉反馈半环。每个半环含两级全通和两段传播延迟。输出从两半环多个内部位置读出；前方拾音共享一部分能量，后段用等范数的不同读出保留宽度。没有Hall式的独立房间早期反射树，也没有给Hall延迟整体缩放后改名。

全通扩散表示主要改变相位与时间分布的滤波网络。经典数字Plate常使用交叉反馈全通结构，但这不等于求解金属薄板振动，更不能宣称EMT140／240物理复刻。真实金属板的频散（不同频率传播速度不同）及拾音器特性，本轮只以声音参考观察，不作精确建模声明。参考：[Valhalla板式声学说明](https://valhalladsp.com/2015/11/08/the-physics-and-psychophysics-of-plates/)、[扩散讨论](https://valhalladsp.com/2015/11/18/valhallaplate-diffusion-and-presets/)。

## 参数职责

- EARLY：输入扩散路径的散开程度；LATE：反馈半环中全通分叉的强度。两个参数都必须实际改变时间结构。
- Attack：初始扩散能量铺开的跨度。Plate常用快速建立，不能照搬Hall的远近定位含义，也不压低整段湿声冒充柔和起音。
- Decay：按每个有记忆的传播段计算绝对衰减；全通内部反复传播也计入，避免只估一个“总循环时间”导致Size或Late变化时衰减失准。
- BassMult、HighFreq、HighShelf：传播损耗的分频衰减；LowCut、HighCut：输出音色。输入带宽仅作轻微约束。
- MOD：轻微非同步延迟变化，用于缓解重复纹理，深度归零应稳定工作，不靠强合唱感掩盖共振。
- 首先只制作基础Plate。其余两个模式暂共用这个内核，并明确未独立设计，不以固定亮度或衰减倍率宣称不同金属材质。

## 编写前确定的验证方向

固定主参数：2.39秒、15ms、Size100、Attack30、EARLY/LATE100、Rate0.8Hz、Depth20%、HighFreq6000、HighShelf-18、BassFreq300、BassMult1、LowCut20、HighCut9000；同输入100%湿声测量。

1. 高扩散40～120ms密度均值大于0.65，120～500ms大于0.80；建立后的20ms窗口能量不出现超过20dB的空洞。
2. 左右能量差小于1.5dB，相关绝对值小于0.6，单声道合并功率比大于0.18；包括相同左右输入与单边输入。
3. EARLY、LATE、Attack在匹配电平后仍有可听结构差异。平坦损耗、无调制的1／3／6秒衰减误差不超过10%，并核查Size和Late端点。
4. 44.1／48／96／192kHz、块大小、线性叠加、零输入、最长低频衰减和连续自动化等保持数值稳定。
5. Hall两个已定稿模式、Room、Chamber与0906E真实VST3逐样本对照；Plate发布不能顺带改变它们。
6. 合成诊断覆盖短噪声打击和有音高短句；真实人声及军鼓由用户复听，机器检查不替代声音认可。

若第一次实现未通过这些检查，保留失败记录并修改内核原因，不以改阈值迁就输出。
