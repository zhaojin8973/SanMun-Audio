# 混响界面 U10 · 浅色透明水膜候选

> 后续修订：U11 处理高光和水膜透明度，U12 移除静止 CSS 环影并收紧深色控制配色。当前以 [U12 记录](UI_U12_WATER_SURFACE_POLISH.md) 为准。

2026-09-09。用户决定保留 U9，同时尝试一种不依赖暗色对比的浅色表达。本轮实现“透明水膜＋极淡水下光纹”候选；深色仍保持粒子尘埃。

## 形态

浅色主题不再显示粒子和暗色漩涡，而是在声场中显示一片透明的薄水膜。中心扰动来自输入参考，湿声高度场从中心向外围展开并逐渐平复。表面坡度、曲率和视角高光形成柔和折光；底层光纹使用同一高度场的曲率近似，不引入第二套无关动画。

透明水膜的颜色以银蓝、青灰为主，频段色彩只轻微混入。高光已限制透明度，避免白色水花和白雾。深色主题使用 `dust` 材质，浅色主题使用 `water` 材质；两者共享同一音频指标、参数语义、时间时钟和三种观察模式。

## 声音映射

- 输入电平：中心短扰动与中心折光。
- 湿声电平：外围水面起伏、表面密度与尾音留存。
- PreDelay：湿声形态出现的时间间隔。
- Attack：中心压低、后方水面建立更舒展。
- Size：水膜展开范围；Decay：形变和亮度的消退时间。
- Early／Late：中心到外围的纹理融合；Mod：局部细微漂移，不让整片水面左右摆动。
- MIX：湿声水膜的显示强度，输入参考仍独立；MIX 为零时水膜不显示但内部状态继续演进。

水面是视觉模型，不代表真实水波方程或混响内部延迟线。静音且尾音结束后，水面回到透明静止状态，不循环制造活动。
