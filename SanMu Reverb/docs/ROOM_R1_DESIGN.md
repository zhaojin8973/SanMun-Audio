# Room R1 独立设计与验收

2026-09-07。Hall、Plate已获阶段听审认可，本轮只替换Room声学内核；Chamber暂缓。

旧版原始证据位于 audit/2026-09-07/room_r1/before：Attack和Late端点逐样本差为零，三个模式共用反射与循环长度，只改变读出比例。原始脉冲中两个模式峰的位置完全重叠。因此全部替换RoomEngine及其旧原语依赖。

新结构：预延迟 → 一、二阶镜像反射 → 早期散射；另一路进入时间铺展器 → 十六路短传播反馈网络 → 晚期读出。两路混合后输出EQ。镜像反射根据长宽高、声源和接收位置计算；晚期是统计近似，不宣称完整物理仿真或商业算法复刻。

两种风格：Studio Room基准尺寸6.1×4.4×2.9米，较近反射、紧凑尾音；Live Room为11.3×8.1×4.9米，更长的反射间距和晚期传播路径。Size同时缩放几何与晚期路线；不是只改Decay。参考尺寸是算法设计坐标，不是实测房间。

EARLY改变早期反射的微扩散；LATE改变晚期输入与循环内扩散；Attack让明确的前方反射逐渐让位于较迟且铺开的晚期能量，不使用音量检测、压缩或吞掉音头的包络门。调制只作用于晚期，几何反射不随调制漂移。

每段存储含按传播时间计算的频率损耗；散射矩阵正交，不添加隐藏反馈增益。低频吸收和输出电平固定依赖参数，不依赖输入音量。独立实现基础延迟、滤波、全通原语；不引用或改变Hall、Plate内核。

预先验收：两个模式同参数归一化波形差>0.2；三个控制端点差>0.2；高扩散尾部归一化密度>0.8；中央单声道输入左右总能量差<1.5dB、相关绝对值<0.85、折叠单声道功率比例>0.2；平坦阻尼下RT60误差<15%；四种采样率、静音、线性、极端参数、自动化有限且无发散；不同块大小及真实VST3与离线渲染差<2e-6；干声端点严格相同。测量不能证明听感满意，R1交付状态为待用户试听。

宿主mode仍保留三个内部编号以兼容自动化：Room 0=Studio，1=Live，2兼容Live；菜单仅两个。Hall只显示Concert与Cathedral，Cathedral内部编号2不变。Plate菜单与算法不变。旧Room工程改用新算法，声音会变；0907B留作回退。

保留现有37个工厂预设的编号、参数；末尾追加Room基准及应用预设。Room预设建议0.45～1.3秒。共同默认3.99秒也验证，但它不是紧凑房间的主要试听设置。

首稿结果：7组CTest、真实VST3路由和保留检查通过。初始版本全局湿声电平较认可Plate低约6dB，固定标定2倍后共同默认白脉冲能量接近Plate；没有修改反馈、扩散与频谱结构。详见0907C试听说明与审计报告。

设计资料：镜像反射与统计晚期可以采用不同建模精度，参考[房间散射延迟网络论文](https://arxiv.org/abs/1502.05751)的早期精确、高阶近似思路；本版采用镜像反射加正交反馈网络，并非该论文的SDN实现。
