# 0907A／Plate P3 试听候选

针对“新插入插件后直接切换类型”时，Plate中低频嗡鸣较多、与Concert Hall色彩过近的问题。本版按实际新建默认参数校准，未修改默认值；Hall沿用已认可的0906E。

## 这次改了什么

- Plate的双半环反馈改为八路传播、混合回送，分散低中频突出的共振。
- 初始扩散与尾声阻尼分开，保留更完整的起音频谱；高频余韵比P2延续得更自然，以形成板式色彩。
- 保留55Hz输入高通、温和的低频传播吸收与小幅调制。三个Plate预设更新为P3名称，参数与位置不变。

这里也更正之前的架构描述：P1/P2虽然重写了代码，仍属于双半环反馈结构；P3才改变核心反馈组织。本版不声称复刻参考插件的私有算法。

## 实测变化

48kHz、100%湿声、相同输入与初始化时间线；参数为Decay3.99秒、PreDelay20ms、BassMult1.5、Attack50、Early/Late100、Mod2.53/38及其余新建默认值。

| 指标 | P2 | P3 | VintageVerb Plate NOW |
|---|---:|---:|---:|
| 80～400Hz谱峰谷统计 | 18.08dB | 10.50dB | 10.32dB |
| 关闭调制后的谱峰谷统计 | 19.42dB | 10.65dB | 本项未测 |
| 2.8～5.6kHz估算衰减 | 2.25秒 | 2.83秒 | 2.94秒 |
| 5.6～10kHz估算衰减 | 1.36秒 | 1.94秒 | 2.40秒 |

P3相对P2的100～200Hz脉冲能量降低约1.18dB，200～350Hz降低约1.54dB；整体脉冲能量对应电平约增加0.70dB。持续噪声下100～350Hz能量也降低约0.71dB。没有把中低频大幅挖空来追求清晰。

谱峰谷统计为固定分析方法下的P95－P10，包含频谱斜率，不能换算成听感相似度。某些单音尾声的局部起伏仍比P2大，不能据此宣布嗡鸣完全解决。参考HighCut实际回读为7990Hz，SanMu默认8000Hz；其余共同指定参数吻合。Supernova仅作辅助参考，不列入同参数表格。

## 怎么复听

1. 保存工程，完整退出并重新启动REAPER，避免旧插件二进制继续留在内存。
2. 新插入SanMu Reverb，选择`PLATE → Classic Steel`；面板说明应显示`Plate P3`。先保持全部新建默认值和Mix100%，直接切换`HALL → Concert Hall`对比。
3. 用同一段人声听字头、100～350Hz的嗡鸣及后方尾音；再用军鼓听鼓身是否温暖、尾音是否清楚。对比其他插件时匹配湿声响度。
4. 完成默认状态对比后，再试`板式 · P3 基准`、`板式 · P3 温暖人声`、`板式 · P3 军鼓短板`。加载预设会改变参数，不要把它与“只切类型”的测试混在一起。

`Modern Silk`和`Vintage Gold`暂共用P3；当前交付重点为Classic Steel。

## 验证与回退

五组自动测试通过；新插入只切类型与显式设置默认参数的输出一致。真实VST3与离线DSP最大样本差约3.86e-8，Mix0严格保留干声。Hall、Room、Chamber及九个Hall预设的27项对照均与0906E逐样本一致。

本机48kHz/128样本的离线处理耗时约为音频时长的1%，约为P2的两倍；这不是REAPER多实例实时负载保证。本轮素材为脉冲、纯音、噪声及合成谐波/鼓击，真实素材听感尚待用户确认。
