# 定稿前工程审查与修复

本轮已修复确认的问题并完成自动化回归。声音和视觉设计可继续保持已认可版本；完整插件发布仍需新界面接入，以及接入后的真实宿主验收。

## 已修复

| 问题 | 修复后的行为 | 验证 |
| --- | --- | --- |
| 浏览器音频启动失败后残留输出节点，静音、音量操作访问空上下文 | 先清空公开状态，再断开节点、关闭消息端口和上下文；关闭失败也不覆盖原始错误 | 单元故障注入及真实浏览器工作节点启动失败测试 |
| 音频处理器运行中故障后仍标记为已就绪 | 停止输入、清理失效音频图，下次播放重新创建 | 在真实音频工作线程内抛出异常，随后操作控件并重新播放通过 |
| 原生数值输入只提取数字，错误解释单位 | 原生旋钮与宿主文本入口共用解析；支持中英文频率、时间、分贝和倍数单位；非法输入保留当前值 | `8.5 kHz → 8500 Hz`、`.035 秒 → 35 ms`、`2500 ms → 2.5 s`；15 项参数显示文本往返通过 |
| 宿主工程恢复缺少用户预设已有的完整性校验 | 两个入口共用状态校验；非法、缺失、重复、越界和非整数模式状态被拒绝，当前参数保持 | 先复现 5 项失败，再修复；正常 23 组完整参数恢复及历史模式兼容回归通过 |
| AU、AAX 构建包只有无效的临时签名 | 三种格式在完整包生成后执行本地开发签名；开启自动复制时先签名再复制 | VST3、AU、AAX 均通过严格包签名验证 |

声音处理器源码、工厂预设数值定义及浏览器音频模块的 SHA-256（文件内容指纹）与本轮开始时相同。预设管理代码的改动仅为复用状态校验；视觉布局和材质未调整。

## 已完成验证

- 原生 Release 构建：VST3、AU、AAX，当前构建架构为 arm64。
- 原生 9 组 CTest 全部通过，覆盖各类混响契约、整体回归、预设与运行期测试。
- 原型 22 项 Node 测试全部通过：既有 16 项声场测试，加 6 项音频生命周期回归。
- 原型生产构建和音频模块与源码一致性检查通过。
- 八种风格的浏览器音频与原生引擎输出比较通过；旋钮、预设、对比、撤销、旁通和双主题检查通过。
- 5 组浏览器回归全部通过，无页面运行错误：主界面 12 组布局、设置 19 组布局、语言 48 组布局、玻璃主题 12 组布局，以及 3 种真实音频故障恢复场景。
- 23 个工厂预设的全部 17 项参数通过宿主状态接口保存和恢复；既有用户预设文件保存、非法文件拒绝和旧模式迁移检查通过。
- 单声道、立体声，44.1／48／88.2／96／176.4／192 kHz，以及 1／16／32／64／127／512／2048 采样缓冲，共 672 组输入与风格切换测试通过；包含超过准备块长的实际输入和零长度块。
- 无效音频采样处理、状态恢复后的旧尾音清理，以及原生编辑器关闭重开 12 次通过。
- 8 实例在 48 kHz、32 采样缓冲下各处理 1 秒音频，串行耗时约 0.161 秒。所测音频回调内 C++ 动态分配计数为零。
- 改动的空白错误检查通过。深浅主题截图已实际查看。

以上多实例耗时是本机离线测试值；动态分配计数覆盖 C++ 分配入口，不能据此宣称所有宿主、所有系统调用均满足实时期限。构建保留既有的精确浮点比较等警告，原型构建保留较大资源包提示。

## 发布前剩余工作

1. **新界面接入原生插件。** 当前玻璃面板、粒子、水波、A/B 和设置位于浏览器原型；原生 `PluginEditor` 仍为旧编辑器，工程明确关闭了浏览器嵌入。需要把界面参数、宿主自动化手势、状态保存、预设与音频电平连接起来。浏览器试听入口与宿主音频输入的职责也需在接入时落实。
2. **接入后的真实宿主验收。** 本轮验证的是插件处理器的宿主状态接口和独立编辑器生命周期，未替代 REAPER、Pro Tools 等宿主中的工程保存重开、自动化回放、旁通、窗口重开和长时间多实例使用。
3. **正式分发检查。** 当前产物为本地开发签名；正式 AAX 分发授权、正式签名、公证及目标架构覆盖尚未在本轮验收。

本轮构建关闭自动安装，已安装的插件未被本轮产物替换。临时故障注入只存在于测试浏览器，测试结束后已关闭；用户原有预览服务保留。
