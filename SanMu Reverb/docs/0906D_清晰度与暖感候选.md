# 0906D：250 Hz附近的清晰度与暖感平衡

> 后续状态（2026-09-06）：用户已用钢琴、弦乐、人声复听并认可当前0906D声音。另发现EARLY=0的局部前段声像问题，本轮仅排查，插件保持原样；见[听审认可与零值排查](0906D_听审认可与EARLY零值排查.md)。下文保留候选制作时的记录。

2026-09-06。用户复听0906C后，认为仍稍浑浊，250 Hz附近也偏多；这是相对VintageVerb、Supernova的人声纯湿听感，同时要求保留暖感、避免过亮。本轮调整中低频分布，0906A继续作为已认可的初稿。

## 先核查参考差异

对已保存的相同宽带噪声输出匹配整体RMS（均方根电平）后，0906C在210～300 Hz的相对能量比VintageVerb低约1.11 dB，比Supernova高约0.62 dB。因此不能把用户的感受直接写成“0906C整体中低频比两个参考都多”。持续人声、具体音高、反射的时间分布和电平都会影响比较，这次只形成可复听的音色候选。

参考噪声来自前次完整参数记录。VintageVerb为Concert Hall／1970s和用户确认参数；Supernova为之前脚本的Vintage Hall、4秒、20 ms、100%湿声，其余默认。两者参数系统不同，不能宣称Supernova与用户面板完全对应。图与原始统计在 `audit/2026-09-06/hall_lowmid_d/参考频谱检查.*`。

## 具体改动

保留单个晚期读出钟形均衡，将曲线从175 Hz／Q=1.35／-2 dB调整为 **225 Hz／Q=1.10／-2.5 dB**。它向250 Hz附近平滑延伸，没有叠加新的削减级。

150～175 Hz附近的削减略浅，250～350 Hz附近更收敛。高频增益、输入带宽、输出高切和反馈高频阻尼保留，未加入高频提升。减轻中低频后主观上仍可能更通透，不能把高频设置未变等同于听感一定不会更亮。

早期反射、反馈拓扑、Attack、Late、调制、衰减和总输出标定保持0906C的实现。这是静态音色分布的候选，不是动态共振抑制算法。

## 相对0906C的测量

48 kHz、同一脉冲输入、相同参考参数、100%湿声、静音预热一秒，输入后300～3000 ms频带能量：

| 频带 | 0906D相对0906C |
| --- | ---: |
| 70～110 Hz | +0.04 dB |
| 150～200 Hz | +0.03 dB |
| 210～300 Hz | **-1.24 dB** |
| 300～450 Hz | -0.77 dB |
| 600～1200 Hz | -0.12 dB |
| 2～6 kHz | -0.01 dB |

同一固定音高、两个启动相位下，250 Hz停音后的晚期电平约再低1.35 dB；150 Hz约恢复0.35 dB，175 Hz附近变化很小。整体频带能量基本保持不代表每个音高完全相同。

210～300 Hz衰减外推仍约4.93秒，归一化曲线基本重合。前40 ms输出逐采样相同；脉冲和噪声总电平变化不到0.08 dB，中位时刻变化不到3.5 ms，晚期密度与左右相关变化很小。

220／262／330 Hz固定和弦位于本次调整范围，整体下降约0.90 dB。预先设置的新测试方案对该和弦检查适量下降，不能继续要求沿用175 Hz局部调整时的小电平变化条件；宽带及结构检查仍保留原要求。合成谐波短句整体约低0.30 dB，原始与匹配电平试听分别保存。没有用用户实际人声文件验证听感改善。
