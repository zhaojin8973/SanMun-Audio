# 混响界面 U8 · 浅色冷蓝灰漩涡

> 历史候选：用户随后指出浅色颗粒与深色不同、窄漩涡像污迹。本方案已由 [U9 共用发光尘埃](UI_U9_SHARED_DUST.md) 替代。

2026-09-09。用户认可深色版的粒子空间感，指出浅色版的黑色漩涡与白色面板不协调，同时完全透明又缺少深度。本轮保留深色版，仅调整浅色显示。

## 视觉方案

浅色声场使用带冷蓝／灰紫色相的半透明漩涡，不使用纯黑。中心最深处限制在较窄区域，第二层和第三层快速降低不透明度，最外层在约 54% 椭圆半径处消失，并叠加极弱的紫蓝内晕。其作用类似浅色玻璃中的深色内腔：提供前后关系，但不形成独立的黑色面板，也不产生上一版的大面积白雾。

浅色粒子继续使用频段对应的粉、紫、青蓝显色，保持细小颗粒和透明边缘；不增加粒子数量、不改变模拟尺寸。深色的面板、漩涡、粒子合成和颜色保持 U6／用户认可状态。

## 实现边界

只改浅色主题的 `--field-atmosphere`；声音、粒子位置与生命周期、频段颜色、MIX 规则以及深色主题不改。该漩涡是显示层的背景提示，不代表真实声学边界或混响算法中的延迟线。

## 核对结果

- 以控件过渡关闭的同一冻结声场对照 U7 与 U8：深色画布的像素变化为零。
- `test:glass` 通过，浅色与深色均有可辨识粒子，十二种布局和文字对比通过。
- `test:views` 通过，三种信号视图和 MIX 100→25→0→100 检查保持：MIX 为零时湿声不可见，恢复后回到原状态。
- 浅色最终截图保存在 `prototypes/particle-life/test-results/u8/final-narrow.png`；前版纯黑漩涡对照为 `u8/luminous.png`。两者仅供视觉比较，最终仍由用户判断。
