# 0907C · Room R1 首稿

2026-09-08补丁候选已独立归档为 **0907D**：仅对新插入默认的长尾状态（Decay超过2.5秒）增加轻度早期高频空气吸收，降低离散反射的金属边缘；四个短Room预设保持原有轮廓。详见[0907D说明](0907D_Room默认柔化候选.md)。

Room已重新设计为独立内核，提供两种风格。0907C已安装ARM VST3；机器验证通过，Room尚待用户真实素材听审。Hall及Modern Silk、Classic Steel保持0907B声音。

## 两种风格与起始预设

| 风格 | 设计重点 | 新增预设 |
|---|---|---|
| Studio Room | 较近、紧凑的房间反射，保留声源音头，适合干录人声、木吉他、钢琴及多轨共同空间 | 录音室 · 自然基准（0.65秒）；录音室 · 贴近人声（0.45秒） |
| Live Room | 较大的反射间距和更开阔的展开，适合鼓组、打击乐与乐器合奏 | 现场房间 · 开阔基准（1.30秒）；现场房间 · 鼓组空间（0.85秒） |

四个预设在工厂列表末尾，均为100%湿声，方便辅助轨和纯湿诊断。插入轨使用时，先将Mix降至10～25%听贴合、音头和远近，再回到100%湿声检查尾音。这里的范围是首稿试听起点，不是响度匹配标准。

保存工程后完全退出并重新启动REAPER，以加载已安装的新二进制。选择ROOM时，模式菜单应只出现Studio Room与Live Room。

## 控制与结构

旧Room的Attack和Late端点输出完全相同，三个模式只改增益配比。本版已替换旧RoomEngine及其原语依赖：采用一、二阶镜像反射（由参考几何坐标计算反射路径）加十六路统计晚期反馈场；没有调用Hall或Plate声学内核。

EARLY改变早期反射的微扩散；LATE改变晚期输入及循环中的扩散；Attack让明确的前方反射逐渐让位于更迟、更铺开的晚期能量。它不是响度保持旋钮，端点总体电平会有适度变化；没有压缩、自动增益或音频触发包络。MOD只作用于晚期，早期几何反射不随调制漂移。

两个模式使用不同的长宽高比例、反射时间和晚期延迟分布。房间坐标仅为设计参考，晚期为统计近似；不宣称完整物理建模，也不宣称复刻商业算法或某个录音棚。

新插入默认仍是原来的3.99秒及其他原参数，直接切Room会得到较长的房间尾音。判断这次Room定位建议先用新增的短预设。Hall、Plate的默认旋钮未改。

## 验证结果

- 7组CTest通过，包括Room专项、Hall、Cathedral、两种Plate、全引擎回归与预设往返。
- 真实VST3：18项保留类型/模式检查及31个非Room旧预设，与0907B逐样本相同；旧37个预设的参数和宿主编号全部保留。
- 两种Room的离线与真实VST3逐样本一致；Mix=0严格等于干声；24.8%等功率混合最大误差约2.1×10⁻⁹。
- EARLY、LATE、Attack端点真实改变时间结构。平坦阻尼在0.4、1、3秒、尺寸与扩散端点的衰减误差均在预设15%门槛内。
- 四种采样率、不同块大小、单声道、中央/单侧/反相输入、静音、线性、模式切换、连续自动化及极端参数通过。
- 两个基准预设在中央输入、EARLY=0/100时，左右总能量差小于0.12dB。单声道兼容由真实求和能量同时检查。
- 共同默认下，Studio/Live相对输入白脉冲能量约-6.02/-5.73dB；Modern Silk约-5.75dB。首版Room低约6dB，依据同口径测量增加固定2倍输出标定，不跟随输入音量。此结果不等同任意音乐素材的感知响度相同。
- 已安装版本通过签名、整包逐文件哈希及重新加载渲染验证。原始数据与合成试听位于`audit/2026-09-07/room_r1/`，候选归档位于`candidates/0907C/`。
