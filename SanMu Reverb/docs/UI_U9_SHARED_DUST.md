# 混响界面 U9 · 两个主题共用发光尘埃

2026-09-09。用户指出 U8 浅色粒子像独立彩点、扩散观感与深色不同，中央漩涡像小块污迹；希望保留深色版宽阔、微弱同心层次的空间感。本轮为浏览器原型候选，仍待用户视觉确认。

## 原因与处理

U7／U8 的浅色路径把湿声显示直径乘以 1.7，并使用普通透明覆盖、较深显色和独立的透明度压缩。运动数据没有改变，但投影大小和叠加关系改变了细密程度与远处尘埃的可见度。U8 又把背景的主要深度收窄到中心，形成小块暗斑。

U9 删除浅色专用的粒子放大、颜料显色和普通透明材质分支。浅深两个主题共用同一套点尺寸、柔边、颜色、显示系数及发光叠加；原声也恢复相同的细丝。浅色面板采用普通画布合成，深色保留原有滤色合成，适应不同底色。因此合成到面板之前的尘埃图像一致，最终背景对比与主观亮度仍会不同。

浅色背景改为宽幅银蓝渐层，在 28% 和 50% 半径继续过渡，在 70% 处透明，以免椭圆在声场上下边界被截成矩形。另有最高约 3.5% 不透明度的同心明暗纹理，向中心及外围消失。纹理静止，只是显示层的纵深提示，不表示音频中的周期振荡，也不改变尘埃运动。

## 验证与边界

- 用同一冻结声场切换本轮前后的着色程序，深色中央图像逐像素一致；结果见 `prototypes/particle-life/test-results/u9/regression.json`。
- `test:glass` 增加主题切换前后的原始画布比较，防止以后再次出现主题改变粒子尺寸、柔边或叠加密度的情况，同时保留十二种布局、文字对比、可见度和状态保持检查。
- `test:views` 通过，原中央页面的三种观察方式和 MIX 联动仍正常。
- 粒子模拟、出生、生命周期、空间运动和音频模块没有修改。修改前源码与校验值在 `audit/2026-09-09/ui-u8-before/`。

当前浅色截图为 `prototypes/particle-life/test-results/u9/final-light.png`，同帧深色为 `final-dark.png`。这些截图用于对照，测试通过不代表用户已认可浅色审美。
