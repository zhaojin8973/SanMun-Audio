# 生命粒子视觉设计草案

2026-09-08。根据用户提出的中央三维生命粒子概念整理。用户已认可空气尘埃运动、梦幻配色及三种观察视图；本次让混响和叠加视图中的尘埃统一跟随 MIX。参见 [原型运行与边界说明](../prototypes/particle-life/README.md)。当前实现仅覆盖 Concert Hall，不修改已认可的混响算法。

## 已确定的方向

- 中央三维粒子是界面的主体验，每颗粒子有自己的生命过程和稳定个性。
- 输入声音触发生成，混响长度影响生命长度，频率成分对应颜色。
- 每个声音参数需要有含义清楚、能直接观察的视觉反馈。
- 优先制作独立粒子原型；顶栏、类型栏、参数区、电平表等产品组件随后设计。

## 推荐的整体形态

用户体验首版后进一步明确：希望是空气中的尘埃，由中心向四周弥散；像实时频谱一样随声音产生动态，运动应丝滑，不要喷射或左右摇晃。

第二版因此采用居中的悬浮尘埃体积：能量由中心向四周唤亮尘埃，主要动态由各频段真实湿声能量控制可见强度，尘埃本身只缓慢向外移动，并保留细微、连续、非周期的局部漂移。取消首版前下方出生后向后飞行的轨迹与地面圆环。

固定接近正视、略带俯视的镜头，同时保留前后透视。空间边界由尘埃分布自然隐去，不绘制实体房屋或球壳。镜头不自动绕场旋转，整体中心不随左右统计摆动；同一窗口内镜头也不追随 Size 自动缩放。

第三版根据用户希望更梦幻的反馈，改用固定频率色谱：低频柔粉、中频雾紫、中高频冰青、高频珠光蓝，相邻色调作轻微过渡。发光保留颜色和暗部，避免粒子一多就叠成白色光团；色彩不表示更好或更差的声音。

## 原声与混响的独立观察

用户提出希望从图像分辨原始声音和混响，这在当前工程中可直接读取两路独立信号。第三版提供原声、混响、叠加三个视图，默认叠加，视图切换不改变试听声音。

原声层是固定在中央小范围内的珠光短细丝，直接由混响前的实际输入频带控制，快速响应起音和结束，不使用混响参数安排寿命。混响层保留认可的外围尘埃与缓慢弥散，继续使用纯湿声约束明暗。两层通过线与点、集中与弥散、快速起落与长尾留存区分，共用频率色谱。

用户进一步确认：中央应保持输入参考，混响和叠加视图均应反映 MIX 控制后的混响用量。因此两个视图统一把声音的等功率湿声增益作用于尘埃显示强度，MIX 调小则尘埃变淡，为 0% 时不可见，为 100% 时完整呈现。此变化不修改粒子的出生、寿命、空间或配色；内部尾音持续演进，恢复 MIX 时显示其当前状态。

原声视图独立观察混合前的输入信号。混响视图只隐藏中央输入参考，不绕过 MIX，其尘埃强度与叠加一致。中央始终是输入参考，所以 MIX 为 100% 时原声和叠加视图仍可看原声，不等同于最终输出中的干声分量。未来辅助轨中的中央代表发送到插件的输入，插件之后的辅助轨推子不属于可直接观测的数据；本原型尚未嵌入宿主。

叠加不声称表现整个工程最终输出的精确干湿响度比例。画面的迟缓感包含混响的建立、拖尾，以及视觉平滑；不能把画面时间常数直接当作混响算法的响应时间。

## 三层驱动

1. 输入事件：输入电平与频带分布决定出生率、初始权重和颜色；瞬态触发短促成簇生成，持续声音保持连续生成，尾音本身不重复充当新输入。
2. 声场规则：按类型、模式、预延迟、建立过程、扩散、调制和阻尼安排传播及衰退。位置与运动是可解释的视觉模型，不声称粒子逐个对应真实声波或内部延迟线。
3. 输出约束：用真实纯湿声的频带能量、包络和立体声指标约束可见强度与整体分布，避免只有旋钮在驱动画面。实际有尾音时应有存量粒子，无尾音时不维持虚假的自激活动。

当前 ReverbProcessor 只有输入/输出峰值和湿声绝对值均值，无法准确支持频带颜色或早晚反射的分离。实现时需要独立的可视化数据旁路；不把现有 getReverbEnergy 当作完整频谱或声学能量测量。

## 单颗粒子的生命

每颗粒子记录出生时间、代表频段、能量权重、声源左右位置、传播路径、调制相位和固定随机种子。出生时赋予小范围的方向、速度、体积与路径差异，同一颗粒子的个性在生命期间保持连续，不逐帧重新随机。

生命周期建议分为待传播、早期散射、晚期弥散和消隐。它们是可视化阶段，不要求每颗粒子都经过同一条声学支路；早期与晚期粒子组可以共享同一次输入事件。PreDelay 期间允许显示短促的声源提示，但混响粒子尚未出现。

Decay 对应衰减尺度。RT60 指衰减约 60 dB 所需的时间，不是到点突然截断。因此粒子逐渐变暗，在可见阈值附近自然退出；以固定的感知亮度曲线保留尾音层次。个体寿命可略有差异，但同频段整体衰减包络必须受约束，不能靠随机寿命编造尾音。

更改 Decay 或阻尼时，已有粒子从当前能量继续改变衰减速率，不重置年龄，也不让已消失的粒子复活。参数影响按其声学位置发生：预延迟主要影响新输入的传播，反馈阻尼影响后续衰退，输出 EQ 会影响当前存量湿声的可见权重。

## 参数映射

| 参数 | 主视觉职责 | 必须保持的语义 |
| --- | --- | --- |
| 输入电平 | 生成率和能量权重 | 瞬态成簇，持续音连续生成；固定动态范围映射，避免逐帧自动归一化掩盖大小声差异 |
| Decay | 整体留存和消隐时间 | 尾音更久，不等于空间更大或运动更慢 |
| PreDelay | 输入与湿声诞生的时间间隔 | 保持真实毫秒时序，不为明显而夸张拉长 |
| Size | 空间尺度与传播跨度 | 固定镜头下范围变化；与 Decay 分工明确 |
| Attack | 前方早期存在感和后方建立过程 | 增大时前方减弱、后方更迟更舒展，不能只把全部粒子减速 |
| Early | 初生阶段的散射程度 | 低值有清楚的反射簇，高值较早形成均匀颗粒场；0% 不表示没有早反射 |
| Late | 尾部的混合、疏密和路径均匀度 | 低值保留重复/成簇结构，高值弥散；0% 不表示没有尾音；扩散本身不凭空增加总可见能量 |
| HighFreq | 高频寿命变化的起始频段 | 改变哪部分颜色开始更快衰退，不等同于移除其最初出现 |
| HighShelf | 高频衰退强度 | 高频颜色更快消退，保留不同引擎自己的衰减关系 |
| BassFreq | 低频寿命变化的范围 | 决定哪些暖色粒子受 BassMult 影响 |
| BassMult | 低频相对留存时间 | 暖色可更久存在，不应仅变大或变亮；考虑各引擎内置低频吸收 |
| Mod Rate | 晚期尘埃局部漂移的变化速度 | 平滑随机场的时间连续，不逐帧随机或让整场周期摆动 |
| Mod Depth | 晚期尘埃局部漂移的偏移幅度 | 与 Rate 分开；Depth 为 0 时局部调制位移消失，缓慢弥散仍可继续 |
| LowCut / HighCut | 对应频段的当前可见权重 | 根据真实输出 EQ 反映颜色减少或变暗，不伪装成只修改寿命 |
| Mix | 控制实际试听的干湿比例及混响、叠加视图的尘埃强度 | 中央输入参考保持独立；两个含混响的视图统一跟随 MIX，只淡化尘埃，不缩小空间或缩短寿命 |
| 左右能量与相关性 | 保留实际音频统计，相关性轻微影响两侧展开 | 按第二次反馈保持整体中心稳定，不把左右统计转成声场横移 |

颜色属于频率，数量/权重属于能量，寿命属于衰减，几何属于传播，摆动属于调制。同一参数可以连带影响多个视觉量，但应有一项清楚的主职责。

## 四类八模式的视觉身份

共享同一频率色谱和相机基准，类型差异主要来自传播和空间形态。下列是视觉隐喻，不是物理重建。

| 类型 | 共同身份 | 两个模式的区别 |
| --- | --- | --- |
| Hall | 有纵深、向后展开的体积粒子场 | Concert Hall 连续而宽展；Cathedral 纵深和上方展开更充分，建立更迟 |
| Plate | 薄而有厚度的横向粒子膜，传播较迅速 | Modern Silk 连贯细密；Classic Steel 保留较清楚的颗粒簇与传播纹理 |
| Room | 紧凑、有明确方向和边界暗示的反射群 | Studio Room 收紧、贴近；Live Room 路径跨度更大、轮廓更鲜明 |
| Chamber | 有包裹感、多次折返的粒子体积 | Velvet Chamber 融合柔和；Stone Chamber 保留更清楚的反射层次 |

## 声音和操作边界

- 静音且尾声消失后停止生成，保留暗淡的空间轮廓即可；不靠虚构信号维持热闹画面。
- 切换类别/模式沿用实际音频切换时序，旧群退出、新群建立；不能让数秒的旧画面冒充已经结束的旧尾音。
- 停止播放、宿主暂停处理、跳转、旁路和重开窗口分别定义时钟/清空策略，禁止恢复窗口时喷出积压粒子。
- 绘制数量和发光强度均有上限，密度提高时可合并显示权重；不能让长 Decay 和持续输入导致粒子数量无限增长。
- 音频线程只写入固定容量的数据队列，不等待图形线程，不在其中运行粒子仿真或渲染；界面关闭时停绘，重新打开只追上当前状态。
- 频谱与左右指标读取实际音频；空间传播、个体性格和寿命模型是经过校准的表达，不宣称逐粒子声学真值。

## 原型顺序和验收

第一阶段只实现 Concert Hall 的中央粒子体验，配最少的临时调试控件。先用单次脉冲确认输入、预延迟、生成、扩散和消隐；再使用不同频段的短音核对颜色、阻尼和低频寿命；最后加入真实人声、钢琴、军鼓。

按“一段素材、一次改变一个参数”核对：Decay 与 Size 可区分，Attack 与 Late 可区分，阻尼与输出 EQ 可区分，Mod Rate 与 Depth 可区分。20 ms 等短变化在常规帧率下不强求夸张可见，调试时可用标注为慢放的视图检查时序。

第二阶段建立四类八模式的传播规则，验证同参数下的视觉身份；第三阶段进入插件性能评估和嵌入，最后再做其余产品组件。预设旧项目、输出音频和自动化行为必须与冻结音频基线回归核对。

原型的核心成功标准：同一段人声停下后，能看见高频颜色先退去，较长频段继续留存；提高 Attack 能看到后方空间逐渐展开；提高 Late 能看到尾部从成簇到连续，而不是所有旋钮都让画面变得更大、更亮。
