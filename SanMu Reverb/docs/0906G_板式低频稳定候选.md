# 0906G／Plate P2：低频稳定候选

用户反馈 Plate P1 的低频、中低频震荡还需要稳定、松弛一些。本候选保留 P1 的扩散、立体声和高频性格，只修改低频进入反馈网络的方式与传播损耗。

## 修改

1. 输入端高通从 12 Hz 调到 55 Hz，减少深低频进入板式反馈网络。
2. 每个传播段加入温和的 260 Hz 以下频率损耗，约束中低频持续循环；不使用压缩、限幅或随输入电平变化的处理。
3. 高频和 700 Hz 以上变化极小，没有用提亮补偿低频。

EMT 140 的输入端确实存在低频削减。UA 官方手册记录：原 EMT 线路是约 80 Hz 的 -4／-10／-16 dB 削减，Martech 改装是 90～360 Hz 的低频搁架。P2 只借鉴“进入反馈前先管理低频”的结构方向，没有复制其档位或宣称硬件复刻。

## 客观结果

固定 P1 参数、100%湿声、同一脉冲和同一初始化时间线：

- 40～100 Hz 能量约降低 2.88 dB，尾声寿命缩短约 16.4%。
- 100～200 Hz 能量约降低 1.18 dB，尾声寿命缩短约 14.1%。
- 200～350 Hz 能量约降低 0.61 dB，尾声寿命缩短约 9.3%。
- 350～700 Hz 能量约降低 0.25 dB，尾声寿命缩短约 4.4%。
- 700～2800 Hz 能量变化小于 0.08 dB。

160 Hz、250 Hz 短音停止后的局部回升会更快收下去；P2 没有改变混响密度、宽度或高频明亮度的设计目标。

## 试听

完整重启 REAPER 后选择 PLATE。预设为：

- `板式 · P2 基准`
- `板式 · P2 温暖人声`
- `板式 · P2 军鼓短板`

先用人声的纯湿声听 100～350 Hz 是否更松弛，再用军鼓听鼓身是否仍然温暖、尾音是否不再嗡住。对比其他混响时先匹配湿声响度。P2 是低频稳定候选，仍需真实素材听审。

## 验证

五组 CTest、Plate 专项合同、真实编辑器预设回读、真实 VST3 与离线 DSP 对照均通过。Hall、Room、Chamber 与 Hall 预设的保留检查继续逐样本一致。P1 回退包为 `candidates/0906F/`，Hall 定稿回退包为 `releases/0906E_Hall/`。
