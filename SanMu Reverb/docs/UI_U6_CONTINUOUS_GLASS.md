# 混响界面 U6 · 声场融入玻璃面板

> 后续确认：用户认为深色版基本可以定稿，深色保持本版。浅色继续调整，当前方案见 [U7 记录](UI_U7_LIGHT_GLASS.md)。深色对应的文件备份在 `audit/2026-09-09/ui-u6-dark-approved/`。

2026-09-09。用户认为 U5 的粒子清晰度明显改善，但独立深色矩形破坏整体协调，尤其是浅色主题。当前浏览器候选仍位于 `http://127.0.0.1:5173/studio.html`。

## 设计选择

去除声场的独立边框、圆角与内阴影，保持声场面积、控件位置和已认可的旋钮。状态、视图选择、电平和图例沿用所在主题的玻璃配色。

深色主题继续使用发光叠加，中央通过逐渐消隐的深色底色保护粒子对比，边缘自然回到主面板；浅色主题保留亮底，中央只有轻微的灰紫色调。

浅色可见度由粒子自身的显色方式解决。原先发光叠加只能继续提亮像素，在亮底上容易失去差异；现在将相同的频段色彩映射为更深的粉、紫、青，通过透明覆盖显色。原声短细丝使用带少量频段色彩的银灰色，维持中央输入与外围混响的区分。两套主题的材质明暗不同，频段对应、形态和动态逻辑相同。

## 实现边界

`LifeScene.setAppearance` 增加可选的 `pigment` 显色开关，默认关闭，因此原中央页面继续使用既有显示路径。浅色完整界面开启该开关，将湿声与原声材质切换为普通透明合成；深色继续加法合成。浅色湿声显示系数为 2，深色维持 1.4，颜色饱和度均为 1.4。这些系数仅适配背景的显示对比，不是音频增益。

没有写入粒子位置、颜色数组、出生时间或透明度数组。四类混响内核、音频模块、粒子模拟、干湿视图与 MIX 曲线均保持现有逻辑。中英文、默认英文、设置与提示规则保持 U5。

## 核对结果

- `test:glass` 通过：十二组双主题布局、实际背景文字对比、粒子可见度、主题切换状态保持和 MIX 检查。样本中文字最低对比度深色约 7.69、浅色约 5.34。
- 在同一冻结声场下，逐一测试浅／深主题的混响、叠加视图，MIX 为 100→25→0→100。截图分别与隐藏湿声粒子的同帧相减，确认显示强度随 MIX 下降，0 时湿声像素差为零，恢复 100 后返回相同声场。全过程参数（除 MIX）、粒子出生、位置、颜色、透明度及原声透明度数组不变。
- `test:views` 通过，原中央页面的三视图、输入参考、MIX 联动与尾音留存仍正常。
