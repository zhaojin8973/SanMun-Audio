# 0908B 预设整理与四类终审

日期：2026-09-08

## 当前结论

四类混响的声音以用户真实钢琴、弦乐、人声和军鼓听审结果为准，当前版本保留四类独立引擎：Plate、Room、Hall、Chamber。每类菜单保留两个可见风格：Modern Silk / Classic Steel、Studio Room / Live Room、Concert Hall / Cathedral、Velvet Chamber / Stone Chamber。

## 预设整理

工厂菜单从历史混合列表整理为 23 项正式预设，按类别和风格连续分组：Plate 4、Room 4、Hall 9、Chamber 6。旧版本、实验版本和未重新听审的历史预设不再进入菜单，仍保存在 candidates/ 和 releases/ 归档中，便于回退和追溯。Concert Hall 的版本号、首稿等内部开发标签已从界面名称和说明中移除；标准基准是当前认可声音的名称。

用户预设仍从用户目录读取，保存时重名另存，不覆盖既有文件；加载前检查完整参数、范围和数值有效性，损坏文件不会部分改写当前状态。宿主 Program 数量仍为 1，工厂菜单序号不会改变宿主工程保存的参数；旧 Plate 状态按兼容标记迁移到当前两种风格。

23 项正式预设逐项与 0908A 菜单数据及真实 VST3 对照：参数来源一一匹配，100% 湿声最大样本差为 0，旧宿主状态恢复后的输出也一致。Hall 的 9 项正式预设是在当前 Hall 声场上设计的参数组合；本轮只把“0906D 基准”改名为“标准基准”，没有改参数。

## 最终机器检查

- CTest 8/8 通过：四类回归、Hall、Room、Chamber、Cathedral、Plate、Steel 和预设保存恢复。
- Room 2.5 秒附近的早期滤波改为 2.3～2.8 秒平滑过渡；专项检查最大相对样本差 0.0000299，0 项失败。
- 播放切换覆盖四类八模式、48/96 kHz、32/128/512 采样块；没有超时。七次模式切换最大边界样本差 0.0061，模拟界面分两步写入类别和模式的最大边界差 0.00094，未重现此前偶发噗声。
- 真实 VST3 与离线 DSP 最大样本差 1.96e-8；Mix=0 干声误差为 0，Mix 路由、状态往返和 12 项 Chamber 预设检查通过。插件签名校验通过。

这些是机器和结构检查，不能替代用户在 Pro Tools 中用真实工程再次试听。0908B 已安装到本机 AAX 与 VST3 目录，安装二进制与候选包哈希一致。当前 Pro Tools 进程没有重启，需完整退出并重开一次，才会读取新 AAX。

AAX 的 PACE 与 Apple 严格验证均通过。沿用本机开发签名配置，PACE 产品元数据仍显示 SanMu EQ6；插件自身身份为 SanMu Reverb / SMRV。因此当前包适合本机开发试听，商业发行前仍需建立独立的 SanMu Reverb 签名产品配置。

## 仍需留意

尚未能在自动化中复现用户曾报告的偶发“啪啪噗噗”杂音，因此没有声称其已被彻底修复。当前切换使用双引擎 50 ms 等功率交叉淡化，处理线程无运行期内存分配；若重启宿主后仍出现杂音，应记录采样率、缓冲区、发生时的参数和切换路径，再做针对性复现。
