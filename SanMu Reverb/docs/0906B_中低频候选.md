## 本轮反馈与范围

用户希望中低频温暖但不浑浊，指出150～200 Hz略有浑浊，随后明确：

> 我是在人声上做的测试，在mix100%的情况下对比Supernova、VintageVerb感受到的。

本轮聚焦纯湿人声尾音的音色。当前没有取得用户实际使用的人声文件，因此不能声称已在该人声上复现或解决浑浊。合成固定音高、宽带噪声、脉冲与谐波短句只用于验证候选的作用范围，最终复听仍用原人声。

## 先测量，再选择改动

同一参数、48 kHz、100%湿声、静音预热一秒的现有输出显示：0906A 在150～200 Hz的频带能量略突出，但归一化衰减并不比参考更慢。该频带 T20 外推时间为0906A约5.47秒、VintageVerb约7.08秒。它是频带测量，不等同旋钮标称时间，也不能独自判断浑浊。

新增80～600 Hz的16个固定音高测试，每次新实例，分别前置1秒、2.7秒静音。0906A在某些音高的响应较明显，例如150 Hz停音后100～800 ms的电平约比参考高5.9 dB，但180 Hz等位置并不呈现同样趋势。这支持先小幅处理局部能量，尚不足以证明用户所听问题的完整机制。

与参考比较必须同时考虑整体电平：宽带噪声下0906A整体约高2 dB，不能把某频带的全部原始差值当成需要削减的幅度。原始分析位于 `audit/2026-09-06/hall_lowmid/`。

## 候选改动

在 Hall 的两个晚期读出通道各加入相同的固定钟形均衡（中心最深、两侧平滑恢复）：中心175 Hz、Q=1.35、最大削减1.0 dB。滤波器采用 [W3C 收录的 RBJ 钟形均衡系数公式](https://www.w3.org/TR/audio-eq-cookbook/)，系数及状态使用双精度。

滤波位置在反馈场之后、早晚反射混合之前。早期反射支路保持0906A原样；反馈矩阵、扩散结构、Attack映射、BassMult、Decay、调制和原输出 EQ 均保留。本候选对晚期能量作小幅音色校准，不具备识别某个共振峰再动态抑制的机制，不能记为“共振问题已解决”。

初次试验为1.25 dB，最终收敛到1.0 dB，降低对厚度与整体电平的影响。`trial125_*` 保留中间输出，该中间版本未安装。

## 0906A 与候选的实测变化

在固定参考参数的脉冲响应中，对输入后300～3000 ms积分：

| 频带 | 0906B相对0906A |
| --- | ---: |
| 70～110 Hz | -0.23 dB |
| 150～200 Hz | -0.94 dB |
| 250～400 Hz | -0.28 dB |
| 500～1000 Hz | -0.04 dB |

150～200 Hz的频带衰减外推均约5.47秒，曲线基本重合。固定音高测试中，150／175附近／200 Hz的晚期电平降低约0.85～1.0 dB。钟形曲线有平滑过渡，因此125 Hz、250 Hz附近仍有约半分贝影响，并非只作用于150～200 Hz边界内。

同一脉冲的前40 ms输出与0906A逐采样相同；脉冲和宽带噪声的总电平变化约-0.05 dB、能量中位时刻移动不到1.5 ms，晚期密度和左右相关变化很小。固定和弦电平变化约-0.26 dB，能量中位时刻约前移9.4 ms；不同音高权重变化会移动和弦能量分布，不能把它直接解释为增加或减少传播延迟。

合成谐波短句的整体湿声 RMS（均方根电平）降低约0.32 dB，匹配文件补回此差值，用于区分“稍轻”和“稍清晰”。这不是用户的人声录音，也不代表任意人声的等响结果。
