# 混响界面 U2 · 玻璃材质候选

> 历史版本。用户进一步澄清只参考原系列面板主题，其配色、字体、按钮仍需重新设计。当前候选见 [U3 记录](UI_U3_GLASS_DETAILS.md)。

2026-09-09。用户非常喜欢 U1 旋钮与专业排版，希望将这些优点结合原系列的玻璃拟态及深浅主题。此版仍待用户确认。

预览：`http://127.0.0.1:5173/studio.html`。

## 本次修改

- 一整块半透明磨砂面板，薄边缘反光、柔和投影和内缘折射感。背景为静止的薄荷、天蓝氛围光，通过面板连续透出。
- 浅色为米白玻璃；深色为烟色玻璃。两套主题独立设置文字、控件、输入框、电平与反光颜色。
- 降低分隔线的存在感，移除中央独立黑色底板和底栏实体色块。声场、电平及旋钮处于同一块玻璃表面。
- 保留 U1 的旋钮尺寸、270 度轨道、短指针、刻度、外置数值和交互，仅调整盘面透光与边缘反光。
- 预设选择框和弹窗使用同一套材质，优先保证小字号可读。

## 声场合成

`LifeScene` 增加可选的透明画布初始化参数，仅完整界面启用。原中央页面默认仍为原暗底。粒子运动、寿命、位置、音频分析、频段颜色数据及 MIX 规则均未修改。

深色以发光方式合成；浅色对画布做亮暗反转与色相补偿，以暗色细丝和有色尘埃在亮底保持可见。这个变化属于主题显色，不把它声称为与原暗底逐像素一致。切换主题不会重建声场，也不会修改声音参数。

## 验证

`npm run test:glass` 固定同一音频时刻，检查切换材质前后参数和粒子数组完全相同；比较有信号／隐藏信号后的合成截图，避免用浅色背景误判粒子可见。另测量实际玻璃底色与主要标签的对比度，并检查深浅两套主题在六种尺寸下的溢出和碰撞。

报告及截图：`prototypes/particle-life/test-results/glass/`。原声场回归：`npm run test:views`。本轮不修改音频算法或其他三个插件；U1 材质备份在 `audit/2026-09-09/ui-u1-before/`。
