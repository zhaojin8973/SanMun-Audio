## 目标

让用户先判断“是什么空间、离多远、尾音多长”，再处理颜色和细节。当前暗色基础、青色强调和 980×580 画布可以保留，下一版先改善层级，不改变 DSP 和参数含义。

## 页面结构

1. 顶栏：品牌、预设浏览器、上一项/下一项、保存；预设列表按四类和八种风格分组，显示用途说明和 Mix 类型。当前工厂预设既有纯湿基准，也有插入比例，浏览器必须明确显示 `100% WET` 或 `INSERT`，避免切换时把音量差误判为算法差。
2. 类型栏：Plate、Room、Hall、Chamber 四个主入口；类型内只显示两个风格，当前状态同时由文字、边框和选中底色表达，不能只依赖颜色。
3. 空间主区：以 Decay、PreDelay、Size、Attack、Mix 为核心控制，配合简洁的建立时间和尾音能量可视化。可视化是辅助判断，不宣称声学测量结果。
4. 细节区：Damping、Early/Late、Modulation、Output EQ 分组。默认折叠或降低视觉权重，保证 15 个参数仍可访问。
5. 右侧电平：输入和输出电平表保持窄而清晰，增加削波保持时间和可见峰值数值。

## 交互规则

旋钮双击恢复默认，拖动、滚轮和修饰键微调遵循同一灵敏度；支持直接键入带单位数值。预设加载、类别切换和模式切换都必须一次性更新界面状态，并保留当前宿主自动化通知。参数改变后显示“已修改”，保存后恢复预设名称。

窗口从固定尺寸改为受控缩放，至少支持 75%、100%、125%、150%、200% 五档；布局使用最小尺寸约束，不能让标签或数值被裁切。键盘焦点顺序按顶栏、类型、主参数、细节参数排列，焦点环和文字对比度保持可见。

## 实施顺序

先用单个 Concert Hall 模式完成三维生命粒子原型，确认音频、参数和视觉的映射；再扩展到四类八模式，验证性能和插件嵌入。中央体验确定后，再设计顶栏、类型栏、参数区和电平表，并补齐预设浏览、缩放、A/B 与撤销历史。A/B 与撤销需要状态快照设计，不能只添加按钮。

## 视觉边界

外围控件保持克制、可读；中央场景的颜色和运动由频谱、声音和粒子传播规则决定，不再限制为单一青色。粒子场作为主体验自由展开，不装入额外的装饰卡片。场景与参数控件保留独立可读区域。
