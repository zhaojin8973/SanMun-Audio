# 混响界面 U4 · 彩色胶囊与玻璃叠层

2026-09-09，当前视觉候选。完整界面入口：`http://127.0.0.1:5173/studio.html`。

用户认可 U3 的字体、旋钮、排版与主面板。本轮只借鉴 Comp 顶部玻璃叠层及系列胶囊的功能配色，增加层次；其他旧版控件不作为设计依据。Logo 不再作为重点，也不阻碍本轮交付。

## 当前设计

- 主面板保持柔白／烟灰玻璃，顶部独立一块圆润玻璃控制板，借助薄反光与下投影区分高度。
- 大厅、板式、房间、回声室胶囊分别使用薄荷、香槟、冰蓝、藕紫。未选中时保留淡色，选中时加强底色、边缘与文字；风格按钮沿用所属类型色。预设区用淡紫，A/B 分别用蓝／紫粉，旁通激活使用红色。
- 字体、十五个旋钮的绘制与交互、主要参数分组保持 U3。
- 品牌显示为 SanMu Audio Reverb，附临时的三道声纹标记。标记未定稿；生成原图与候选在 `audit/2026-09-09/ui-u4-brand/`，界面透明资源为 `prototypes/particle-life/public/brand/sanmu-mark.png`。

## 共用辅助功能

右上角明确显示 BYP 与齿轮设置。设置提供浅深主题、85%／100%／115%／125%／150% 界面缩放、恢复 100%、悬停提示开关、操作帮助与关于。所有项目均可操作，偏好保存在当前浏览器本地；窄窗口限制无法容纳的放大档位。

这里的窗口操作调整浏览器原型内的界面大小，尚未接入宿主插件窗口。弹窗与提示独立于缩放容器，防止位置偏移或帮助文字随窗口缩得过小。帮助覆盖旋钮、键盘、预设、A/B、BYP、干湿视图和电平。

## 验证与范围

`npm run test:glass` 检查双主题、十二种窗口布局、信号显示和 MIX；`npm run test:settings` 检查十九组窗口／缩放组合、参数与粒子状态保持、设置持久化、帮助弹窗和 BYP。截图与报告分别在 `test-results/glass/`、`test-results/settings/`。构建时核对声音模块源码校验值。

另逐项测量双主题四类胶囊的实际背景与文字对比度，八组均达到 4.5。十五个旋钮透明画布在两套主题下均与 U3 逐像素一致；59 个既有源码与音频文件核对中，仅完整界面样式和交互入口改变。

本轮不修改四类混响声音内核、中央粒子模拟或另外三个插件。U3 备份位于 `audit/2026-09-09/ui-u3-before/`。视觉仍需用户确认，未安装或替换宿主插件界面。
