# 0907D · Room 默认早期反射柔化候选

0907C 的 Room 结构和预设已经得到用户认可。本候选只处理一个反馈：新插入插件、直接切换到 Room 的共同默认参数下，几何早期反射略有金属边缘。

测量显示问题集中在早期反射层：旧版默认脉冲的早期路径没有独立频率损耗，离散反射峰比短 Room 预设更明显。0907D 在 `Decay > 2.5 s` 时给早期反射增加轻度高频空气吸收，并保持晚期十六路反馈、几何路径、Room 两种风格、控制映射和四个预设不变。短尾 Room 预设仍使用原有反射轮廓。

这不是全局高切，也不是把 Room 变暗；只是早期反射的轻微频率相关柔化。默认共同参数的早期能量占比由约42.7%降至约38.3%，左右相关和结构仍在契约范围内。它是听感候选，机器测量不能代替用户复听。

验证：7组CTest全部通过；Room真实VST3路由、EARLY/LATE/Attack控制、四种采样率、单声道、极端参数、Hall/Plate/Chamber保留及31个非Room历史预设检查全部通过。二进制安装后须重启REAPER再听。

试听建议：直接新建实例切换 ROOM，先听 Studio Room 和 Live Room 的共同默认；再加载“录音室 · 自然基准”和“现场房间 · 开阔基准”确认预设轮廓没有被削弱。若默认金属边缘下降但空间仍自然，保留0907D；若变暗或失去反射轮廓，回退0907C。
