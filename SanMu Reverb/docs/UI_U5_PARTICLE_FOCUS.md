# 混响界面 U5 · 以粒子为中心的双语玻璃面板

> 历史候选。用户认可本版粒子清晰度，但认为深色声场与浅色面板不协调；当前方案见 [U6 记录](UI_U6_CONTINUOUS_GLASS.md)。

2026-09-09。用户要求取消标志，提供中英文并默认英文，以已认可的生命粒子作为整个界面的视觉重点。当前入口仍为 `http://127.0.0.1:5173/studio.html`；这次更新是浏览器原型，尚未替换宿主插件界面。

## 视觉调整

保留用户认可的字体、旋钮绘制、参数分组、顶部玻璃叠层和各类胶囊色彩。品牌仅使用 SanMu Audio Reverb 文字，顶部与关于窗口均移除临时标志。

中央声场扩展为一层深蓝黑透明玻璃，常规桌面高度由 320 增至 380 像素。浅色主题保留柔白外面板，深色主题减弱灰白反光；两套主题都用同样的深色声场衬托粒子，避免同一段声音在浅色面板下被冲淡。

移除浅色声场的反相／色相旋转合成。湿声绘制的显示亮度和饱和度系数均为 1.4，中心白色高光系数由 0.1 减为 0.025；保留粉、紫、青的频段对应。原声短细丝保持原有珠光色，便于区分输入与混响。这些是显示映射，不写入粒子的模拟数据或音频增益。

共享绘制器新增可选外观参数，默认值等同于之前的中央页面。`src/life.js`、`src/dry-field.js`、音频模块与四类 C++ 引擎保持原样。出生、生命周期、漂移、扩散形态和 MIX 规则继续使用已定稿逻辑。

## 语言与提示

- 首次打开默认英文，齿轮设置中可切换 English／中文，选择保存在当前浏览器。界面、八种风格、23 个工厂预设的显示名称、帮助、数值单位、提示与可访问名称均适配两种语言。
- 悬停提示独立提供跟随界面、中文、英文、关闭四项。例如英文面板可以显示中文提示。
- 工厂预设只翻译显示名称；用户命名、本地音频文件名、预设标识与参数数据不翻译。搜索支持中英文工厂名称。
- 切换语言不重建声场、旋钮或音频。已有用户预设与原有提示关闭偏好兼容保留。
