# 2026-10 限时内测实现

BetaAccess.h 与 BetaNotice.h 是四产品当前一致的实现副本，存放在各产品 source 目录以保持项目独立可构建。后续修改应同步四个副本并重跑 tests/test_beta_processor.cpp；EQ 另含 tests/test_beta.cpp 的时钟边界和音频门控测试。

期限常量为 1793462400000 毫秒，表示北京时间 2026-11-01 00:00。没有环境变量或网页参数可以更改期限。处理器构造函数的可选记录文件参数仅用于 C++ 自动测试的隔离存储；发行格式工厂均使用默认构造，实际宿主没有此设置入口。日期本身始终固定。

Access 在后台每秒检查一次绝对时钟，以单调计时补充本次会话时间；每分钟通过跨进程锁保存较大的历史时间。允许十分钟校时误差；超过误差的回拨、无效记录或存储错误进入原声直通。记录位于 JUCE 用户应用数据目录下 SanMu Audio/Beta/2026-10.clock，不写入工程或预设。不依赖编辑器计时器。

AudioGate 在 prepare 阶段分配缓冲，音频回调只使用已分配内存与原子访问结果。期限前保留原始 DSP 输出，到期期间用 50ms 渐变转为干声。稳定到期后跳过效果处理。EQ 按极限线性相位最大延迟、Comp 按平滑模式延迟预分配原声缓冲，以保持宿主延迟补偿一致。Delay/Reverb 使用零处理延迟。异常大于预分配尺寸的宿主块安全退回原声直通。

期限提示条是独立原生组件，包含日期、临近到期、已到期、时间异常和存储异常状态。Reverb 额外增加 28px 窗口高度，保存的 height 仍表示网页内容高度，兼容原有偏好与工程状态。

离线日期和本地记录无法阻止有意修改程序、删除记录或控制系统时钟的人，也不能远程撤销先前发行的不限时二进制。未来商业授权应作为独立工程设计。

验证日志位于 internal-audit-20260929-beta。四个版本分别为 EQ 0.1.3、Comp 0.1.15、Delay 0.1.3、Reverb 1.0.2。本批次没有覆盖系统插件安装目录。
