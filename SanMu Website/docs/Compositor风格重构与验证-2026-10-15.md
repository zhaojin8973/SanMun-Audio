# SanMu Audio：Compositor 参考重构与验证

日期：2026-10-15。
参考网站：https://robbietilton.com/compositor。
静态逆向细节见同目录《Compositor参考站静态逆向与音频映射-2026-10-15.md》。

## 本轮范围

- 重写首页、四款双语产品详情、公共导航、页脚与全局样式。
- 下载和工作室双语页面采用同一白底版式；支持、版本、隐私、更新页同步使用公共样式。
- 全局样式改为单一白色基础，移除旧深色、杂志式与展台多层覆盖。
- 首页大标题、黑白胶囊按钮和大幅产品主视觉对应参考站的结构。
- 显示器外形由 HTML/CSS 绘制，画面仅用自己的真实插件截图，不重绘控件、曲线或参数。
- 首页提供 EQ6 / Comp / Delay / Reverb 及浅深主题切换；没有默认自动旋转或快速闪烁。
- 下半页为半幅实录图库和工作室、功能说明；产品入口与资料仍可直接访问。
- 原有纸盒包装图和 ProductDeck 不再用于页面主视觉，素材文件保留。
- 导航改为明确按钮打开，支持 Escape、离焦和点击外部关闭；手机菜单可选所有产品。
- 主体使用 Inter 与系统中文字体，品牌继续采用 Avenir Next 的两行 SanMu / Audio 字标。
- favicon、苹果触摸图标与分享图已移除旧三竖条设计。
- 页面说明个人工作室协同 AI 开发，未宣称开源或确定收费安排。
- 下载与反馈降级提示改为用户可理解的语言，不向公开流程展示 Supabase 或对象存储细节。

## 数据与功能边界

- 保持原有双语路由、产品 slug、留言组件、注册下载组件和后端契约。
- 当前发布数据仍为 internal-beta-20261006-catalina-ui-fix3，内测截止 2026-10-31 23:59（Asia/Shanghai）。
- 手册、EULA 与产品说明链接均指向现有最新批次文件。
- 未连接生产 Supabase，注册与安装包下载仍未开放。本轮没有执行数据库迁移、上传包、创建用户或发布网站。
- 产品截图来自已整理的 music-capture 目录，EQ 轨道名继续隐藏。
- UI 重构与插件宿主验收是不同范围，本轮没有新增宿主兼容承诺。
