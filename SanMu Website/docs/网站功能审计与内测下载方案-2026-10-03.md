# SanMu Audio 网站功能审计与内测下载方案

## 已具备

- 四款插件双语产品页与真实音乐播放响应图。
- 统一的 SanMu Audio 两行字标和浅色编辑式布局。
- 产品说明、用户手册、EULA、版本清单、校验值和签名记录页面。
- Supabase 评论、注册、登录和管理员审核的基础结构。

## 本轮补齐

- 导航增加下载中心，移动菜单也能进入下载中心。
- 新增 `/zh/downloads` 与 `/en/downloads`，包含注册、登录、退出和按平台查看内测包的入口。
- 注册表单在注册模式下要求勾选内测 EULA，并链接到发布资料页。
- 安装包不放在静态 `public` 目录，改由 Supabase 私有 Storage 保存；下载时生成短时签名 URL。
- 新增 `beta_artifacts` 发布清单表和 `beta-downloads` 私有 bucket 的 RLS 契约。
- 首页增加真实界面 3D 旋转展台：只旋转实际产品包装图，不重绘插件 UI，也不把装饰性 3D 当成产品功能。

## 上线前仍需完成

1. 在 Supabase 执行 `0003_beta_downloads.sql`，创建 private bucket 并登记真实对象路径。
2. 把四个 macOS `.pkg` 上传到 `beta-downloads/internal-beta-20261002/macos/`，校对 SHA-256 后将记录设为 `ready`。
3. 当前工作区没有可核验的 Windows 二进制压缩包、签名或宿主验证记录；拿到 Windows 包后再登记 `Windows` 记录。
4. 在 Supabase Auth 中确认站点域名和重定向地址，生产环境关闭本地占位 URL。
5. 用一个普通注册用户和一个无权限用户各跑一次登录、签名 URL、过期链接和退出流程。

## 设计判断

3D 展示适合作为首页第二屏的“产品界面展台”，用于比较四款产品；不适合替代真实界面图、功能说明、版本记录或下载入口。所有展台图片仍来自真实音乐播放中的插件界面与包装素材。
