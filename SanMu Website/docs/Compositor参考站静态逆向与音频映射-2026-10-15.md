## 2. 页面结构

页面由五个区域构成：轻量顶部导航、居中标题与两个按钮、大幅产品主视觉、左右各占 50% 的图库/产品说明区、底部品牌与重复行动按钮。

公开 HTML 中没有 3D、WebGL、滚动视差或大型前端框架入口。其呈现方式依赖比例、留白、真实产品图，以及少量 CSS 动效。视觉重点来自主视觉占据的大面积，而不是组件数量。

## 4. 响应式机制

`1100px` 以下，标题缩至 `60px / 64px`，副标题 `24px`，说明区内边距变为 `60px 40px 50px 50px`。

`768px` 以下，导航左右内边距 `20px`，主标题顶部留白 `60px`；按钮移到主视觉之后，变为纵向排列，高 `45px`、宽 `190px`。图文区上下排列，图库占满宽度，说明区内边距约 `42px 32px 40px 29px`。

原站手机主视觉使用 `190.5%` 图片宽度、`left: -44.25%`、`top: -9.5%`，配合容器 `padding-bottom: 78.3%` 做特定裁切。这些数值与原站自己的主视觉强绑定，不能直接用于 SanMu 图；否则会再次出现用户指出的产品变形、裁断问题。

SanMu 应按实际图像尺寸建立单独手机构图：优先一款完整界面或清楚的四款缩略组合，保持纵横比。桌面到手机的重排可以复刻，图片偏移不能机械复刻。

## 5. 交互与动画

| 机制 | 静态所见 | 音频改造判断 |
| --- | --- | --- |
| 普通按钮悬停 | `scale(1.03)`；过渡 `0.15s` | 可以保留，但键盘聚焦也应提供清楚反馈 |
| 主按钮背景闪图 | `0.64s`、`step-end`、无限循环；8 个切换帧；只在支持悬停且用户未要求减少动画时启用 | 不建议复刻快速闪烁。用插件识别色轻微变化或静态波形更稳定 |
| 手机图库 | 原图加重复图组成轨道；`48s linear infinite`；从 0 平移到 `-50%` | 如保留，必须增加暂停机制及减少动画适配；不缩放插件 UI、不冒充实时音频处理 |
| 桌面图库适配 | 比较 3 张/4 张图片的裁切成本，选择相对更少的一组 | 若 SanMu 用固定四款介绍，优先自然比例和固定分区，避免过度裁切 |
| 最新版本日期 | `fetch` GitHub 最新 release；失败保留 HTML 默认日期 | 使用自身已确认的版本清单；不照搬原仓库接口 |
| 点击统计 | 下载与 GitHub 按钮调用 `gtag`，`beacon` 传输 | 当前任务不需要复制原站统计标识；若后续接入，使用自身统计配置 |

桌面图库的计算是：原图比例固定为 `1456 / 816`；以图库宽度推导自然图高；分别比较每张分配 `h / 3` 或 `h / 4` 与自然图高的对数差绝对值，再决定是否加上 `three` 类。这属于垂直堆叠图库适配，不是 3D 展台。

原站减少动画偏好仅覆盖按钮闪图，手机图库没有相同保护。重建时应补全 `prefers-reduced-motion`（用户减少动态效果的系统偏好），让所有循环动画都停下，并提供可操作的暂停按钮。

## 7. 实现与验收约束

1. 以新主页独立样式实现排版，不把原站完整 HTML、CSS 或 JavaScript 搬进发布目录。
2. 不复制原站照片、图标、商标、产品名称、文案、下载地址、统计标识。
3. 保留 SanMu Audio 现有文字字标，无三竖条图形。
4. 全部产品图使用真实比例；桌面与手机都检查边缘、旋钮、字体无拉伸。
5. 现有中英文产品资料、下载中心、登录、手册、EULA、版本信息继续可达。
6. 不宣称未核实的开源、永久免费、Windows 已验证或商业发布状态。
7. 浏览器验收与静态分析分开记录：本报告只完成参考页静态结构调查，重建页面仍须进行实际浏览器验证。
