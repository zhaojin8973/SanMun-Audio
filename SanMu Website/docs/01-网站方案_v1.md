## 2. 你提的三个问题的回答

### 2.1 以后能不能支持卖授权？
**能，且方案已预留。** 现在是"试用下载 + 暂不收费"，将来接支付时有三条路，从轻到重：

1. **轻量授权码**（推荐起点）：Stripe / PayPal 收款 → Supabase 生成授权码 → 邮件发码 → 插件内激活输入 → 在线校验（离线 fallback）。开发量小，配合你"回本即可"的定价完全够用。
2. **平台代管**：Gumroad / Lemon Squeezy 自带授权码系统与税务代缴，最省心，抽成约 5%。
3. **商业级**：iLok / PACE 授权（SanMu 发布链路里已有评估），防破解最强，但成本高、用户体验重，¥19 的定价下不划算。

本方案 Phase 5 再启动，数据模型会预留 `licenses` 表位置，届时不必返工。

### 2.2 域名可以购买吗？
**可以。** 已用 whois 查证，以下候选全部未被注册：

| 域名 | 年费参考 | 建议 |
|---|---|---|
| **sanmuaudio.com** | ¥60–80 | **推荐主域名**——.com 通用、便宜、邮箱/SEO 都好 |
| sanmu.audio | ¥120–150 | 品牌感强（音频行业），可作为跳转/备用 |
| sanmuplugins.com | ¥60–80 | 兜底备选 |
| sanmu-audio.com | ¥60–80 | 兜底备选 |

推荐在 **Cloudflare Registrar**（成本价，无溢价）或 Porkbun 购买；买好后绑 Vercel，同时开通 **Zoho 免费域名邮箱**（contact@sanmuaudio.com 转发到你的常用邮箱，一年 ¥0）。

### 2.3 以后想国内快怎么办？
三条路，按成本递增：

1. **不备案**：把托管换成 **Cloudflare Pages** 或加 Cloudflare CDN 优化路由（对国内优化有限但通常好于裸 Vercel）；或用香港/日本节点反代。省事，效果中等。
2. **备案**：ICP 备案（3–6 周，需国内服务器或 CDN 厂商）+ 阿里云/腾讯云 CDN，国内访问快且稳定。备案后 Vercel 主站仍可服务海外，国内走 CDN 分流。
3. **国内镜像**：静态页在 Gitee Pages / 国内对象存储放一份镜像，动态功能（留言）仍走海外。

**结论**：现在不动；将来要提速再走第 1 → 2 条。方案的技术选型（Astro 静态 + Supabase）三条路都兼容，无需返工。

## 5. 技术方案

- **Astro 5** 静态生成；路由 i18n（`/zh` 默认 + `/en`），内容存 Markdown，改稿即改文件。
- **Supabase**：
  - Auth：email + password（禁邮箱验证）；将来支付阶段再加验证与风控。
  - 表：`profiles`（昵称/头像）、`comments`（product_id、parent_id、type：需求/Bug/反馈/闲聊、title、body、status：待审/已发布/已解决、is_pinned、created_by、created_at）、`votes`（需求投票）、`feedback_subscriptions`（Coming Soon 邮箱收集）。
  - 通知：新留言 → Edge Function 经 Resend 发邮件给你。
  - 管理后台：轻量 `/admin` 页（登录即管理员）：待审队列、状态标记、置顶、删除、导出 CSV。
- **下载**：安装包放 **GitHub Releases**（直链稳定、不占 Vercel 带宽），官网下载按钮指向最新版直链。
- **统计**：Umami（Cloud 免费或自托管）；**SEO**：sitemap、meta、OG 卡片、结构化数据。
- **部署**：GitHub 仓库 → Vercel 自动构建；staging 预览链接供你验收。
