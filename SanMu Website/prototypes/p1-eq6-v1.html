特性

双引擎

Zero Latency 引擎应对实时混音与录音；Linear Phase 引擎提供无相位染色的手术级精度，母带无忧。

六段全参量

每段独立增益 / 频率 / Q 值，bell 与 shelf 可选，20Hz–20kHz 全频覆盖。

TPT-SVF 滤波

零延迟反馈式滤波拓扑，低噪底、平滑调制，参数扫频无拉链声。

中 / 侧处理

Mid/Side 模式精细塑造立体声宽度与空间感，直达声与声场分开调。

实时频谱

频响曲线随参数即时重绘，所见即所听，六段频段色一目了然。

轻量 CPU

精心优化的处理链，单实例占用极低，总线挂满也不心慌。
