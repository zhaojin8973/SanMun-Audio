# P5 购买与授权方案（提案 v1，启动 P5 时确认）

> 状态：**候选**（未拍板）。依据 `docs/01-网站方案_v1.md` §2.1 与已冻结定价口径。
> 定价：EQ6 / Comp / Reverb 单款 ¥19 · 捆绑四款 ¥49 · Delay 免费 · 试用 15 天。

## 目标

- 回本即可，不追求防破解天花板；体验优先（¥19 的用户不该被授权流程折磨）。
- 上线顺序：先卖单款与捆绑 → Delay 免费下载 → 试用期 15 天后开始计时。

## 方案 A：轻量授权码（推荐）

```
购买（Stripe/PayPal，官网内）
  → Webhook 通知 Supabase Edge Function
  → generate_licenses 生成授权码
  → Resend 邮件发码（含下载链接）
插件端：About 页输入授权码 + 本机指纹
  → activate_license 在线校验（剩余额度 / 状态）
  → 离线兜底：首次激活时下载的签名文件，30 天宽限
```

- 数据模型已预留：`migrations/0002_licenses.sql`（licenses / activations / 生成与激活函数）。
- 插件端改动点：JUCE About 页加激活面板；域名常量 `licensing.sanmuaudio.com`；机器指纹 = 硬件哈希（不收集隐私信息）。
- 防滥用：一人 ¥19 定价下，离线宽限 + 3 台激活额度 + 异常频率风控足够，不做更重的。
- 工作量：后端约 1 天（Webhook + 邮件），插件端约 1–2 天（激活 UI + 校验 + 15 天计时）。

## 方案 B：平台代管（省事，抽成）

- Lemon Squeezy / Gumroad：自带授权码系统、税务代缴、邮箱分发；抽成约 5%。
- 改动最小（官网放购买按钮跳转即可），但体验割裂、品牌弱、数据在第三方。

## 方案 C：商业级（iLok/PACE）——不推荐

- ¥19 定价与个人站定位下成本不成比例；仅在将来进大经销商渠道时再评估。

## 15 天试用计时

- 插件端本地计时（首次实例化写时间戳）；购买激活后解除。
- 试用结束行为（三选一，待定）：a) 静默提示不锁功能；b) 输出间歇静音 1s；c) 只读参数。建议 a，靠口碑转化。

## 需要你拍板的（启动 P5 时）

1. 收款渠道：Stripe（海外）是否同时要 PayPal？国内要不要支付宝/微信（需要商户资质）？
2. 试用结束行为选 a/b/c；
3. 购买页文案与退款政策（7 天无理由？）；
4. 授权码方案 A 还是平台代管 B。
