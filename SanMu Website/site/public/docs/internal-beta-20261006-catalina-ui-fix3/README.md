# SanMu Audio Catalina compatibility beta candidate (2026-10-06)

This directory tracks internal-test-20261006-catalina-ui-fix3 and contains the four macOS Universal 2 candidate packages' notes, manuals, EULA, checksums and platform status.

The candidates target Intel macOS 10.15+ and Apple silicon macOS 11.0+. Each package contains VST3, AU and AAX. The AAX binaries currently have Apple Developer ID Application signatures only; no PACE digital envelope has been applied. The pkg files have no Developer ID Installer signature and have not been notarized by Apple.

First validate the window, settings panel, 85/100/115/125/150% scaling, knobs, meters, EQ point interaction, reverb particles/water and actual audio on a Catalina + Pro Tools machine. PACE, Installer signing and Apple notarization come only after that validation. Windows is not built and website downloads remain closed.
