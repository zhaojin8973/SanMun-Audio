# SanMu Audio 内测用户手册

## 1. 安装与首次使用

安装前完全退出宿主。macOS 总安装包会显示 VST3、Audio Unit (AU)、AAX 三个可选组件；Pro Tools 只需选择 AAX，Logic Pro 选择 AU，其他宿主通常选择 VST3。安装后重新启动宿主并执行插件扫描。

macOS 安装位置：

- VST3：`/Library/Audio/Plug-Ins/VST3`
- AU：`/Library/Audio/Plug-Ins/Components`
- AAX：`/Library/Application Support/Avid/Audio/Plug-Ins`

Windows 安装位置（待 Windows 安装包完成后使用）：

- VST3：`C:\Program Files\Common Files\VST3`
- AAX：`C:\Program Files\Common Files\Avid\Audio\Plug-Ins`

## 2. 通用操作

- 旋钮上下拖动调节；滚轮可微调。
- 双击旋钮或按住 Command/Ctrl 点击可恢复默认值。
- 聚焦旋钮后可使用方向键，Home/End 可到达边界。
- `A/B` 保存两组声音状态，复制按钮可在两组之间复制。
- `BYP` 旁通效果处理。
- 设置中的主题、语言、提示和界面比例会保存到本机，并用于后续实例。
- 工程参数由宿主保存；界面偏好独立保存，不会改变声音参数。

## 3. SanMu EQ6

### 两种处理模式

- **Zero Latency**：最小相位、无额外处理延迟，适合实时混音。
- **Linear Phase**：线性相位 FIR 处理，适合母带和并行处理；宿主会报告并补偿额外延迟。

### 频段操作

每个频段可调中心频率、增益、Q、滤波器类型和动态参数。曲线上的频点可以直接拖动；拖动结束后宿主应立即恢复播放，无需点击 DAW 空白区域。

### 频谱

频谱可切换输入/输出观察，峰值保持用于定位频率。峰值显示不应阻止频点继续选择；如果需要更清晰的画面，可在设置中关闭动态图像，声音和电平表仍继续运行。

## 4. SanMu Comp

四种模式：

- **LEV**：自适应平准，适合人声和持续素材。
- **VCA**：响应明确，适合总线和鼓组。
- **FET**：攻击快，适合抓取瞬态。
- **Opto**：压缩曲线平滑，适合需要温和动态的素材。

曲线显示输入、输出和增益衰减。暂停曲线只冻结显示，不停止音频和电平表；清除峰值只重置峰值保持和过载提示。

## 5. SanMu Delay

- **Modern**：清晰、稳定的数字延迟。
- **Tape**：带有磁带式色彩和调制。
- **BBD**：较暗、较有颗粒感的模拟风格。
- **Diffused**：扩散回声，适合做空间尾巴。

路由可选 Independent、Ping-Pong、Cross。时间可选 Sync、BPM 或 Free；Ducking 会在输入信号出现时降低湿声，让原声更清楚。

## 6. SanMu Reverb

- **Plate**：密集、连续，适合人声和鼓。
- **Room**：近距离房间感，边界清楚。
- **Hall**：宽阔、展开，适合钢琴、弦乐和主唱。
- **Chamber**：带腔体特色的室内空间。

主要控制：

- `Predelay`：原声与第一批反射的间隔。
- `Decay`：尾音持续时间。
- `Size`：空间尺度。
- `Attack`：混响场建立速度。
- `Early Diff / Late Diff`：早期反射与晚期尾音的密度。
- `Bass Mult / High Shelf`：低频和高频尾音的持续与阻尼。
- `Low Cut / High Cut`：最终湿声的频率边界。
- `Rate / Depth`：尾音内部调制速度和幅度。
- `干 / 湿 / 混合`：只切换声场观察层，不改变声音比例。

浅色主题显示水波，深色主题显示粒子/尘埃。设置中的声场开关只关闭动态图像，不会停止混响处理或电平表。

## 7. 内测到期

内测版本有效至北京时间 2026 年 10 月 31 日 23:59。到期后效果处理自动停止并输出原声，工程中的插件参数仍保留。请在到期前冻结或导出重要工程，并等待后续版本。

## 8. 问题反馈

反馈时请同时提供：插件名称和版本、操作系统版本、宿主名称和版本、插件格式、单声道/立体声状态、复现步骤和截图。若插件未显示，请先完全退出宿主，再确认安装路径和重新扫描结果。
