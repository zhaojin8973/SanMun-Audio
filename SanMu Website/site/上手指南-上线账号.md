# 上线账号手把手（完全不懂也没关系）

> 你只需要做"注册 + 点几下 + 复制粘贴"，约 40 分钟，全部**免费或几十块**。
> 三个账号 + 一个域名，每个都告诉我"做完第 X 步了"，我来检查并接手下一步。

## 它们分别是什么（一句话）

| 服务 | 是什么 | 花多少钱 | 要做多少事 |
|---|---|---|---|
| **Supabase** | 云数据库：装留言、投票、账号的"仓库" | 免费 | 注册 → 建项目 → 粘贴一段 SQL → 抄 2 个密钥（已写好指南） |
| **GitHub** | 代码仓库：放网站源码、放安装包下载 | 免费 | 注册 → 建一个仓库（我帮你把代码传上去） |
| **Vercel** | 把网站"挂到公网"的地方（别人访问的服务器） | 免费版够用 | GitHub 登录 → 导入 → Deploy 一个按钮 |
| **域名** | 网址 sanmuaudio.com（可在 Vercel/Cloudflare 买） | 约 ¥60–80/年 | 注册时填信息 + 最后改两条 DNS 记录 |

**顺序建议：Supabase → GitHub+Vercel → 域名。** 前三步做完网站就能被全世界访问（临时网址），域名是给它一个正式名字。

## 第 1 步：Supabase（15 分钟，最重要）

完整步骤在 `site/supabase/SETUP.md`，这里讲人话版：

1. 浏览器打开 **https://supabase.com** → 点 **Sign in** → 选 **GitHub**（没有 GitHub 账号就先注册一个，顺便完成第 2 步的一半）。
2. 登录后点 **New project**：
   - 名称随便填（如 `sanmu-site`），
   - 数据库密码：**点"生成"图标自动生成一个，抄下来**（后面几乎用不到，但要留着），
   - Region 选 `Tokyo`（离国内近），
   - **Start**。
3. 等 2 分钟初始化完成 → 左侧菜单 **SQL Editor** → New query → 把我给你的文件（`supabase/migrations/0001_init.sql`）整个粘进去 → **Run**。跑完显示 Success 就行。
4. 左侧 **Authentication → Providers → Email**：把 **Confirm email** 的开关**关掉**（默认是开的，不关用户注册后没法登录）。
5. 左侧 **Project Settings → API**：把 **Project URL**（`https://xxxx.supabase.co`）和 **anon public** 那串长密钥（`eyJ...`）**复制**下来。
6. 把这两行发给我（或按 `site/.env.example` 填进 `site/.env`），剩下我处理。

✅ 完成标准：把第 5 步的两串密钥发我，或者说"第 6 步已填"。

## 第 2 步：GitHub（10 分钟）

1. **https://github.com** → Sign up（邮箱注册；Supabase 那边如果用了 GitHub 登录就跳过了）。
2. 注册完告诉我你的 GitHub 用户名。
3. 我来建仓库并把代码推上去（需要你本地 Git 登录一次，我一步步带；或者你按网页提示建一个叫 `sanmu-site` 的空仓库，其余我也能代劳）。

✅ 完成标准：告诉我用户名 + "仓库建好了"。

## 第 3 步：Vercel（10 分钟）

1. **https://vercel.com** → Sign up → 选 **Continue with GitHub**（授权 Vercel 读你的仓库）。
2. Add New → Project → 选 `sanmu-site` 仓库 → Framework 自动识别为 **Astro**，直接 **Deploy**。
3. 部署完会有一个 `<项目名>-<用户名>.vercel.app` 的网址——**这就是能公开访问的网站了**。
4. 若 Supabase 已配好，再把那两个密钥（PUBLIC_SUPABASE_URL / PUBLIC_SUPABASE_ANON_KEY）加到 Vercel 项目 Settings → Environment Variables，然后 Redeploy。

✅ 完成标准：把 vercel.app 网址发我，我检查上线质量。

## 第 4 步：域名 sanmuaudio.com（10 分钟 + 年费）

1. 推荐 **cloudflare.com** → 注册 → 首页搜 **sanmuaudio.com**（未注册，约 ¥60–80/年）→ 付款。
2. 完成购买后，把 Cloudflare 页面里给你的两条 **DNS 记录**（类型 + 名称 + 值）发我，我帮你填进 Vercel。
3. Vercel → 项目 → Settings → Domains → Add → 填 `sanmuaudio.com` → 按提示操作，证书自动签发。

✅ 完成标准：收尾时我把域名邮箱（contact@sanmuaudio.com，Zoho 免费）也一并配置好。

- **做错了会不会坏？** 全是新创服务，不存在覆盖你现有东西的风险；错了随时删除重建。
- **多长能上线？** 按此顺序 40 分钟做完，我一小时内完成检查与收尾，当天即可上线。
