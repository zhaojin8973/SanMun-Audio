# 第四轮：信息卡与实时选峰

日期：2026-09-15。对应用户六项晚间反馈，本文件接替第三轮关于模式按钮、卡片、频谱选峰和显示层的操作说明。自动阈值、四种处理模式的音频实现与上一轮一致。

## 六项调整

| 用户反馈 | 当前实现 |
| --- | --- |
| 模式按钮偏离系列设计 | 恢复与 Delay／Comp／Reverb 同源的浅彩底、玻璃描边、选中渐变与轻阴影。每个未选按钮也保留各自颜色，选中时加强底色与描边，取消上轮的粗底部色条。全局旋钮仍跟随模式颜色 |
| 信息卡小巧、完整、可扩展 | 184×68 像素，较 232×68 缩小约 21%。显示频率、带正负号的增益、Q，保留类型、声道、斜率、开关、耳机与删除。每个可用按钮都有频段色悬停和键盘焦点提示，箭头打开更多操作 |
| 点击／拖动时卡片消失 | 按下频点即显示，拖动期间持续跟随频点并更新读数；增益提升优先置于上方、衰减优先置于下方，靠近边界自动避让。小指向角连接频点。松手后仍显示，移开才隐藏。按住耳机扫频时保持按钮位置，防止监听目标跟着鼠标逃走 |
| 选峰太快、错误冻结 | 普通悬停先等待约 1 秒，再用约 1.5 秒逐渐加深；进入前鼠标明显移动即复位。完成后频谱、能量和候选峰继续随音乐更新，不保留冻结数组。移出频谱实际覆盖的谱形范围立即恢复，即使指针仍在大画布内部 |
| 激烈跳动 | 加入独立显示平滑：显著上升采用约 28 ms 时间常数，小幅上升约 85 ms，回落约 220 ms。按时间而非帧数计算，明显起音保留快速响应，细碎变化和回落更缓和 |
| 线条太多 | 移除细棕色峰值保持线、输入频谱对照线、各段重复响应线、静态总线与动态范围虚线。保留一条彩色实时频谱轮廓及填充、一条实际总 EQ 响应；正在调整的单段仅显示很淡的区域。移除 IN／OUT／PEAK 图例 |

## 小卡片扩展菜单

箭头或右键频点打开：旁通／启用、增益反向、动态开关、滤波类型、斜率、声道位置、复制、粘贴、复制为新频段、剪切、删除。切除滤波器禁用增益反向，非切除滤波器禁用斜率；动态禁用条件继续遵循原处理能力。没有添加尚未实现的“频谱动态处理”或“拆分”占位入口。

复制使用当前编辑器实例内部剪贴板，关闭编辑器后清空；不读取系统剪贴板，不跨实例复制。不复制临时监听或历史持续独听。粘贴和复制为新频段保留频率、增益、Q、类型、声道、斜率、启用及动态参数。所有声音修改走现有 begin／set／end 参数事务，可撤销；新增与后续拖动合并为一个事务。

## 实时选峰的操作边界

候选峰下方显示空心临时频点，尚未占用 24 个频段槽位。按下候选点才创建 0 dB Bell，并可在同一次按住中左右调频率、上下调增益；没有选取的候选点不会改变声音。键盘 Enter／空格也可新增。24 段已满时禁用候选点。

候选算法继续基于显著局部峰及峰间距筛选，最多五个；约每 120 ms 更新候选，复用附近峰的按钮节点，避免每帧重建 DOM 丢失点击。轮廓持续使用新频谱。工具栏入口可主动进入选峰，但鼠标随后仍遵循谱形边界退出；Escape、失焦、隐藏页面也会解除。

频谱数值的显示平滑与原生 FFT 分离。FFT（把音频分解为各频率能量）的窗口、采样、速度没有修改；动态压缩、检测器、阈值和 GR 原始读数不经过这层平滑。显示平滑意味着轮廓不等于每一瞬间的原始读数，不用于宣称采样峰值。

## 参数与文件

宿主参数仍为 323 项，没有新增或改变 ID、顺序、范围、默认值与状态迁移。

| 入口 | 绑定与状态 |
| --- | --- |
| 模式按钮 | 原 `eq_mode`／`character_mode`，仅改变 CSS 状态表现 |
| 卡片频率／增益／Q | `bandN_freq`／`bandN_gain`／`bandN_q`，只读实时显示 |
| 卡片选择器 | `bandN_type`／`bandN_placement`／`bandN_slope`，沿用原范围 |
| 菜单反向／开关／动态 | `bandN_gain` 符号反向、`bandN_enabled`／`bandN_dynamic` 切换 |
| 新增或复制频段 | 使用空闲 `bandN_*` 槽位，`present` 最后启用，所有字段在同一撤销事务 |
| 实时选峰和显示平滑 | 编辑器显示状态，不写入声音预设或宿主自动化 |

主要改动：`ui/band-tools.js`、`ui/spectrum-focus.js`、新增 `ui/spectrum-motion.js`、`ui/graph.js`、`ui/app.js`、`ui/eq.css`。原生仍内嵌同一份网页资源。共享 `reverb.css` 与 `icons.js` 已再次与 Delay 逐字节比较一致；EQ 局部覆盖不写回其他插件。
