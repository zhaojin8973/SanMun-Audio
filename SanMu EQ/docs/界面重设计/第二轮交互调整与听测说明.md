## 四类处理模式

界面只保留同级的 **Clean / Tube / Discrete / Linear Phase**。

| 界面入口 | 现有参数映射 | 当前真实处理 | 使用方向与边界 |
| --- | --- | --- | --- |
| Clean | `eq_mode=0, character_mode=0` | 最小相位均衡，无额外非线性染色 | 精确调整、保持干净 |
| Tube | `eq_mode=0, character_mode=1` | 相同均衡滤波器，加带偏置的软饱和 | 偶次谐波较明显，输入越强染色越重 |
| Discrete | `eq_mode=0, character_mode=2` | 相同均衡滤波器，加对称软饱和 | 很轻的奇次谐波、柔化峰值；普通电平下可能接近 Clean |
| Linear Phase | `eq_mode=1`，保存原 `character_mode` | 线性相位均衡 | 动态与音色暂停，回到前三类恢复参数 |

两项宿主参数保持原有 ID、顺序、范围和数值语义，四入口只是统一的操作层。一组模式选择在一个撤销事务中完成。宿主旧的相位自动化仍控制 `eq_mode`，不能扩成四值范围，否则会改变旧工程自动化。历史宿主参数中的名称不作为当前界面入口。

**实际结论：目前不能宣称三种音色在所有素材上都有明显优势。** Tube 与 Clean 区别成立；Discrete 的变化小得多，本轮保留其透明方向，没有为了制造差异而随意加重失真。它们也尚未包含不同的硬件滤波网络、比例 Q、变压器或元件级模型，不能视作 825 / 8200 复刻。

### 分级电平测量

来源：`tests/test_eq_upgrades.h` 的 `testAuditionAndCharacterLevels`。48 kHz、双声道、256 样本块、937.5 Hz 正弦，所有频段关闭，预热后同步统计二至八次谐波。以下为总谐波失真百分比，不包含完整互调或混叠指标，也不是主观听感评分。

| 输入峰值 | Clean | Tube | Discrete |
| --- | ---: | ---: | ---: |
| −24 dBFS | < 0.00001% | 0.3254% | 0.001607% |
| −18 dBFS | < 0.00001% | 0.6495% | 0.006393% |
| −12 dBFS | < 0.00001% | 1.2975% | 0.02543% |
| −6 dBFS | < 0.00001% | 2.6028% | 0.1010% |
| 0 dBFS | < 0.00001% | 5.3186% | 0.3986% |

−6 dBFS 下的基频变化为 Tube 约 −0.209 dB、Discrete 约 −0.026 dB，比较时需要留意音量差。Clean 的输入输出电平在该测试下保持一致。

20 Hz–20 kHz 可继续作为四类共同的中心频率／截止频率调节范围；模式差异来自相位处理和电平相关的非线性，不需要为模式拆成不同频率范围。保留范围也保留旧工程自动化映射。20 kHz 是调节上限，并不表示音色产生的全部谐波均落在其内；高频非线性的混叠表现还需要专门测量。更高采样率本身也不等于硬件音色更接近。

## 频谱与布局

- 原生频谱的分析窗口、分频率响应速度、输入输出数据、峰值保持和停播衰减均未修改。
- 主画布从 286 提高到 **380 像素，增加约 33%**。频段调节行从 153 压到 102 像素；频率、增益、Q 旋钮直径 66 像素。
- 颜色为连续多级渐变：红、珊瑚、橙、金黄、黄绿、绿、青绿、青蓝、蓝。颜色根据对数频率位置变化，频点、响应线、频谱填充与旋钮保持关联。
- 移除底栏采样率、延迟显示及“清除峰值”按钮。宿主真实延迟补偿保持原样；点击或键盘激活输出电平表清除保持峰值。
- 动态区固定在底栏中央，提供阈值、范围旋钮，较大的 GR 数字和 0–24 dB 固定刻度条。细线标记当前最大压缩范围，填充代表真实衰减，因此调节范围不会把同样的衰减夸大成不同条长。
- 动态暂不支持的 Linear Phase 与切除滤波器显示原因并禁用控件；关闭动态后保留参数供再次开启。

## 频点信息卡与声道选择

卡片提供滤波类型图标菜单、声道位置图标菜单、斜率菜单以及开关、按住独听、动态开关、删除。没有增益归零按钮。斜率只对 Low Cut / High Cut 可用，固定 12 / 24 / 36 / 48 dB/oct；不显示不存在的 Bell 斜率功能。

主调节区的滤波类型和声道位置改成带标题、图形、完整名称的选择器，删除冗余频段编号标题。菜单选中项同时具有描边、填充、加重文字和勾选标记。

声道依然是 Stereo / Left / Right / Mid / Side 五选一。菜单用重叠圆、单侧圆、交集和外侧轮廓表示，不占用频率色。曲线上 Stereo 不加标记；其余显示 L / R / M / S 小标记，M 使用圆框，S 使用双边框，窄窗口也保留字母以避免只靠形状辨认。

## 快捷操作契约

| 目标 | 操作 | 结果 |
| --- | --- | --- |
| 任意旋钮盘 | Option / Command + 单击；兼容 Control + 单击 | 恢复该参数的原生默认值 |
| 任意旋钮盘 | 双击 | 恢复默认值 |
| 普通增益频点 | Option / Command + 单击 | 增益归零 |
| Low Cut / High Cut 频点 | Option / Command + 单击 | Q 恢复 1 |
| 频点 | 左右拖动／上下拖动 | 频率／增益；切除滤波器上下调 Q |
| 频点 | 滚轮 | 调 Q |
| 耳机图标 | 按住 | 临时监听该频段 |
| 耳机图标 | 按住并左右拖动 | 边监听边扫频，松手结束监听，频率改动保留且可撤销 |
| 耳机图标 | 聚焦后按住空格或 Enter | 临时监听，松键结束 |
| 旋钮读数 | 输入数值后 Enter | 精确输入，支持 Hz / kHz / dB；Escape 取消 |
| 旋钮盘 | 方向键；Home / End | 细调；最小值／最大值 |
| 频点 | Delete / Backspace | 删除该段，可撤销 |
| 图中空白 | 双击 | 在该位置新增频点，最多 24 段 |
| 输出电平表 | 单击；聚焦后 Enter / 空格 | 清除保持峰值 |

Q 的旋钮行程为两段对数映射：0.1→1 占左半圈，1→40 占右半圈；**Q=1 指针朝上**。仅显示／交互映射改变，原生参数和宿主自动化不变。

新监听是原生引擎的临时覆盖状态，不使用历史 `bandN_solo` 参数保存监听。旧工程若已有持续独听，界面会亮起对应耳机；用户重新按住试听时解除旧开关，防止松手后仍被旧状态锁住，此清理可撤销。按住监听不进入预设或自动化，不产生单独的撤销项；扫频产生一个频率编辑事务。松手、取消指针捕获、失焦、隐藏页面及编辑器销毁都会结束；浏览器每 250 ms 续期，原生 1 秒收不到心跳时解除。临时监听遵循所选 L/R/M/S；即使该段 EQ 已旁通，仍可试听该频带。整体 BYP 继续优先。
