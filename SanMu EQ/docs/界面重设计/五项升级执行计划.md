## 已确认根因

截图中低频平台来自现有 FFT 显示映射：8192 点 FFT 的同一个离散频点，被多个对数显示点重复使用。增加画布精度或单纯圆滑路径不能恢复这些点之间的信息。需要先改频域插值，再处理显示平滑。

现有分析在音频线程执行，刷新由宿主块长触发，固定 EMA 系数使时间响应跟随块长变化；界面只有输出频谱，无法直接比较处理前后；其频谱 dBFS 与 EQ 增益坐标也没有明确区分。

## 音色依据与边界

用户所称 825 对应稀有的五段电感/电子管母带 EQ 方向。Lindell EQ825 官方资料描述了特殊滤波网络、电子管和变压器；IGS 825EQ 官方给出比例 Q、分档调节和电子管配置。仅靠公开资料不能声称电路等效复刻，SanMu 实现应作为自身的模拟音色，不直接冒充硬件型号。

- [Lindell EQ825 官方资料](https://www.plugin-alliance.com/products/lindell-audio-eq825)
- [IGS 825EQ 官方规格](https://igsaudio.com/825eq/)

GML 8200 是五段宽范围重叠、频率连续可调的参量 EQ，Q 为 0.4–4，两端可切搁架，目标是透明度、余量与精确度。它与电子管染色方向不同，不能用同一个强饱和器代表两者。

- [GML 8200 官方产品页](https://www.massenburg.com/model-8200/)
- [GML 8200 原厂手册](https://www.massenburg.com/wp-content/uploads/2020/02/GML8200man.pdf)

Pro-Q 的动态 EQ 是随信号电平改变 Bell/Shelf 的增益，区别于频谱动画。默认检测频段限制后的输入；压缩量和实际衰减分别显示。Cut 没有增益参数，不能把动态 Cut 偷换为同一概念。

- [FabFilter 动态 EQ 官方说明](https://www.fabfilter.com/support/help-detail?alias=pro-q&url=using%2Fdynamic-eq)

## 兼容约束

现有 226 个参数的顺序、ID 和范围必须保留。动态参数和模拟音色参数追加；旧状态缺少新增参数时必须恢复为关闭，避免旧工程突然变声。相位处理与模拟音色是不同维度，不能直接扩大旧 `eq_mode` 的归一化范围而改变既有自动化含义。

线性相位动态 EQ 必须维持声道、检测与延迟一致性；不允许把最小相位动态滤波静默追加到 Linear Phase 后还宣称整链线性相位。每阶段完成后更新本表，不用仅能点击的界面代替真实 DSP。

## 本轮实现边界

后台频谱分析器使用长窗与短窗混合、分数 FFT bin 插值、输入/输出双轨、峰值保持；音频线程只提交预分配采样。动态 EQ 使用本频段检测器和共享立体声包络，动态增益以约 3 kHz 控制速率更新，Linear Phase 中禁用动态处理。

音色模式名称在 UI 中为 Clean、Tube、Discrete。Tube 是 825 类电子管/变压器暖感方向，Discrete 是 8200 类高余量、透明方向；两者均为 SanMu 自身模型，不宣称硬件电路复刻。

本轮不是完整硬件建模：两种音色采用 2 倍过采样下的非线性残差，Tube 带偏置、Discrete 对称，残差经过 5 Hz 去直流。模式混合采用 30 ms 过渡；保持现有 EQ 曲线和连续频点，不包含原机电感网络、比例 Q 或元件模型。是否达到用户期望的 825/8200 味道尚未听测，下一阶段应以等响音频对比决定是否继续加入比例 Q 与频率相关饱和。

动态 EQ 固定 4:1、6 dB 软拐点、10 ms 检测启动、150 ms 释放，并对控制量再次平滑；这些数值不能当成最终实测阶跃响应时间。支持 Bell、Low Shelf、High Shelf 及 Stereo/L/R/M/S 路由。第一版仅向下压缩，不含自动阈值、外部侧链、扩展或 Pro-Q 4 的频谱动态处理。Linear Phase 中动态和音色均暂停，参数保留。此限制在 UI 禁用状态和悬停提示中显示。

## 本轮验证证据

- `tests/test_eq_upgrades.h`：44.1/48/96 kHz，64/512 块长，目标 1 kHz 最大压缩 6 dB，实测约 -6.000/-5.999/-5.999 dB；左右衰减一致，100 Hz 带外未误触发，L 路由不影响 R，Linear 未混入动态 IIR。
- 音色测试：Clean 谐波幅度约 1.6e-9；Tube 二次谐波约 0.0121；Discrete 三次谐波约 0.000501（输入峰值 0.5）。确认有可测变化，不代表已匹配硬件。全旁通逐样本恢复测试通过。
- 60 Hz / 1 kHz / 10 kHz 正弦双轨测试：峰值频率正确，输入 -20 dBFS 的谱峰显示约 -20.43/-20.78/-20.63 dBFS，输出低 6.0206 dB；相邻低频点没有旧版平台；宿主不继续提交音频时显示可衰减。
- 旧版 226 参数顺序完整保留；新增 73 项后共 299 项。状态保存恢复、旧状态补默认值与工厂预设清除动态状态均已覆盖。
- `tests/test_render_ui.cpp` 验证原生动态衰减与动态曲线桥接；`tests/verify_web_ui.cjs` 验证滤波菜单、节点工具、动态控制撤销、Linear 限制、浅深色、五档窗口、24 节点和空状态。
- 未完成用户 DAW 听测、真实硬件等响对比、完整 THD/IMD/混叠扫描及多实例压力验收；浏览器预览仍是示意数据。

## DAW 测试顺序

1. 重启宿主并重新插入 SanMu EQ6，播放人声或全频混音，先检查低频台阶消失、输入/输出轨迹和停播回落。
2. 在 1~4 kHz 新建 Bell，保持静态增益 0 dB，开启动态；范围 6 dB，阈值逐步降低，确认只在能量过阈值时衰减。
3. 用同一段音频对比 Clean、Tube、Discrete，记录音量差、低频厚度、高频边缘和瞬态；目前两个音色模式不改变既有频响参数。
4. 检查频点工具的独听、开关、归零、删除与撤销；切换 Linear 后确认动态/音色暂停，再切回 Zero 恢复。
