## 本轮 12 项对应结果

| 用户要求 | 当前实现 |
| --- | --- |
| 按住耳机左右移动，卡片与频点同步 | 鼠标捕获保持监听，按横向距离对数扫频；卡片持续贴附节点。松手、失焦、取消、关窗解除监听。扫频为一次撤销事务。 |
| 显著峰值稳定、接近时不消失 | 实时谱能量继续变化；独立候选跟踪保留身份，约 250 ms 更新一次，最多 5 点。候选频率缓慢移动，新峰须持续显著约 700 ms，暂时消失的旧峰保留约 4 秒。鼠标靠近或键盘聚焦时锁定候选位置，点击拖动后成为正常 EQ 频点。 |
| 更紧凑、直接输入、文字斜率 | 卡片为 180 × 64 基准像素，频率、增益、Q 可直接输入；支持 Hz/kHz/dB，回车提交、Esc 取消、非法值拒绝。斜率用 `12 dB/oct` 等文字；低切/高切的增益输入禁用。 |
| 次级频率网格 | 主标记之间增加对数分布的次级竖线，弱于主网格，不增加密集文字。 |
| 自动增益与极性反转状态 | 与 BYP 使用同一悬停/开启反馈：悬停浅色，点击开启加深，鼠标移开仍保持。 |
| 输出联动过大 | 联动按钮缩为 20 × 20，位于 L/R 旋钮之间。 |
| 输入与斜率分隔 | 增加竖向区域分隔线。 |
| BYP 电平不回落 | 内部旁通仍测量实际输入/输出；宿主停止音频回调后，桥接读数超时衰减；界面电平条与峰值保持自然释放。单声道两条电平采用同一测量，避免右表残留。BYP 不代表静音，不应点击就强制归零。 |
| 动态开关与图标胶囊 | 动态 EQ 使用电源图标；同类状态按钮统一浅色悬停、开启加深。扩展菜单动态项也改为电源图标。 |
| 频谱开关文字 | 主开关显示“频谱”或英文界面中的 Spectrum，保留独立选峰入口。 |
| 当前轨道名称 | 在 Linear Phase 右侧显示 JUCE `updateTrackProperties` 的实际轨道名，过长省略；无名称则隐藏。名称不是预设参数，也不会使用模拟钢琴名称。 |
| 频谱视图设置 | 设置面板加入 Pre/Post、悬停选峰、峰值保持、显示范围、分辨率、速度、倾斜。详见下表。 |

## 分析设置与行为

| 设置 | 选项及默认值 | 实际作用 |
| --- | --- | --- |
| Pre / Post | 默认只开 Post | 显示真实处理前/处理后频谱。两者都开时，Pre 为较淡参考线；两者都关则不画频谱。 |
| 悬停选峰 | 默认开启 | 指针在谱区稳定约 1 秒后开始加深，约 1.5 秒完成；中途移开立即恢复。完整选峰状态保留候选附近容错与短暂退出宽限，离开整个谱区退出。 |
| 峰值保持 | 默认关闭 | 累积显示期间各频率的最大能量。短点切换，按住超过 250 ms 临时保持、松手恢复原状态。它与实时选峰是两个独立功能，不改变音频。 |
| 显示范围 | 60 / **90** / 120 dB | 显示纵轴范围；分析底限扩为 −150 dBFS，避免 120 dB 范围及高频倾斜产生虚假底部平台。 |
| 分辨率 | 2048 / 4096 / **8192** / 16384 | 实际切换后台 FFT（把声音转换为频率能量的运算）的低频窗口长度。250 Hz 以下采用所选窗口，250 Hz–1 kHz 逐渐混合 2048 短窗口，1 kHz 以上保持短窗口的起音速度。 |
| 显示速度 | 快 / **中** / 慢 | 只改变界面运动平滑；不改变 EQ、动态检测器或音频。明显起音仍比小幅抖动更快响应。 |
| 显示倾斜 | **0** / 1.5 / 3 / 4.5 / 6 dB/oct | 以 1 kHz 为参考，仅改变可视化斜率；非零倾斜下纵轴标识 dB，不冒充未经修饰的 dBFS。 |

常规频谱保持原连续多色走向与单条主要轮廓。只有用户主动开启 Pre 才增加处理前对照线。共享字体、图标笔画、面板材质、四模式按钮体系继续沿用。

外部侧链频谱和跨实例频率冲突检测本轮没有接入。当前插件没有对应外部信号来源及实例间频谱通讯，因此未放置无效按钮；设置面板已说明。当前动态 EQ 算法及四种音色/相位模式不在本轮重新设计范围。
