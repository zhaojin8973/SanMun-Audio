## 组件来源

参考工程：`../SanMu Comp/ui`、`../SanMu Delay/ui`。

| 项目 | 本版实现 |
| --- | --- |
| 品牌字体 | 同源 Avenir Next，品牌 26px、型号 21px，Audio 横向均匀排布 |
| 正文字体 | 同源系统字体栈，数值沿用 Avenir Next |
| 图标 | `ui/shared/icons.js` 原文件，EQ 额外操作沿用 Lucide 路径、16px 尺寸与 1.5px 线宽 |
| 旋钮 | `ui/shared/draw-knob.js` 原文件，共用表面、270 度轨道、刻度和短指针 |
| 面板、主题 | `ui/shared/reverb.css` 原文件，共用玻璃板体、薄底缘、顶栏、预设胶囊和设置控件 |
| EQ 工作区 | 彩色频响曲线、频谱、编号节点、频段选择条、当前频段参数和双声道输出表 |
| 窗口 | 1100 × 750 基准，插件支持 85%、100%、115%、125%、150% |

上述三个公共文件已与 Comp 逐字节比较，完全一致。EQ 布局覆盖集中在 `ui/eq.css`，后续修改应优先保留公共文件一致性。

## 操作与状态

- 接入现有 24 个固定参数槽位；界面可增删频点、拖动、调整 Q、切换滤波类型与声道、独听和旁通。
- 参数输入支持 Hz、kHz、dB 单位；非法输入不会写入音频参数，取消后清理错误状态。
- 相同位置的节点错开显示并连接实际锚点；频段编号保留，不因增删而重排参数标识。
- 频响数据使用现有 EqBand 响应函数；停止播放时仍可调整并显示曲线。
- 原生操作通过桥接调用现有参数树，事务结束时立即同步，以保证快速增删可撤销。
- 初次从 A 切换到 B 前保存当前 A，切换声音快照时保留界面主题。
- 动态 EQ 尚未实现（仅指本历史初版）；当前实现与限制见[第三轮动态与频谱交付说明](第三轮动态与频谱交付说明.md)和[打包前最终审查](打包前最终审查-20260924.md)。
