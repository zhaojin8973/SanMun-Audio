## 自动阈值的实际算法

检测器与动态滤波器分离。Bell 使用带通检测，搁架使用相应低通／高通；沿用既有立体声、L/R、M/S 音频路径。自动阈值在检测电平高于 -85 dB 时累计 100 ms 有效信号建立参考，然后以 1.5 s 的平滑速度跟随带内包络电平。参考以下 4 dB 作为目标阈值，以 40 ms 平滑变化，范围限制在 -84 至 +6 dB。

未完成学习时不触发自动压缩；低于门限的静音不继续学习。频率、Q、类型变化、重新启用或切入 AUTO 后重新建立参考。手动模式保留 -60 至 0 dB 的原有参数范围和处理语义。AUTO 的显示值是检测结果，不会覆盖保存的手动阈值，也不会把实时学习写入宿主自动化。

稳定单音下会建立约 3 dB 的衰减，较大的短时突发触发更多衰减，由范围旋钮限制。这是电平自适应的动态均衡，不是已经验证过的人声／乐器智能识别。Linear Phase 和切除滤波器仍暂停动态处理。

新参数 `band1_dyn_auto` 至 `band24_dyn_auto` 追加在原有 299 项之后，总数 323；原有 ID、序号和数值范围保留。旧工程或旧用户预设没有该参数时补为 MANUAL，保留之前的声音；新建频段及工厂预设使用 AUTO，但默认动态仍关闭。

## 频谱选峰

鼠标在频谱填充区域或轮廓附近停留约 650 ms 后，频谱在约 500 ms 内加深现有连续频率色。EQ 曲线和节点同步淡出。完成后冻结当下的显示频谱，提供最多五个显著局部峰供选择；播放和音频处理继续运行。

候选点由输入的实际频谱数组计算：轻量三点平滑，排除低于 -78 dB 的谱峰，要求局部突出度至少 1.2 dB，并限制峰间距。平坦谱和静音不会制造候选点。点击频率标签添加一个 0 dB Bell 频段，最多 24 段；新增可以撤销。

移出频谱区域、点击其他操作区或按 Escape 恢复实时显示。工具栏的选峰图标提供固定进入方式，可用键盘选择候选点，再次点击退出。固定进入时不会因为鼠标移开而立即退出。动画完成和退出边界已加入完整操作回归，覆盖选峰后撤销、再次悬停及退出恢复。

原生分析器的窗口、频率采样、响应速度、输入／输出频谱、峰值保持与停播衰减没有改变。浏览器预览使用示意数据；原生插件继续使用实际音频的分析结果。

## 布局与交互

- 信息卡缩至约 232×68 像素，透明材质；靠近频点、停留在卡片、打开其菜单或按住试听时显示，离开后隐藏。仍可从键盘聚焦频点进入。卡片保留类型、声道、斜率、开关、临时监听、动态和删除。
- 全局输入、输出 L、输出 R 的旋钮色跟随 Clean／Tube／Discrete／Linear Phase，分别使用蓝、琥珀、青绿、淡紫。频段旋钮与频谱继续使用低红至高蓝的连续渐变。
- 四模式选中态同时使用较强填充、描边、加重文字和底部色线；浅色、深色均检查了颜色覆盖关系。
- 自动增益补偿、极性反转移至顶部 BYP 同栏，均为图标状态按钮。复选框与菜单勾号已移除，选中菜单使用圆点、描边和填充表达。
- 主调节行左右对称：左侧滤波类型，右侧声道位置，中间频率、增益、Q。右侧重复的监听、删除、开关移除。
- 底部新增四档斜率旋钮：12／24／36／48 dB/oct。仅切除滤波器可调；切除模式下增益旋钮保留、变灰且禁止编辑。斜率可用方向键单档调整或直接输入数值。
- 参数数字在各自旋钮正下方居中，单位独立靠右排列，不再把数字中心推偏。
- Option／Command 加单击复位、Q=1 指针朝上、按住耳机左右扫频以及松手结束监听继续有效。
