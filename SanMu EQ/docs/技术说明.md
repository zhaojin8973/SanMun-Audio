# SanMuQ6 技术说明（产品决策版）

> 撰写日期：2026-08-14。面向产品决策者，兼顾后续开发参考。
> 所有数值均从源码核实（`source/params`、`source/dsp`）。

---

## 1. 一句话定位

**六段参量 EQ**：零延迟模式（最小相位）+ 线性相位模式双引擎，精密仪表式玻璃 UI，
对标肥波 Pro-Q3 的操作习惯，并有三项自己的特色（见 §5）。

---

## 2. 信号链路

```
输入 ──→ 输入增益 L/R（±30dB）──→ 六段 EQ 级联 ──→ 输出增益 L/R ──→ 电平计算 ──→ 输出
                                        │
                                        ├─ Zero Latency 模式：最小相位 IIR（零延迟）
                                        └─ Linear Phase 模式：对称 FIR 4097 点卷积（64ms 延迟）
```

附加功能：相位反转、频段独听（Solo，带通隔离）、Post-EQ 实时频谱（32768 点 FFT）。

---

## 3. 两种处理模式（"线性还是非线性"的答案）

| | Zero Latency（默认） | Linear Phase |
|---|---|---|
| **相位特性** | 最小相位：相位随频响变化（所有 IIR EQ 的天然特性） | 线性相位：全频段相位差恒定，**无相位失真** |
| **延迟** | 0 ms | 3072 采样 ≈ 64ms @48kHz（宿主自动补偿） |
| **实现** | 双二阶 IIR 级联，6 段 × 2 声道 × 最多 4 级 | 从整链频响合成对称 FIR（4097 点，频率采样法 + Kaiser 窗），overlap-save 分块卷积 |
| **音色特点** | 传统模拟 EQ 味道；低频相位偏移会让瞬态有"糊"感 | 极端透明；相位零污染，适合母带与相位敏感素材 |
| **适用** | 混音、创作、实时性要求高的场景 | 母带处理、并联处理（parallel）、对相位敏感的录音 |
| **代价** | 无 | 64ms 延迟（宿主自动对齐，不影响操作）；低频极窄峰精度受 FIR 分辨率限制（见 §7 已知限制） |

**两种模式都保留**是刻意的：用户可随时切换（参数自动同步），不是"哪个更好"而是"哪个更合适"。

## 4. 滤波器家族与响应曲线（重点：你看到的"低切提升补充"）

### 4.1 五种滤波器

| 类型 | 说明 | 参数 |
|---|---|---|
| Bell（钟型） | 中心频率提升/衰减，最常见 | 频率、增益 ±30dB、Q 0.1-20 |
| Low Shelf（低频搁架） | 截止点以下整体抬升/压降 | 频率、增益、Q |
| High Shelf（高频搁架） | 截止点以上整体抬升/压降 | 频率、增益、Q |
| Low Cut（低切/高通） | 截止点以下切除 | 频率、Q（共振）、斜率 12/24/36/48 dB/oct |
| High Cut（高切/低通） | 截止点以上切除 | 频率、Q（共振）、斜率 12/24/36/48 dB/oct |

### 4.2 你看到的"低切时有一部分频率做了提升补充"——这是共振（Resonance）

低切曲线在截止点附近拱起的小山包，**不是 bug，是滤波器的共振特性**，由 Q 值控制：

- Q = 0.5：平滑过渡，无拱起（"巴特沃斯"手感）
- Q = 0.707：截止点处恰好 -3dB，微微拱起
- Q > 0.707：截止点处出现**提升峰**，Q 越大峰越高越尖（Q=7.9 时约 +18dB）

这是专业 EQ 的标准能力（肥波 Q3 也有，但 Q3 的 Cut **不允许自由调 Q**，斜率档位自带固定 Q≈0.5-0.7）。

**SanMuQ6 的特色做法**：允许自由调 Q，但加了**物理安全上限**（见 §5.2），既有创意空间又不损伤设备。

### 4.3 另一个隐藏细节：Cut 多级频率补偿

48dB/oct 陡坡由 4 个滤波器级联而成，级联会让"实际截止点"偏移标称频率。
我们做了数学补偿（修正因子 1.0/0.802/0.714/0.659），保证**你看到的频率刻度就是真实 -3dB 点**。
许多廉价 EQ 没做这个，陡坡的实际位置会漂。

## 5. 特色能力清单（差异化资产）

### 5.1 Cut 共振物理安全上限（独有）

多级级联的共振峰 = 20·log10(Q)×级数，无上限时 Q=20 × 4 级会产生 **100+dB 共振**——
振铃、失真、甚至损伤监听设备。我们按斜率收窄 Q 上限，保证共振峰 ≤18dB：

| 斜率 | 12 | 24 | 36 | 48 dB/oct |
|---|---|---|---|---|
| Q 上限 | 7.9 | 2.8 | 2.0 | 1.7 |

（对比：Q3 干脆不给自由 Q；DSP 教科书惯例是"陡峭度用级联、共振用低 Q"。我们是两者的折中。）

### 5.2 参数平滑（零爆音）

所有参数变化（拖动、滚轮、切类型、切模式）都经过系数级平滑过渡（每块 25%，约 70-90ms 完成），
**拖动过程中没有任何滋滋声/爆音**。LinearPhase 模式用频域逐帧平滑实现同样的效果。

### 5.3 LinearPhase 低频精度（4097 点 FIR）

线性相位 EQ 的通病：FIR 核短了，低频窄峰被"抹平"。我们用 4097 点核（频域分辨率 ~12Hz），
保证 34Hz 的 Q=1 提升可用（肥波 Q3 的高精度档也是类似思路，延迟翻倍换精度）。
代价是 64ms 延迟（Q3 高精度档延迟更大）。

### 5.4 延迟异步上报（防宿主静音）

切换模式时延迟变化（0 ↔ 64ms），在音频线程里直接上报会让部分宿主重建音频图导致**瞬间静音**。
我们异步上报，切换模式不断声。

### 5.5 交互特色（已由你逐轮验证）

- 三圈竖排旋钮 + 曲线手柄双入口；滚轮微调（粗调 + Shift 10 倍细调）
- 曲线区滚轮：Cut 切斜率（斜率联动 Q 手柄不跑）、Bell 调 Q
- ⌘+单击回默认、双击内联输入、值气泡、频谱+峰值保持
- 全部交互方向已按设备修正（触控板自然滚动、Shift 横滚映射）

## 6. 与肥波 Pro-Q3 对标

| 能力 | SanMuQ6 | Pro-Q3 |
|---|---|---|
| 段数 | 6 | 最多 24 |
| 线性相位模式 | ✅（64ms） | ✅（多档延迟可选） |
| Cut 斜率档 | 12/24/36/48 | 6/12/18/24/30/36/48/60/72/96 |
| Cut 自由 Q | ✅ + 安全上限 | ❌（档位固定 Q） |
| Cut 频率补偿 | ✅ | ✅ |
| 频谱显示 + 峰值保持 | ✅ | ✅ |
| 输入/输出独立 L/R 增益 | ✅ | 输出增益+Auto Gain |
| Solo 独听 | ✅（带通隔离） | ✅ |
| 相位反转 | ✅ | ✅ |
| **Dynamic EQ（动态处理）** | ❌ | ✅ |
| **Mid/Side 处理** | ❌ | ✅ |
| **Auto Gain（自动增益）** | ❌ | ✅ |
| **倾角 Tilt 模式** | ❌ | ✅ |
| **过采样选项** | ❌（无过采样） | 无（Q3 天然高内部精度） |
| 界面风格 | 精密仪表玻璃 | 扁平化 |

**结论**：核心 EQ 品质与操作手感已对齐 Q3；我们的特色在 Cut 共振玩法、低频精度与爆音控制。
Q3 的 Dynamic EQ / Mid-Side / Auto Gain 是**功能面**的差距（需要时可立项）。

## 7. 性能现状剖析

### 7.1 CPU 热点（从源码推算，未做 profile 实测）

| 热点 | 成本 | 触发时机 |
|---|---|---|
| LinearPhase 卷积 | 每块 2 声道 × 8192 点 FFT | LinearPhase 模式常驻 |
| LinearPhase FIR 重建 | 2048 频率点 × 6 段幅度计算 + 4096 点 FFT | 参数变化时（已节流 10 块一次） |
| 频谱分析 | 32768 点 FFT + 500 点对数带 RMS | 持续（每若干块一次） |
| ZeroLatency 级联 | 6 段 × 2 声道 × ≤4 级双二阶（很轻） | 默认模式常驻 |
| UI 绘制 | 玻璃渐变、曲线 500 点、三圈弧 | 30Hz 定时器全量重绘 |

**最大头的两块**：LinearPhase 模式（FFT 卷积 + 重建）和 UI 全量重绘（无脏区缓存）。

### 7.2 内存

LinearPhase 引擎全部工作缓冲在 prepare 时一次性预分配（约数 MB 级别），
处理路径**零动态分配**（不会产生内存碎片/GC 卡顿）。这点已经是良好状态。

### 7.3 加载

UI 全部为代码绘制（图标是内置贝塞尔路径，无外部资源文件），加载快、无资源缺失风险。

### 7.4 已知物理限制（非 bug）

34Hz + Q=10 的极窄峰在 LinearPhase 模式提升约 1.41 倍（理论上 3.98 倍）——
FIR 分辨率固有限制，已与你确认接受。

## 8. 候选性能优化方向（供你决策）

| 方向 | 预期收益 | 风险 |
|---|---|---|
| A. UI 脏区缓存（只重绘变化的区域/降低重绘频率） | 界面更流畅、CPU 显著下降 | 中（绘制逻辑改造） |
| B. LinearPhase 重建算法优化（缓存频响采样、增量重建） | 拖拽参数时 CPU 尖峰下降 | 低 |
| C. 频谱 FFT 降级档（32768→8192 可切换） | 省 CPU | 低（分辨率换性能） |
| D. ZeroLatency 路径微优化（SIMD/展开） | 小幅 | 低 |
| E. 内部处理精度/过采样（音质向，非性能向） | 高频质感提升 | 中，CPU 上升 |

**建议**：先做 A + B（体验感知最大），C/D 按需，E 属于音质路线需单独讨论。
