# LEV 0.1.2：取消前瞻，增加约 1 dB 压缩

用户在 Reaper 对比 0.1.1 后，要求取消前瞻以便录音使用，并略微增加压缩量，无需追平 RVox。

## 实现

- 删除 LEV 湿声、干声延迟线、峰值前瞻队列及均值窗口；同一采样输入、处理和输出。
- 删除整插件旁通补偿延迟线。四模式统一向宿主上报 0 个采样延迟，不在模式切换时动态修改延迟。
- 保留即时峰值包络：遇到峰值立即减小增益，随后按 50 毫秒时间常数恢复。与主体压缩选择更严格的增益，避免重复叠加衰减。
- 主体目标衰减在原曲线上增加 `1 − exp(−原目标衰减 / 2)` dB：正常压缩区接近增加 1 dB，接近零时连续减小，COMP=0 不额外压缩。自动补偿量没有增加，GAIN 仍独立控制输出。
- LEV 参数标识与范围保持兼容，更新模式提示、使用指南及 LISTEN 的 LEV 参数反算和说明。LISTEN 的分类与选型重设计仍暂停。

## 实际测量

1 kHz 正弦，COMP −20、GAIN −30、GATE 关闭；输入列为峰值，不是 RMS。

| 输入峰值 | 0.1.1 主体 GR | 0.1.2 主体 GR | 增加量 |
| --- | --- | --- | --- |
| −36 dBFS | 1.162 dB | 1.602 dB | 0.441 dB |
| −24 dBFS | 3.916 dB | 4.775 dB | 0.859 dB |
| −18 dBFS | 6.594 dB | 7.557 dB | 0.963 dB |
| −12 dBFS | 10.285 dB | 11.279 dB | 0.994 dB |

48 个静态点全部检查；原主体 GR 为 3～15 dB 的测试点增加 0.794～0.999 dB。增强量是电平相关的实际压缩，不是统一降低输出 1 dB。

同输入动态对照包含 30 毫秒、300 毫秒、2 秒强音、模拟音节强弱变化和 70 Hz 低频，前后共 90 段渲染。全部输出有限，全湿采样峰值检查通过。70 Hz、COMP −30 的稳态基波外残差由约 0.0372% 变为 0.0339%；这一个测试音不代表整体音质优劣。

**取消前瞻的代价**：从低电平突然跳到强音时，首个波峰可出现短暂平顶。即时控制无法提前安排平滑增益，不能把零延迟等同于任意素材都无失真。采样峰值限制也不等于采样间真峰值限制，MIX 干声不受湿声上限约束。

/tmp/sanmu-comp-check-au-latency
