# SanMu Comp — FET 经典极速瞬态压限器 官方使用指南

---

### ⚡️ 概述与设计理念

**FET**（Field Effect Transistor）基于经典传奇硬件 **1176 晶体管固态电路** 物理建模。

FET 压缩器以其**微秒级（20 μs）的超高速瞬态抓取力**与**标志性的中频爆发力（Punch & Grit）**闻名于世。它不是为了低调透明而生，而是混音师打造**坚如磐石的底鼓、穿透混音的军鼓、充满能量与嘶吼感的摇滚人声以及颗粒分明的电贝斯**的终极武器。

### 🎛️ 面板核心控件指南

```
┌─────────────────────────────────────────────────────────────────────────┐
│ [ INPUT 大盘 ] ── (🔗 LINK 桥) ── [ OUTPUT 大盘 ] ── [ RATIO / ATK / REL ] ── [ SC / HR / MIX ] │
└─────────────────────────────────────────────────────────────────────────┘
```

#### 1. INPUT 与 OUTPUT（驱动与输出补偿，1.0 ~ 40.0 硬件刻度）
- **INPUT**：顺时针推入可同时提升进入压缩器的信号电平与驱动深度。推入越多，压缩量越大，晶体管变压器饱和谐波越浓郁；
- **OUTPUT**：控制经过压缩衰减后的最终输出电平；
- **LINK 反向联动桥**：点击 Input 与 Output 之间的 `[🔗 LINK]` 按钮，调节 Input 时 Output 将自动进行反向等量补偿，在探索不同压缩量时始终保持试听响度一致，避免“声音变大误以为变好”的主观听觉误差。

#### 2. RATIO（压缩比率：4:1 / 8:1 / 12:1 / 20:1 / ALL）
- **4:1（温和适度）**：适合原声乐器与通用人声，保留自然动态；
- **8:1 / 12:1（经典打击档）**：适合军鼓与摇滚人声，提供强劲的中频击打感；
- **20:1 / ALL（全按钮狂暴限幅）**：将动态瞬间压平，激发极度凶猛的室音（Room Sound）与爆炸性泛音。

#### 3. ATTACK（启动速度，1 ~ 7 经典反向刻度）
- **特性**：遵循硬件经典反向刻度——**刻度 1 最慢（约 1.6 ms），刻度 7 最快（约 20 μs）**；
- **混音建议**：
  - **打击乐瞬态保留**：建议设为 `3 ~ 4`，让鼓槌敲击鼓皮的初始“拍头（Transient）”完全穿透过去，随后紧紧压住鼓腔余音；
  - **人声瞬态驯服**：建议设为 `5 ~ 7`，快速抓取突发高频齿音与尖锐动态。

#### 4. RELEASE（释放时间，1 ~ 7 经典反向刻度）
- **特性**：遵循硬件经典反向刻度——**刻度 1 最慢（约 1200 ms），刻度 7 最快（约 45 ms）**；
- **默认值**：出厂默认标定为 **`4.0`（约 230 ms 黄金通用档）**；
- **混音建议**：
  - **快释放（5 ~ 7）**：快速复位，增强鼓组踩镲的延音与房间吸气感，带来浓郁的泵吸律动；
  - **中/慢释放（3 ~ 4）**：平滑复位，让人声与贝斯极其稳健扎实，毫无抽吸杂音。

#### 5. SC HP（侧链高通滤波，OFF / 60Hz / 90Hz / 150Hz / 250Hz）
- **功能**：高通滤波侧链控制信号，避免低频大能量（如底鼓低音）过度触发压缩导致中高频被暗中压低。

#### 6. HEADROOM（动态余量，4 ~ 28 dB，默认 16 dB）
- **功能**：调节模拟放大电路的饱和染色灵敏度。数值越小，模拟温暖饱和与微过载越明显。

#### 7. MIX（并行干湿比，0% ~ 100%）
- **功能**：经典“纽约平行压缩法”。将比率设为 `20:1` 或 `ALL` 极度压缩后，通过 MIX 旋钮混合 30%~50%，瞬间获得饱满巨大的击打力同时保留 100% 动态细节。

### 💡 经典实战应用场景

| 应用场景 | RATIO | ATTACK | RELEASE | 侧链 SC | 听感目标 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **底鼓 / 军鼓 Punch** | `4:1 或 8:1` | `3 ~ 4` (较慢) | `5 ~ 6` (较快) | `90 Hz` | 敲击拍头硬朗穿透，鼓腔饱满有力 |
| **摇滚 / 说唱主唱** | `4:1` | `5` | `4` | `60 Hz` | 人声充满张力与穿透力，咬字坚实 |
| **电贝斯颗粒感** | `4:1` | `3` | `3 ~ 4` | `150 Hz` | 低音根音坚如磐石，中高频弹拨细节鲜明 |
| **鼓组平行总线 (All Buttons)**| `ALL (20:1)` | `7` (最快) | `7` (最快) | `OFF` | 激发爆炸般的室音与能量感 (MIX 40%) |

### ⚡️ 快捷操作秘籍
- **双击旋钮**：瞬间复位至出厂黄金默认值；
- **按住 Shift 拖拽**：进入 $0.1$ 刻度高精度微调模式；
- **单击数值框**：直接使用键盘输入目标数值。
