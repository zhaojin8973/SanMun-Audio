## 曲线为何调整

原来的输入输出电平和 GR 共用 0～60 的纵轴；常见浅压缩不容易观察，dBFS 和衰减 dB 的含义也混在一起。本轮改为：

| 区域 | 数据及行为 |
| --- | --- |
| 上方 GR | 增益衰减，独立 6／12／24 dB 显示范围；默认 12 dB |
| 下方 IN／OUT | 输入与输出采样峰值，−60～0 dBFS；输入虚线、输出实线 |
| 时间轴 | 最近两秒，按实际显示时间戳定位，不再仅靠帧数推断时间 |
| 图例按钮 | 分别显示或隐藏对应曲线，不改变声音 |
| 暂停 | 冻结历史供检查；实时电平继续。恢复时清除过期历史，重新采集 |
| 悬停 | 查询同一历史点的时间、输入、输出及 GR |
| 清除峰值 | 清除峰值保持和输入／输出过载标记；普通点击图形不清除 |
| 显示设置 | 关闭曲线后隐藏历史，电平继续；重开不显示过期冻结画面 |

GR 超出所选范围时曲线触及显示边界，实时 GR 数字仍显示真实值，并显示超范围提示。输入／输出为采样峰值，不宣称为真峰值、响度或示波器；不能把两条电平线的差值当作 GR。
