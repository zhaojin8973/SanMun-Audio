## 对用户提出问题的明确答复

| 项目 | 当前实现与证据 |
| --- | --- |
| 四模式独立 | LEV 使用 `vox_mix`，VCA 使用 `vca_mix`，FET 使用 `fet_mix`，Opto 使用 `opto_mix`。侧链频率、输出微调、立体声联动均按适用模式分别存储和路由。 |
| 旧通用 MIX | 保留旧参数 ID 和原参数位置，用于旧工程迁移；不参与活动引擎处理。旧工程缺少 FET/Opto MIX 时分别复制旧值，已有独立值不覆盖。旧 MIX 自动化曲线不会持续驱动新参数，需要用户在宿主改绑。 |
| 无共用引擎处理代码 | `CompressorEngine.h` 仅保留抽象接口。FET、VCA、Opto、历史 Clean 各自在本翻译单元定义侧链滤波和分贝转换；VOX 本身独立。JUCE 基础库、参数容器、调度器、旁通和计量基础设施仍为插件公共设施，不属于四引擎的压缩算法。 |
| 反馈拓扑 | FET/Opto 从上一采样的衰减后、补偿前信号检波；输出增益、干湿混合不回灌检测。FET 使用反馈平衡所需的 `R-1` 斜率。Opto 的 COMP/LIMIT 使用不同软拐和反馈斜率，并限制最大目标衰减。 |
| LISTEN | 主按钮、倒计时和帮助统一为 10 秒；仍为本地特征规则，不发送音频到云端。移除固定置信度百分比，规则结果不再标为高置信。真实素材准确率没有测量结果。 |

## 其他已修复内容

- 编辑器参数回调仅设置原子刷新标志，由界面定时器更新布局，避免音频线程分配界面消息及悬空回调。
- 分析完成使用对象所属定时器和待处理标志；销毁时停止定时器。采集音频线程仅尝试取得缓冲区所有权，失败立即返回，不等待；分析与重新采集不会同时访问缓冲区。
- 特征计算使用中侧声道总能量，峰值还原左右声道，频谱分别累加中侧能量；反相立体声不再相消为静音。空采集也完成回调。
- 虚拟 DSP 校准通过同一段最多三秒立体声音频、多次分块渲染寻找输出设置；量化后再次验证。记录目标、实际峰值和是否可达，无法达到的情况不宣称成功。
- 工厂预设、AI 推荐仅写入目标模式；修复预设快照未声明变量和首次切 B 时丢失 A 的问题。用户预设和宿主状态均执行旧参数迁移，用户预设检查根类型。
- LEV 前瞻延迟为 128 采样；插件旁通和宿主旁通使用相同延迟，活动引擎继续推进状态。切换模式重置被激活引擎的旧包络和旧延迟内容。
- LEV 限幅峰值检测包含当前输出的延迟采样，并增加最终增益约束，修复强脉冲穿透设定上限。
- 输入/输出峰值保留两次界面刷新之间的最大值；GR 曲线、网格和竖表统一为 60 dB。GR 仍为引擎块末包络读数，不声称逐采样峰值或真峰值计量。
- 单声道转立体声复制输入到右声道；插件入口清除非有限浮点，避免污染后续状态。
- 构建支持关闭安装和发布签名。AAX 签名只操作指定产物，凭据来自环境，不再删除资源或改变钥匙串授权。旧脚本曾含明文凭据：移除当前文件不删除历史副本，凭据轮换由持有人处理。

## 验证结果

插件主体及 VST3、AU、AAX 均编译成功。AAX 未执行 PACE 发布签名，不能将本次编译视为正式 Pro Tools 加载验收。

CTest：7/7 通过。最终日志保存在 `docs/verification/2026-09-10/`。新增 `test_plugin_integration` 直接链接插件主体，覆盖：

- 参数路由、工厂预设/推荐隔离、旧 MIX 迁移、已有独立参数保持、A/B 首次切换。
- 编辑器创建/销毁、其他线程参数通知、待完成分析销毁。
- 四模式、单/双声道、两种旁通、128 采样延迟；单声道扩展；异常浮点；刷新间峰值。
- 十秒采集、无音频提前停止、反相立体声峰值/RMS/频谱。
- 四引擎整块与 257 采样分块输出一致。
- 44.1/96/192 kHz 下 FET 四比一反馈稳态曲线、Opto 压缩量单调和 LIMIT 强度。
- 44.1/48/96/192 kHz 下 LEV 强脉冲湿声限幅上限。

原声学回归包含 12 组合成素材，不能用于推导真实乐器准确率。旧双方案测试已改为当前单方案接口；军鼓用例原来错误断言为底鼓已修正；Release 测试启用断言，声学测试失败会返回失败状态。

## 交接边界

本轮列出的代码缺陷已修复并通过上述自动检查。FET/Opto 拓扑改变会影响旧预设听感；参数迁移保留设置，不能保证旧工程逐采样音色一致。宿主需检查模式切换延迟更新、自动化、保存恢复、旁通与真实素材听感。动态切换延迟不承诺无缝无咔嗒。

没有实机传递曲线、失真谱或盲听对照，不能称为准确复刻 1176/LA-2A。LEV 约束的是湿声采样峰值，干声混合及数模重建真峰值不受该保证覆盖。

LISTEN 分析和多轮校准目前在消息线程执行，可能短暂影响界面响应；不占用音频处理线程。真实素材分类评测和耗时基准仍需单独建立，当前不作准确率或毫秒级性能承诺。

硬件拓扑参考：[Universal Audio 2-1176 手册](https://media.uaudio.com/assetlibrary/2/-/2-1176_manual.pdf)、[LA-2A 手册](https://media.uaudio.com/assetlibrary/l/a/la-2a_manual.pdf)。这些资料支持拓扑设计方向，不证明当前数字实现与硬件等效。
