# LEV 命名与压缩力度调整（2026-09-14）

LEV 继续作为 Leveler（电平平准器）的缩写，界面说明采用“LEV · Adaptive Leveler / LEV · 自适应电平平准器”，避免被理解为普通阈值压缩器。

`vox_comp` 对外 0～36 dB 参数范围、参数 ID、预设兼容性保持不变。内部力度改为渐进映射：`effective = amount + 0.25 × amount × (1 − amount / 36)`，并限制在 36 dB。这样 0 dB 行为不变，约 10 dB 已进入可感知平准区，高值逐渐回到原上限，避免把中高段整体推得过激。

实测 48 kHz、1 kHz、输入峰值 −18 dBFS、Gain −30 dB：Compression 6 / 12 / 20 dB 的主体 GR 约为 2.66 / 6.40 / 8.96 dB；Compression 0 dB 保持 0 dB 主体 GR。

`test_dynamic_behavior` 与 `ui_redesign` 共 2/2 通过；三格式重新构建、签名、安装及文件校验通过。旧包备份位于 `/Users/zhaojin/Library/Application Support/SanMu Audio/Plugin Backups/comp-lev-20260914-155539`。

本轮调整涉及 LEV 的内部力度映射和对应回归基线，不改变其它压缩模式、延迟、参数接口或 LISTEN 流程。
