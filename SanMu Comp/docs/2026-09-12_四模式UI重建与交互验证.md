# SanMu Comp 0.1.11：四模式界面重建

## 本轮结论

用户否定了 0.1.10 沿用旧布局、近似系列外观的做法。本轮重新搭建编辑器，直接复用已完成 Reverb 的离线网页界面技术、玻璃样式、旋钮绘制与公共图标；旧原生旋钮面板不再进入正式插件。四模式通过控件次序、大小和分组保留各自的调节习惯，不使用硬件贴图或 VU 表。

0.1.11 的 AU、VST3、AAX 已构建。当前已安装的三个格式仍是 0.1.9；本轮没有替换它们。新 AAX 尚未进行 PACE 发布签名。自动检查通过不代表已完成宿主视觉或听感验收。

## 设计与交互

| 模式 | 新主操作区 | 参考的操作习惯 |
| --- | --- | --- |
| VCA | 横排阈值、比例、启动、释放、补偿；常用比例与启动值可快捷选择 | 总线压缩器依次设置工作点、压缩形状与输出补偿 |
| FET | 输入／输出双大旋钮，启动／释放上下排列，右侧纵向比例键 | 1176 的输入驱动、输出补偿和快速时间控制 |
| Opto | 左侧增益、右侧压缩量双大旋钮，中间压缩／限制切换 | LA-2A 的双主控布局 |
| LEV | 大压缩量主控、输出增益、明确的平滑开关；底部仅门限与混合 | 少量主要操作完成电平整理，并可选择零延迟或平滑 |

四模式共用字标、预设条、撤销／重做、A/B、旁通、LISTEN、设置和曲线区。颜色用于区分模式，材质和操作规则相同。FET 与 Opto 保留熟悉的控制结构，但不加入原实现不存在的硬件功能。

`ui/shared/reverb.css` 与设计系统 Reverb 快照逐字相同，SHA-256 为 `850d0f8abe9fadff10cf34796a3a051538ce96df710e7ea847a6b947e6111a32`。旋钮从同一快照的绘制函数提取，仅适配参数归一化入口；图标使用 Reverb 安装的 Lucide 1.42.0 图标数据，保留许可。Comp 自身的布局由 `ui/comp.css` 提供。

旋钮统一垂直拖动，Shift 精调，拖至边界后反向立即响应；支持键盘、直接数值输入、双击或修饰键复位。非法输入保留原值并显示提示。失焦、释放指针和关闭窗口都会结束宿主参数手势。FET 输入／输出联动仅响应用户编辑，不反写宿主自动化。

VCA 释放显示使用引擎现有的 AUTO 边界：达到 1200 毫秒即显示自动，切换按钮使用原有的 2000 毫秒值。LEV 未显示历史遗留但不进入处理链的立体声联动与输出微调参数，保留其参数身份以兼容工程。

## 曲线与电平

保留两秒历史，上方独立显示增益衰减，可选 6／12／24 dB 刻度；下方输入／输出采用 −60～0 dBFS。输入虚线、输出实线，支持悬停读数、显示开关、暂停／恢复和明确的清峰值动作。

暂停只冻结历史，实时电平继续更新。数据传递继续使用 0.1.9 修复后的有效读数保持，音频块间没有新数据时不会误画静音。电平颜色只显示实际达到的区段，低电平不会带红色顶端。

## 实现范围与兼容性

编辑器使用 JUCE 的离线网页容器，资源打包进插件，不依赖本地预览服务器。网页只能访问自身资源，桥接层验证命令、参数身份、类型、有限值与范围；参数范围、步长、默认值由真实参数状态树提供。

新增 A/B 复制到另一槽的动作；外观、显示开关、窗口缩放与 LISTEN 目标仍独立于声音快照。预设按模式搜索和切换。LISTEN 沿用当前算法，固定当前引擎、手动目标、五秒采集；保留复用录音、取消、应用、撤销和后台计算期间的手动编辑保护。自动分类与 AI 服务入口继续停用。

本轮开始时的 20 个 DSP、参数和助理源码文件哈希全部保持不变。`prepareToPlay`、`releaseResources`、`processBlock`、`processBlockBypassed`、`processAudio` 五个音频函数逐字不变。Git 工作区包含此前已授权但尚未提交的声音修改，不能用相对 Git HEAD 的总差异冒充本轮改动。
