# SanMu Comp — VCA 模拟总线胶水压限器 官方使用指南

---

### 🎛️ 概述与设计理念

**VCA**（Voltage Controlled Amplifier）基于传奇英国 **4000G 经典模拟大型混音台 Master Bus 压缩器** 物理建模。

在现代音乐制作中，VCA 压缩器被公认为**“总线胶水（Bus Glue）”之王**。无论您的工程里有几十轨乐器、鼓组还是和声，经过 VCA 压缩器的凝聚与洗礼，原本离散的各音轨都会瞬间“粘合”在一起，伴随着音乐节拍自然呼吸，呈现出商业黑胶/CD 唱片特有的统一性、密度感与开阔立体声像。

### 🎛️ 面板核心控件指南

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ [ THRESH ] ── [ ATTACK ] ── [ RELEASE (AUTO) ] ── [ RATIO ] ── [ SC ] ── [ MAKEUP ] ── [ MIX ] │
└─────────────────────────────────────────────────────────────────────────────┘
```

#### 1. THRESHOLD（压缩启动门限，-60 dB ~ 0 dB）
- **功能**：设定压缩器开始介入的电平门限。
- **混音黄金法则**：在母带/混音总线上，**通常建议调节 THRESHOLD 使表头产生 1.5 dB ~ 3.5 dB 的轻微衰减（Gain Reduction）**，即可获得完美的胶水凝聚力而绝不破坏整体动态。

#### 2. ATTACK（启动响应时间：0.1 / 0.3 / 1 / 3 / 10 / 30 ms）
- **混音建议**：
  - **30 ms（总线推荐/最通透）**：让全曲所有乐器的初始瞬态（如底鼓拍头、军鼓敲击、原声吉他弹拨）完美通过，随后压缩平滑贴合；
  - **10 ms（经典适度冲击）**：标准现代流行总线设置；
  - **0.1 ~ 1 ms（快速峰值控制）**：适合独立乐器音轨，快速压制毛刺动态。

#### 3. RELEASE 与 AUTO 胶囊（释放时间：0.1 / 0.3 / 0.6 / 1.2 s 与 AUTO）
- **AUTO 自动释放胶囊（混音师最爱）**：
  - 点击 Release 旋钮内的 `[AUTO]` 胶囊，即可开启**智能自适应双阶段释放**；
  - 遇到短促瞬态击打时极速复位避免吞音；遇到长音符与和弦铺底时自动转为平缓长释放，彻底消除生硬的喘息与抽吸声，随歌曲节拍浑然天成。

#### 4. RATIO（压缩比率：2:1 / 4:1 / 10:1）
- **2:1（温和母带总线）**：最平滑的软拐曲线，混音母带首选，动态几乎不受压抑；
- **4:1（标准打击总线）**：适合摇滚、流行鼓组总线，增强击打力度；
- **10:1（紧凑压限）**：适合平行压缩或大动态收敛。

#### 5. SC HP（侧链高通滤波，OFF / 60Hz / 90Hz / 150Hz / 250Hz）
- **功能**：滤除进入检波电路的超低频能量，避免重低音或 808 贝斯导致全曲中高频被盲目压缩。

#### 6. MAKEUP（增益补偿，-24 dB ~ +24 dB）
- **功能**：补偿经过 VCA 压缩衰减后的主观响度损失。

#### 7. MIX（并行干湿比，0% ~ 100%）
- **功能**：全湿胶水粘合（100%）或平行总线混音（60%~80%）。

### 💡 经典实战应用场景

| 应用场景 | RATIO | ATTACK | RELEASE | 衰减建议 (GR) | 听感目标 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **全曲母带总线 (Master Bus)** | `2:1` | `30 ms` | `AUTO` | `1.5 ~ 3 dB` | 完美的唱片级胶水感与开阔呼吸律动 |
| **鼓组总线 (Drum Bus)** | `4:1` | `10 ms` | `0.3 s` | `3 ~ 5 dB` | 踩点结实、军鼓与踩镲紧密一体 |
| **原声吉他 / 弦乐群组** | `2:1` | `30 ms` | `AUTO` | `2 ~ 4 dB` | 层次分明、平滑丝滑且无毛刺 |
| **现代舞曲 EDM / 嘻哈总线** | `4:1` | `30 ms` | `0.1 s` | `2 ~ 4 dB` | 强烈的现代律动感与贴脸能量 |

### ⚡️ 快捷操作秘籍
- **双击旋钮**：瞬间复位至出厂黄金默认值；
- **按住 Shift 拖拽**：进入高精度微调模式；
- **单击数值框**：直接使用键盘输入目标数值。
