## Trim 审计结论

VCA、FET、Opto 三模式的信号流正确，无需修改。

1. `PluginProcessor.cpp` 按当前模式读取对应的 `vca_output_trim`、`fet_output_trim` 或 `opto_output_trim`。
2. `CompressorProcessor::setOutputTrim` 只将数值写入当前模式的独立引擎。
3. 三个引擎均在压缩声与原声混合后乘一次 Trim 增益，Trim 不回送检测器或改变 GR。Opto 的 Trim 参数含约 5 ms 平滑。
4. 插件 BYP 与宿主旁通输出原始输入，跳过 Trim；最终 OUT 电平采集在处理／旁通选择后。
5. LEV 没有公开的独立 Trim；其历史遗留全局参数不用于三模式的当前输出调节。

## 数值验证

新增真实插件处理器信号流回归，使用左右不同频率、幅度及强弱段的本机合成素材。先通过单组 VCA 基线，再扩展：

- 三模式 × 两个采样率（44.1 / 96 kHz）× 两个块长（64 / 257）× 三种 Mix（0 / 37 / 100%）× 三种 Trim（−18 / +6 / +18 dB），共 108 组。
- 经过初始平滑收敛后，对照 0 dB Trim 的完整处理器波形，验证最终输出按指定增益缩放。
- 未选模式的 Trim 及旧全局 Trim 设置不同值，验证其不会污染当前模式。
- 最大相对波形误差约 9.86e−8；最大 GR 差 0 dB。素材确认实际触发压缩。
- 所有组合均验证插件 BYP 与宿主旁通，未残留 Trim 增益。

这是信号流与数值正确性核查，不是动态自动化无噪声或音质验收。
