# LISTEN 0.1.6：VCA 通用回退

本轮根据宿主实测“自动选型几乎不使用 VCA”调整 LISTEN 助理层。四个 DSP 引擎及引擎接口没有修改。

## 问题与规则

0.1.5 的候选评分把 VCA 主要视为混音或总线选择；普通乐器与持续音色的 Opto 偏好明显更强。因此，即使 VCA 的实际压缩深度和输出电平合格，它也几乎没有选择机会。

0.1.6 使用以下规则：

- 明确推测为人声或旋律主奏：比较四个候选，LEV 保持主要偏好。
- 明确推测为打击乐或低频打击乐：比较四个候选，FET 保持主要偏好。
- 明确推测为混音或总线：比较四个候选，VCA 保持主要偏好。
- 推测为乐器或持续音色、合唱或持续旋律待确认：自动选型直接使用 VCA 作为中性通用起点，仅校准 VCA。
- 用户固定当前引擎时，固定选择优先于通用回退；不得切换引擎。
- 用户指定压缩量但未固定引擎时，待确认类别仍使用 VCA，并保持用户目标。VCA 达不到目标或电平／峰值条件时保留原参数，不换引擎、不降低人工目标。

这里的“待确认”是本地分类器返回的显式歧义类别。当前系统没有经过统计校准的置信度百分比，因此不能声称“低于某个百分比”。规则是确定性的，同一捕获和参数会得到相同选择，不引入随机概率。

## 复测结果

使用与 0.1.5 相同的 33 条鼓／乐器片段和 38 条人声片段重新计算：

| 素材类别 | 数量与选择 |
| --- | --- |
| 明确打击乐／低频打击乐 | 14 条，全部选择 FET |
| 乐器或持续音色待确认 | 16 条，全部选择 VCA |
| 合唱或持续旋律待确认（原分轨） | 3 条，全部选择 VCA |
| 明确人声或旋律主奏 | 30 条，全部选择 LEV |
| 合唱或持续旋律待确认（人声集） | 8 条，全部选择 VCA |

71 条方案全部通过可应用条件。33 条鼓／乐器的目标主体 GR 最大误差约 0.33 dB，输出有效电平差约 +0.10～+0.20 dB；38 条人声的目标主体 GR 最大误差约 0.05 dB，输出有效电平差约 +0.10～+0.20 dB。

最终 CTest 9/9 通过，新增覆盖：待确认类别仅计算 VCA、人工目标保持不变、用户固定 Opto 覆盖 VCA 回退、不可达人工目标不换引擎也不降低目标。

证据位于 `docs/verification/2026-09-11/listen-vca/`：`instrument-final.json`、`vocal-final.json`、`ctest.txt`、`installation.json`、`auval.txt` 与 `installed-au-latency.txt`。
