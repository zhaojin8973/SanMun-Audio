# SanMu Comp — LEV 使用指南

适用版本：0.1.3，2026-09-11。

LEV 默认使用零延迟，通过连续压缩、随持续时长变化的恢复和自动补偿收紧动态。可开启“平滑 / SMOOTH”，以约 12 毫秒延迟换取更缓和的增益变化。是否适合当前轨道，仍由素材和听感决定。

## 控件

| 控件 | 范围 | 作用 |
| --- | --- | --- |
| COMP | −36～0 dB | 向下增加压缩和自动补偿；刻度不是实际衰减量。输入电平也直接影响触发深度。0 时没有主体压缩。 |
| GATE | −80～0 dB | 低于门限时逐渐衰减，−80 关闭门控。它按电平工作，不识别人声、呼吸或噪声种类。 |
| GAIN | −36～0 dB | 压缩和峰值控制之后的输出衰减，不反向改变检波或压缩深度。 |
| MIX | 0～100% | 原始干声与处理后湿声的并联比例；100% 为全湿。干湿始终使用同样的延迟。 |
| 平滑 / SMOOTH | 关／开 | COMP 左侧的开关。关闭为零延迟；开启同时平滑主体压缩与峰值控制，增加约 12 毫秒延迟。默认关闭。 |

GR 显示门控、主体压缩与额外峰值控制产生的总衰减，不等于 COMP 刻度。

## 调整方法

1. 先关闭 GATE，MIX 设为 100%，播放轨道中有代表性的强弱段落。
2. 逐渐向下拉 COMP，结合 GR 和听感判断动态是否收紧，避免只照抄另一条轨道的刻度。
3. 用 GAIN 对齐旁通前后的主观音量，再判断压缩是否合适。自动补偿不保证与旁通自动等响。
4. 如需保留更多原始起音，可降低 MIX；最后按实际底噪决定是否开启 GATE，并检查弱字和句尾。
5. 已有适量压缩后，比较平滑开关对辅音、短促强音和句间衔接的影响。不要仅比较整体音量；持续平稳的声音可能差别较小。

## 两种工作方式

关闭平滑时，插件增加的延迟为 0 个采样，使用 0.1.2 的处理行为，适合优先控制监听延迟的录音场景。声卡缓冲、驱动和其他插件仍会影响监听总延迟。

关闭时，峰值控制在尖峰发生时立即衰减，突发尖峰可能较硬。开启时，插件缓冲约 12 毫秒音频，同时把主体和峰值控制的增益变化展开成渐变，减少突发增益跳变。它不滤掉高频来制造暗淡听感，也不额外增加固定输出增益。

平滑不是在所有素材上都更好：起音可能更柔和、冲击感也可能降低。选择需要的动态性格即可。切换时有约 5 毫秒内部过渡，宿主仍需重算延迟补偿；建议停播切换后再作听感比较。平滑开启时，MIX 干声及旁通均保留相同延迟以保持对齐。

全湿输出的采样峰值限制在接近 GAIN 对应的上限。它不保证采样间真峰值，也不限制并联混入的原始干声。GAIN 用于最终电平匹配，并非响度目标。

相比 0.1.1，本版在正常压缩区增加约 1 dB 主体衰减；轻压缩区的增加量平滑减小，COMP 为 0 时不额外压缩。启动与恢复的基本设计保留。
