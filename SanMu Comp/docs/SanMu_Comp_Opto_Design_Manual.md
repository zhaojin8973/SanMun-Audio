# SanMu Comp — Opto 温润光电管机压限器 官方使用指南

---

### 🕯️ 概述与设计理念

**Opto**（Optical Tube Leveler）基于传奇经典 **LA-2A 光电管（T4B）与 12AX7 电子管放大电路** 物理建模。

自 1960 年代诞生以来，Opto 光电压缩器凭借其**“多阶段光物理释放”**与**“电子管温暖平准”**成为了无数录音大师处理人声、贝斯、弦乐与管乐的至尊之选。它没有繁琐复杂的 Attack 和 Release 设置，光敏元件与发光面板的天然物理特性使得它**面对任何音频都能以最柔顺、最符合人耳听觉心理学的方式平滑过渡**。

### 🎛️ 面板核心控件指南

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ [ GAIN 输出增益大盘 ] ── [ COMP / LIMIT 拨档 ] ── [ PEAK RED 压减大盘 ] ── [ SC / MIX ] │
└─────────────────────────────────────────────────────────────────────────────┘
```

#### 1. GAIN（输出补偿增益，0.0 ~ 100.0 硬件刻度）
- **功能**：控制 12AX7 电子管输出放大电路的增益；
- **刻度参考**：硬件刻度 **`40.0` 对应 0 dB Unity Gain（无增益改变）**。根据压减衰减量适度顺时针推入即可补偿响度。

#### 2. PEAK REDUCTION（压减量大盘，0.0 ~ 100.0 硬件刻度）
- **功能**：Opto 引擎的核心控制盘。顺时针拧动即加大驱动发光面板的电平，从而使光敏电阻导通产生增益衰减；
- **混音建议**：
  - **刻度 20 ~ 35（轻柔平准）**：产生 1 ~ 3 dB 衰减，为人声增添温暖丝滑的电子管色泽；
  - **刻度 40 ~ 55（主唱经典黄金档）**：产生 3 ~ 6 dB 衰减，人声如丝绒般温润贴耳；
  - **刻度 60 ~ 80（深层限制）**：用于控制动态极大的贝斯或管乐。

#### 3. COMPRESS / LIMIT（经典双档拨档开关）
- **COMPRESS（约 3:1 柔顺平准，人声首选）**：
  - 拥有极顺滑的软拐特性，主要用于动态平准与声音润色；
- **LIMIT（约 10:1+ 强力峰值限制）**：
  - 拐点更陡峭，适合大动态乐器（如斯拉普贝斯、突发铜管）的峰值防爆。

#### 4. SC HP（侧链高通滤波，OFF / 60Hz / 90Hz / 150Hz / 250Hz）
- **功能**：低切侧链信号，保护光敏元件免受过强超低频的过度激发。

#### 5. MIX（并行干湿比，0% ~ 100%）
- **功能**：支持将温暖的电子管光电压限信号与原始纯净信号按比例混合。

### 💡 经典实战应用场景

| 应用场景 | 模式拨档 | PEAK RED | 衰减建议 (GR) | 听感目标 |
| :--- | :--- | :--- | :--- | :--- |
| **爵士 / 民谣 / R&B 人声** | `COMPRESS` | `35 ~ 50` | `3 ~ 5 dB` | 丝绒般细腻、温暖且极具亲和力 |
| **木贝斯 / 无品贝斯** | `COMPRESS` | `40 ~ 55` | `4 ~ 6 dB` | 延音丰满连贯，低频温厚无突兀跳跃 |
| **钢琴 / 弦乐重奏** | `COMPRESS` | `25 ~ 40` | `2 ~ 3 dB` | 动态自然受控，消除生硬的击弦毛刺 |
| **铜管 / 萨克斯 Solo** | `LIMIT` | `45 ~ 60` | `4 ~ 7 dB` | 驯服高音爆破瞬态，音色饱满圆润 |

### ⚡️ 快捷操作秘籍
- **双击旋钮**：瞬间复位至出厂黄金默认值；
- **按住 Shift 拖拽**：进入高精度微调模式；
- **单击数值框**：直接使用键盘输入目标数值。
