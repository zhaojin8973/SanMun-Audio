## FET

以下均为 48 kHz、输入峰值 -6 dBFS、20:1、最快启动和释放、INPUT 18、OUTPUT 24、HEADROOM 16、全湿、侧链高通关闭。

| 频率 | 修改前基波外残差 | 修改后基波外残差 |
| --- | ---: | ---: |
| 50 Hz | 26.79% | 7.44% |
| 100 Hz | 15.59% | 4.37% |
| 1 kHz | 14.28% | 0.55% |
| 10 kHz | 4.64% | 0.26% |

100 Hz 的增益纹波由约 6 dB 降到约 1.3 dB；原有快速振荡和强音启动时接近 60 dB 的衰减过冲在对应测试中消失。注意：50 Hz、深压缩、最快释放仍有显著周期调制，这部分需要听测，不承诺零失真。

原实现的检波、`R-1` 斜率、单采样反馈延迟、固定 60 微秒/3 毫秒增益跟随器叠加形成高闭环增益。新实现使用一个分贝衰减状态，求解：

```text
g = (base + k * F(level - g)) / (1 + k)
base = 上一衰减状态 * 释放系数
F 的直线段斜率 = R - 1
level - g = 当前受控侧链输出电平
```

侧链高通先作用于侧链分支，该分支的衰减后电平参与同采样反馈方程。它不是读取上一音频采样再追加增益平滑，也不等于在硬件电路中逐个建模元件。软拐段使用二次方程解析解；直线段用闭式解，保证固定运行成本。

启动范围改为 20~800 微秒，释放范围改为 50~1100 毫秒，顺时针变快。上述数值是控制时间常数，不是达到最终衰减的总时间；单采样时间仍限制离散时间分辨率。当前释放是固定时间常数，尚未加入有实测依据的 1176 程序依赖模型。[UA 操作手册](https://help.uaudio.com/hc/en-us/articles/4419447352980-UA-1176-Classic-Limiter-Collection-Manual)

移除未经校准的输出饱和与 18 kHz 低通。OUTPUT 仅作线性补偿，INPUT/OUTPUT 按 5 毫秒平滑，跨采样率一致；低端原有跳变改为连续映射。4:1、8:1、12:1、20:1 的静态斜率有回归检查。ALL 当前只是不同阈值和更宽软拐，不能称为准确的全按钮电路或染色复刻。

## LEV

信号链：下扩展门 → RMS 主体压缩 → 曲线匹配补偿 → 前瞻限幅 → GAIN → 干湿混合。

- COMP 从 0 向 -36 dB 调整时，连续降低阈值，并将比例从 2:1 向 8:1 调整；0 为不压缩。移除 `0.25 * COMP` 的主体衰减上限。
- 自动补偿取该压缩曲线在 0 dBFS 标定点的衰减，取消独立的 1:1 固定抬升。主体使用 10 毫秒 RMS 检波、8 毫秒增益启动、80/600 毫秒恢复分量；这些是明确的行为设计参数，不冒充器件常数。
- GAIN 保持限幅后线性衰减语义，稳态全湿采样峰值上限随之降低。降低 GAIN 不减少内部限幅深度，这与 RVox 手册中部分交互描述不同，不声称相同。
- 前瞻用于限制压缩、补偿后的峰值，不宣称预知音乐内容或让主体压缩自动更准确。固定约 2.67 毫秒，44.1/48/96/192 kHz 分别为 118/128/256/512 采样。
- 最小允许增益的单调队列配合窗口平均形成提前衰减斜坡，移除末端逐采样硬增益约束；峰值上限针对采样峰值，不是真峰值。干声混合不受湿声峰值上限约束。
- 同步宿主延迟上报、插件旁通、宿主旁通和干湿延迟。参数 ID 保持，旧工程可加载，但声音已改变，需要重新听测旧预设。

例：COMP -24、GAIN -12，输入从 -24 升到 -12 dBFS，旧输出从 -21.18 升到 -15.02 dBFS，新输出从 -19.65 升到 -17.03 dBFS。新实现强音的主体衰减约 10 dB，稳态限幅衰减低于 1 dB，不再由后端限幅器承担主要压缩。

RVox 本身包含自动补偿与限幅，两者同时存在不是缺陷；问题是职责与曲线是否合理。[Waves 官方手册](https://assets.wavescdn.com/pdf/plugins/renaissance-vox.pdf)

## VCA

增益包络释放到当前目标衰减，不再在仍需压缩时向零释放。下降到非零目标的恒定输入测试验证单调收敛；原有 10 毫秒 RMS 与启动旋钮的级联仍保留，因此旋钮并不等于整个系统捕捉峰值的时间。

高输出复核额外发现：比例 1:1、输入峰值 0 dBFS 时，原输出补偿 0/+12/+24 dB 对应残差约 0.69%/7.79%/53.06%。原三次项在大信号区不单调。新软饱和保持接近原有的小信号三阶系数，且全区间单调，线性补偿移到它之后。回归检查补偿步进、残差不随补偿变化、传递曲线不反向。

该经验软饱和仍不是 THAT 芯片模型，也未做完整过采样参考对照；正常电平与极端驱动均需宿主听测。

修改后同一输出测试的残差均为约 0.69%，输出有效值分别 -3.19、8.81、20.81 dBFS，准确对应 12 dB 步进。浮点输出可超过 0 dBFS，VCA/FET 不是砖墙限幅器，需要在宿主控制最终电平。VCA 的补偿、比例、阈值等参数目前仍按块更新，连续自动化手感尚未专项验收。

## Opto：用户采纳后完成重构

以下旧测量用于说明重构依据；它们不代表当前实现：

- PR 50、输入 -18 dBFS：COMP 衰减约 3.02 dB，LIMIT 约 6.07 dB；在测试网格中，输入与 PR 增加会提高压缩量，两种模式有效区分。
- PR 60、输入 -6 dBFS：GAIN 40/60/80 的残差分别约 0.17%/0.12%/8.78%，压缩量约 12.51 dB 不变。明显变化来自输出级，是否保留应由声音方向决定；不能仅凭较大失真判断模拟器必然错误。
- 10 毫秒、100 毫秒、2 秒强音后的恢复均单调；强音结束一秒后残留衰减约 0.94、1.02、1.72 dB。已有持续时间依赖，不能称为毫无记忆效果。
- PR 0、GAIN 40、输入 -30 dBFS 的 20 Hz 小信号，48 kHz 输出 -33.15 dBFS，192 kHz 输出 -34.99 dBFS。固定 `0.9995` 直流隔离系数导致约 1.84 dB 差异，应修正为固定截止频率。
- `x * abs(x)` 是奇对称函数，当前注释所说的非对称电子管二次谐波没有由这一项实现。GAIN 无平滑也存在自动化突变风险。

已实施方向：保留反馈、简单 PR/GAIN 与 COMP/LIMIT 操作，建立可测的快恢复和持续时间依赖慢尾；修复采样率差异及参数平滑；移除未校准的输出染色，让 GAIN 独立补偿音量。第一版以平准连续、工作区可预测为目标，后续再决定是否加入独立染色与抗混叠方案。UA 对 LA-2A 的多阶段释放描述可作为方向，不能把手册时间直接等同于当前包络变量的百分比。[UA 资料](https://help.uaudio.com/hc/en-us/articles/215779663-A-History-of-the-Teletronix-LA-2A-Leveling-Amplifier)

实际实现使用独立的 1.5 毫秒功率检波器，检测上一采样的衰减后信号；反馈曲线仍区分 COMP/LIMIT。快状态的恢复常数为 85 毫秒，慢状态以 400 毫秒充入持续压缩量的一部分、以 1.5 秒恢复；总衰减取二者较大值。两个状态交接时数值连续，但导数可能变化，不能当作已测定的光敏电阻物理模型。PR/GAIN 低端映射连续，PR、GAIN、输出微调、混合、联动和模式等控制按 5 毫秒平滑；侧链高通频率本身仍按块更新，未声称所有自动化均已验收。直流隔离固定为约 3.8 Hz，位于反馈环路外、输出补偿前。

最新生产引擎测量结果：

- PR 0、GAIN 40、20 Hz 输入峰值 -30 dBFS：44.1/48/96/192 kHz 输出均约 -33.1643 dBFS，回归要求跨采样率差异小于 0.01 dB。
- PR 60、输入 -6 dBFS：GAIN 40/60/80 时，基波外残差均约 0.003%，衰减均约 12.2867 dB；输出有效值分别 -21.2968、-10.5936、+3.2927 dBFS。输出可超过 0 dBFS，GAIN 是补偿旋钮，不是限幅器。
- PR 50、输入 -18 dBFS：COMP 衰减约 2.8473 dB，LIMIT 约 5.7268 dB，模式仍有明确区别。
- 10 毫秒、100 毫秒、2 秒强音结束一秒后，衰减分别约 0.0439、0.5753、2.7866 dB；2 秒强音结束两秒后仍约 1.4307 dB。恢复慢尾明确依赖持续时间。
- 10 毫秒短音结束后，检波与控制响应仍可能使衰减短暂继续增加；图中可见早期延迟峰值。回归检查的是检波器排空后（30 毫秒以后）尾部单调，不把整个起始恢复段声称为严格单调。

新增自动回归涵盖上述低频一致性、输出补偿不改变检波和残差、长短音慢尾区别、静音八秒后接近零衰减、跨采样率恢复一致性以及 GAIN 跳变输入下的连续过渡。原始曲线和插值摘要保存在 `opto-rebuild-after`，绘图脚本为 `scripts/plot_opto_audit.py`。
