# SanMu Comp 压缩器 DSP 设计稿

> 本文档是 FET（1176）与 Opto（LA-2A）两种模式重写前的技术依据。
> 调研来源：Universal Audio 官方插件手册（1176 Classic、LA-2A Tube）、
> UREI 1176LN 原版维修手册、NIVIEM OPT4（电路级 LA-2A 仿真）技术文档、
> GroupDIY / Gearspace 电路分析帖。
> 写这份稿子的目的：先把硬件真实原理、旋钮职责、信号流彻底说清楚，确认无误后再动代码。

## 一、结论先行（三个最重要的纠正）

1. **1176 没有阈值旋钮，Input 同时是“输入电平”和“相对阈值”**。
   内部有一个固定阈值（由 Q-bias 和比率按钮偏置决定），Input 拧大 = 把更多信号推进阈值之上，
   既增大压缩量，也增大输入级失真。Output 是纯补偿增益，**不影响压缩量**。

2. **LA-2A 的 Gain 是输出补偿增益，不是输入增益；LA-2A 根本没有输入增益旋钮**。
   信号进入后先经过 T4 衰减器，再经过 Gain（输出放大器之前）。压缩量只由 Peak Reduction
   （侧链驱动）决定，Gain 只补电平、不参与压缩。

3. **两种机器都是“反馈式”压缩器**：侧链采样的是“压缩处理后的输出”，不是输入。
   压缩越深、检测电平越低，形成天然自限。这是它们与 VCA 前馈最本质的区别。

## 二、四种模式总览

| 模式 | 检测方式 | 增益元件 | 比率来源 | 时间常数 | 典型听感 |
|------|----------|----------|----------|----------|----------|
| Clean | 前馈 | 数字增益 | 用户阈值+比率+拐点 | 用户 Attack/Release | 透明、精确 |
| VCA | 前馈 | 数字增益 | 用户阈值+比率+拐点 | 用户 Attack/Release | 母线 glue、干净 |
| FET（1176） | 反馈 | FET 压控电阻分压 | 比率按钮（4/8/12/20/All） | 超快 Attack + 程序依赖释放 | 快、狠、带染色 |
| Opto（LA-2A） | 反馈 | T4 光电分压（CdS） | 由拓扑涌现（约 3:1） | 10ms 启动 + 双阶段释放 + 记忆 | 平滑、温暖、自然 |

## 三、FET 模式（对标 1176）

### 3.1 技术原理

- **FET 压控电阻（VCR）**：FET 和一个固定电阻组成分压器，FET 是分压器的下半臂。
  栅极电压越高 → 漏源电阻越小 → 分压衰减越大。电阻不会到零，所以最大衰减有上限
  （约 -30dB），压缩永远“关不死”。
- **反馈检测**：侧链采样压缩处理后的输出（位于前级之后、Output 音量电位器之前），
  所以 Output 不影响压缩量。压缩越深 → 检测电平越低 → 压缩自然回落，形成自限。
- **固定内部阈值 + 比率偏置**：阈值不是用户旋钮，由 Q-bias（内部微调）和比率按钮的
  二极管偏置共同决定。**比率按钮既设比率、也平移阈值**：更高比率对应更高阈值，
  信号要更响才触发限幅。
- **程序依赖释放**：分三部分——快速释放（瞬态之后）、慢速释放（持续高 RMS 之后）、
  过渡时间（信号“处于压缩中”多久才切换到慢释放）。这是 1176 弹跳感的核心来源。

### 3.2 信号流

```
输入 → 输入级(Input 驱动, 非线性) → FET 压控电阻分压(增益衰减) → 前级 → 输出级(Output 补偿) → 输出
                                            ↑                                    │
                                            │  反馈侧链(检测压缩后电平, 前级之后/Output之前) │
                                            └────────────────────────────────────┘
```

关键点：**检测点在前级之后、Output 之前**，所以 Output 只补电平、不改压缩量。

### 3.3 旋钮职责与操作逻辑

- **Input（驱动量）**：同时决定输入电平与相对阈值。顺时针 = 更响 + 更易压 + 输入级失真更大。
  面板刻度不是 dB 校准值；即使拧到 ∞，信号仍能通过并被压缩。
  - 想“更压缩、同一响度”：拧大 Input（更响+更压）→ 拧小 Output 补偿。
  - 想“更少压缩”：拧小 Input（更轻+更少压）→ 拧大 Output 补回电平。
- **Output（补偿增益）**：压缩后的 make-up，只补电平，不影响压缩量。加大 Output 也会引入输出级失真。
- **Attack（20μs–800μs）**：反向旋钮（顺时针 = 更快）。低比率下攻击更接近最快。
- **Release（50ms–1100ms）**：反向旋钮（顺时针 = 更快）。程序依赖：瞬态后快、持续重压后慢。
- **Ratio 按钮（4/8/12/20）**：设比率，同时平移阈值。20:1 用于峰值限幅。
- **All 按钮（British Mode）**：比率约 12:1–20:1，偏置点改变（攻击/释放也随之改变），
  因初始瞬态攻击滞后而产生激进失真，音色被“过载”染色。

### 3.4 Headroom（本产品的扩展设计，原机没有）

原 1176 没有 Headroom。它在本插件中的定位是**在不改 Input 旋钮的前提下，单独压低压缩量**：

- Input = 驱动量：决定输入电平、输入级染色、以及越过固定阈值的程度。
- Headroom = 抬升有效阈值（减少越阈值程度），让压缩量变小，**但不改变输入驱动带来的染色**。

于是有两种用法：

1. 不想动 Input，但觉得压缩太多 → 调大 Headroom 降低压缩量。
2. 想要更多染色但压缩量不够 → 直接拧大 Input；若因此压缩过头，再调大 Headroom 把压缩量降回来，
   真实目的是“只取染色、不取压缩”。

DSP 落点：Headroom 只作为“阈值偏移项”加进 FET 的阈值计算，不参与失真/驱动计算。

### 3.5 Input 的非线性分配

- Input 越靠右，FET 输入级越接近过载，2 次/3 次谐波越多（UA 手册明确“Increasing Input will increase distortion”）。
- 失真随驱动量平滑增长，而不是开关式出现；不同 Input 位置的谐波配比有细微差异。
- 实现建议：输入级用一个随驱动量加深的软饱和（偶数次谐波为主），
  FET 压控电阻本身在深衰减时也有轻微非线性；All 按钮额外放大失真。

### 3.6 DSP 实现要点（重写时逐条落实）

- 反馈：本样本先用“上一采样”算出的衰减增益，再根据输出电平更新下一采样的增益（1 采样延迟 = 反馈回路）。
- 检测点必须在 Output 补偿**之前**（排除 Output 对压缩的影响）。
- 阈值 = 固定基准 + 比率偏移（高比率更高阈值）+ Headroom 偏移。
- 程序依赖释放：快/慢/过渡三态，用“持续压缩时长”在快慢之间插值。
- 最大衰减约 -30dB（电阻不为 0）。
- 反向时间、All 按钮偏置与失真继续保留。

## 四、Opto 模式（对标 LA-2A）

### 4.1 技术原理

- **T4 光电单元**：EL 发光面板把侧链信号转成光；光照在 CdS 光敏电阻上，
  电阻随光变暗而下降（亮态约 680Ω、暗态约 1MΩ）。光敏电阻是分压器下半臂。
- **分压增益**：Gain = R_photo / (R_photo + R_fixed)。
  - Compress 模式 R_fixed ≈ 70.7kΩ（R6 68k + R7 2.7k）→ 约 3:1。
  - Limit 模式 R_fixed ≈ 68kΩ → 约 10:1+（UA 称近似 ∞:1，非线性且与频率相关）。
- **反馈检测**：Compress 模式侧链 100% 采样输出；Limit 模式 1/25 输入 + 24/25 输出混合。
- **无 Attack/Release 旋钮**：时间完全由 T4 光电池物理决定。
  - 启动约 10ms（程序依赖）。
  - 双阶段释放：前 50% 约 60ms，剩余 0.5–5 秒。
  - 记忆效应：CdS 电阻依赖光照历史，持续重压后释放更长（甚至几分钟才完全恢复）。
- **EL 起压阈值**：EL 面板需要约 100V 才起光，低于阈值不压缩 → 小信号原样通过。

### 4.2 信号流

```
输入 → 输入变压器 → T4 衰减器(增益衰减) → Gain(输出补偿) → 输出级 → 输出变压器 → 输出
                        ↑                          │
                        │  反馈侧链(Compress 100% 输出 / Limit 混合) │
                        └──────────────────────────┘
```

关键点：**Gain 在 T4 衰减之后、输出放大器之前，是纯输出补偿，不参与压缩**。
LA-2A 没有输入增益旋钮。

### 4.3 旋钮职责与操作逻辑

- **Peak Reduction（侧链驱动，0→-40dB 触发）**：这是压缩量控制，**不是传统阈值旋钮**。
  调大 = 更多信号驱动 T4 = 更亮 = 更多压缩，同时反馈回路会改变比率与音色。
  - 最小时：不压缩，但信号仍经过电路染色，可用 Gain 调电平。
- **Gain（输出补偿，最高 +40dB）**：压缩后补电平。**不影响压缩量**。
  - 用法：先定 Peak Reduction 的压缩量，再用 Gain 与 bypass 对齐电平。

### 4.4 DSP 实现要点（重写时逐条落实）

- 反馈：同上，用上一采样衰减增益，检测点取 T4 衰减之后、Gain 补偿之前。
- T4 分压：R_photo = R_dark · 10^(-k·light)，Gain = R_photo / (R_photo + R_fixed)，R_fixed 取 Compress ≈70.7kΩ。
- EL 阈值：低于起压点不发光 → 小信号完全不动。
- 双阶段释放：快包络（启动/前半释放约 60ms）+ 慢尾巴（0.5–5s）叠加，记忆效应让持续重压后尾巴更长。
- Peak Reduction 作为侧链驱动增益，调大既压得多、比率也随 T4 曲线略升。
- 最大衰减有上限（电阻不为 0，约 -36dB）。
- （可选，后续）PR=0 时仍保留极轻的电子管/变压器染色，使“关掉压缩也有质感”。

## 五、VCA / Clean 模式（保持现状）

- 前馈检测：侧链采样输入，阈值/比率/拐点 + 一阶平滑，标准 VCA 模型。
- Clean 多一个 Knee 拐点参数；VCA 偏母线 glue。
- 这两种模式不需要改动。

## 六、需要修正的既有错误（上一版代码的问题）

1. FET 的检测把 Output 补偿算进了侧链（`rawL * fetGain * makeup`）→ **错误**，
  会让 Output 影响压缩量。应改为检测压缩后、补偿前的信号。
2. Headroom 被误用成“失真阈值缩放”，而正确语义是“压缩阈值偏移”。
3. FET 的比率按钮没有平移阈值（真实 1176 高比率对应更高阈值）。
4. LA-2A 的 Gain 我确实实现成了输出补偿（这部分方向正确），但需要明确它“不是输入增益”。
5. 上版没有在 PR=0 时保留电路染色（属于可选增强，不影响正确性）。

## 附录 A：实测参数与来源（回答“具体是多少、哪来的”）

### A.1 LA-2A 的 Gain 为什么是“输出补偿增益”

来源（多处独立印证）：

- Universal Audio 官方《LA-2A Tube Compressor Manual》原文：
  “The Gain knob increases the output level by up to 40 dB to compensate for the reduced
  level that results from compression… **The Gain control does not affect the amount of compression.**”
  （Gain 旋钮最多提升 40dB 输出电平，用于补偿压缩带来的电平下降，且不影响压缩量。）
- UA 官方《LA-2A Manual》信号流原文：“After the gain reduction circuit, the signal is sent
  through an **Output Gain control** and a two-stage output amplifier, followed by the output transformer.”
  （信号经增益衰减电路后，再经“输出增益控制”和两级输出放大器。）
- Gearspace 电路分析帖原文：“Gain is input gain to the **output amplifier, after the gain
  reduction and side chain amp. There is no input gain control on an LA2A.**”
  （Gain 是输出放大器的输入增益，位于增益衰减和侧链之后；LA-2A 没有输入增益旋钮。）

结论：**Gain = 输出补偿（makeup），不是输入增益；压缩量只由 Peak Reduction 决定。**

### A.2 LA-2A 失真参数（原厂规格）

- 失真：+10 dBm 输出时 THD < 0.35%，+16 dBm 输出时 THD < 0.75%（原厂手册）；
  早期 UA 目录另标“+10 dBm 输出时 <0.5%（典型 <0.25%）”。
- 谐波以 2 次、3 次为主；放大管为 12AX7A（输入）与 12BH7A（输出）。
- 含义：正常电平下几乎透明（<0.35%），失真只在高电平/输出补偿推高时温和出现。

### A.3 1176 的内部阈值是多少

- 1176 没有用户阈值旋钮，阈值由内部 Q-bias（R59）在出厂时标定，且依赖 FET（Q1）个体特性。
  因此**没有官方发布的单一 dB 值**，不同版本/单台会有轻微差异（这一点与“每个厂家设计略有不同”一致）。
- 有文献实测过其等效阈值（数字域，dBFS，作为参考量级）：
  - 4:1 ≈ **-17.5 dBFS**
  - 8:1 ≈ **-18.7 dBFS**
  - 12:1 ≈ **-19.2 dBFS**
  - 20:1 ≈ 约 -20 dBFS（更高比率阈值略低、更敏感）
  - 来源：Rochester ECE《Analog Compressor Modeling》论文（“1176 无可变阈值，实际阈值需实测”）、
    GroupDIY 的 1176 比率实测帖。
- 工程落点：默认内部阈值可取 **-18 dBFS 附近**，并让比率按钮做 ±1~2 dB 的轻微偏移。

### A.4 1176 的 Input / Output 默认值与总增益

- 整机增益约 **45 dB**（Input + Output 全开时，GroupDIY 实测）。
- 面板常用起点：**Ratio 4:1、Input 与 Output 均置于 12 点（面板刻度“24”）、
  Attack 12 点、Release 顺时针打满（最快）**（Gearspace 混音师实测起点）。
- “24”是面板任意刻度，不是 dB 校准值；Output 最高可提供约 45 dB 补偿（UAD 手册）。

### A.5 1176 的非线性染色：起量点、介入方式、削波保护

- **起量点**：正常电平下几乎无失真。实测（UAD 1176LN，1kHz）：
  - 最快 Attack/Release、0 dBFS 输入时 3 次谐波约 **0.177%**；
  - 全量增益衰减、+36 dBFS 输入时 3 次谐波约 **0.005%**（此档反而极低，因为压缩把电平压下去了）。
  - 即：失真主要在“Input 推高 + All 按钮”等极端驱动时出现，日常 3–6dB 压缩基本听不出。
- **介入方式**：FET 的 JFET 非线性传递函数产生 **2 次、3 次谐波**，随驱动**平滑、渐进**地加入，
  不是开关式突现（UA 手册：“Increasing Input will increase distortion”）。
- **饱和失真保护（关键）**：UAD 的 1176 与 LA-2A 插件都有“clip avoidance（削波避免）”——
  失真随输入增加到某个点后**止步于方形波之前**，即软饱和、有上限，而不是硬削波。
  - 工程含义：本插件的染色阶段必须用**有天花板的软饱和曲线**（tanh 类或多项式软拐），
    目标 THD 在正常电平 <0.2%、极端驱动才上升到可闻但始终不硬削。
  - 定位是“压缩器带一点染色”，不是饱和器，不能把信号推成方波。

### A.6 这些数值的可信度与边界

- LA-2A 的 Gain 职责、THD 规格、1176 总增益/输出 45dB：来自官方手册，**确定性高**。
- 1176 阈值 dBFS 与 THD 百分比：来自学术论文 / 论坛实测，**量级可信、具体值有 ±容差**，
  且随硬件版本（Rev A–H、LN、Reissue）变化。
- 本插件是“对 1176/LA-2A 声音特性的工程还原”，不追求逐版本 1:1 克隆；
  采用上述量级作为参数锚点，最终以 REAPER 实机听感为准。

## 附录 B：两处核心架构纠正（第二次纠正）

### B.1 1176 的 Input / Output 是“一对衰减器”，不是“驱动 + 0dB 补偿”

之前把 FET 的 Input 当成“驱动增益”、Output 当成“-24~+24dB 且 0dB=unity”的补偿，是错的。
真实 1176：

- 整机约 45dB 固定放大级，Input 与 Output 都是信号通路中的**衰减器**。
- **Input 在 FET 之前**衰减信号，FET 的固定阈值锚定在“Input 衰减之后的电平”上，
  所以 Input 直接决定信号离阈值多远（拧大 = 更靠近/超过阈值 = 更压缩 + 更响）。
- **Output 在放大级之后**衰减，用于把电平拉回。
- **Unity（净增益≈0）出现在 Input/Output 均置于 12 点（面板刻度“24”）时**，
  而不是“Output=0dB”。所以“Output 0dB”在真实手感里是补偿过头、会爆。

工程结论：

- Input 与 Output 是**成对校准**的，默认值（noon）共同锚定一个 unity 工作点。
- 阈值 = 固定基准，锚定在 Input 衰减之后的信号电平上；改 Input 就改“越阈程度”。
- Output 的刻度与默认位置要重新设计，使“默认 Input + 默认 Output ≈ unity”，
  而不是把 0dB 当 unity。

### B.2 LA-2A 的 Gain 会直接牵动压缩量（反馈环内，这是光学压缩的本质）

LA-2A 是**反馈式**光学压缩器，侧链采样的是**输出信号**（Compress 模式 100% 输出）。
“输出”指的是经过增益衰减 + 补偿增益之后的最终输出，因此 **Gain 在反馈环内**。

反馈环（按物理量写）：

```
输出 O = 输入 I × 衰减 A(T4) × 增益 G(Gain)
侧链驱动 D = O × PeakReduction        （采样输出）
EL 光强 L ∝ D                          （驱动越大光越亮）
衰减 A ∝ 1/L                           （光越亮 CdS 电阻越小 → 衰减越大）
```

于是：**G ↑ → O ↑ → D ↑ → L ↑ → A ↓ → 压缩量 ↑**。
同时输出不会按 G 等比例升高，因为增大的衰减会抵消一部分电平——这正是“更响 + 更压”的手感。

- 为什么“make-up gain”这个词会误导：它来自**前馈**压缩器（VCA）——前馈检测器看输入，
  输出补偿在环外，确实不改压缩量。
- **反馈**压缩器（LA-2A/多数光学与 vari-mu）检测器看输出，补偿增益就在环内，
  所以 Gain 必然牵动压缩量。这是反馈与前馈最本质的区别。

工程结论：

- Opto 侧链采样**最终输出（含 Gain）**，让 Gain 进反馈环，还原用户听到的耦合。
- “Gain 不影响压缩”只适用于前馈拓扑，不适用于我们要做的反馈式光学压缩。

### B.3 对实现的影响（重写时一起改）

1. FET：Input/Output 均为**衰减器**，刻度 0（全通）→ ∞（全衰减），标记 6/12/18/24/30/36/48/∞，
   默认 noon=“24”（-24dB）成对校准；阈值锚定在 Input 衰减后的电平。
2. Opto：**反馈式**——侧链采样最终输出（含 Gain），Gain 进反馈环，直接牵动压缩量。
3. 统一心智模型：VCA/Clean 是前馈（补偿在环外）；FET/Opto 是反馈（电平/增益在环内、
   牵动压缩），这是二者手感与音色的根本差异。

### B.4 Input/Output 刻度与默认值（结合 CLA-76 / UA 参考）

- 两种主流刻度本质相同，都是**衰减刻度**：
  - CLA-76（Waves）：-Inf → 0，具体值一路到 -59.9 再跳到 -Inf。
  - UA：∞、48、36、30、24、18、12、6、0（0=全通，∞=全衰减）。
- 12 点（noon）落在“24”刻度 = -24dB 衰减。
- 默认值：**Input = 24、Output = 24**；整机约 45dB 固定增益 - 24（Input）- 24（Output）≈ unity。
- UI 建议：Input/Output 不显示具体 dB 数值，只显示 ∞/48/36/…/0 刻度（学 UA 保留模拟手感）。

## 附录 C：光学压缩与 1176 的跨厂家对比（用于确定“共性”与“我们的风格”）

### C.1 光学压缩（LA-2A 类）：启动/释放/压缩比的共性

原机 LA-2A 没有 Attack/Release/Ratio 旋钮，时间与比率完全由 T4 光电池物理决定。
各家“忠于原机”的复刻（UA LA-2A、Warm WA-2A、Waves CLA-2A 等）都继承以下**共性**：

| 项目 | 共性数值 | 说明 |
|------|----------|------|
| 启动 Attack | 约 10ms，程序依赖 | 固定、不可调；随输入电平/光照有轻微变化 |
| 释放 Release | 双阶段：约 60ms 恢复前 50%，剩余 0.5~5s | 慢尾巴程序依赖 + 记忆效应 |
| 压缩比 Ratio | 约 3:1（Compress）/ 10:1+（Limit），**随电平增大而升高** | 不是固定值，由 T4 光照决定 |
| 记忆效应 | CdS 依赖光照历史 | 持续重压后释放更长 |
| EL 起压阈值 | 有（约 100V） | 小信号不动 |

各家在“不可调”这件事上的差异（这就是“风格”来源）：

- **UAD LA-2A**：启动偏快、释放偏慢，压瞬态更明显。
- **Waves CLA-2A**：启动偏慢，更保留瞬态/子音清晰度；释放前快后慢“不劈”。
- **Warm WA-2A**：照原机 10ms / 60ms+0.5~5s，最中性。
- **NIVIEM OPT4**：给 T4 加了 Modern/Vintage 两档响应 + Attack/Release 特性塑形，
  本质是把“原机固定曲线”拆成可选曲线。

结论：光学压缩的**骨架是固定的**（10ms 启动 + 双阶段释放 + 电平依赖比率 + 记忆），
差异只在曲线的**细微倾斜**。我们的 Opto 先按中性骨架实现，留出“响应曲线”供后续试听调成自己的风格。

### C.2 1176：为什么各版本/各家的 Input/Output 默认位置不一样

1176 有 A、A/B、B、C、D、E、F、G、H 多个硬件版本，增益结构与阈值各不相同：

| 版本 | 输入结构 | 输出结构 | 增益/阈值差异 |
|------|----------|----------|----------------|
| Rev A（Bluestripe） | 600Ω 输入变压器 + T-pad 衰减 | UA-5002 输出变压器 | 原始版 |
| Rev C/D/E（Blackface，LN） | 同上（LN 低噪） | Rev E 换 B11148（+12dB） | 约 45dB 系统增益，最受推崇 |
| Rev F | 同上 | Class AB 输出级 | 输出级不同 |
| Rev G/H（Silverface） | 去输入变压器，差分运放输入 | — | 输入级不同 |

实测差异（论坛/对比帖）：

- Bluestripe 比 Blackface **阈值约低 5dB**，同样 Input 位置压缩量不同。
- Waves CLA-76 与 UAD 1176 的 Input/Output **刻度校准不同**：
  达到同样 GR 与输出电平，CLA-76 的 Input ≈ -21.8，UAD 1176 的 Input ≈ -13、Output ≈ -14。
- 所以 UA 各款 1176 从 DAW 加载后默认 Input/Output 不同，是因为它们**各自建模了不同硬件版本的增益结构**。

结论：Input/Output 默认位置由“该版本的增益结构 + 阈值锚点”决定，不是一个通用值。

### C.3 我们产品的落点（单一 FET 模式，不是多版本）

共性骨架：

1. Input = 输入衰减器（降低进入 FET 的电平）。
2. Output = 输出电平控制。
3. 固定内部阈值（Q-bias），数字域参考约 -18dBFS。
4. 系统增益参考 Rev C~E 的约 45dB。
5. 默认 Input/Output 均置 noon（“24”刻度）→ 约 unity。

因为只做一个 FET 模式，不追求逐版本 1:1，用 Rev C~E 作为增益结构基准，
再把 Input/Output 做成衰减刻度、默认 noon 成对校准即可；阈值锚定在 Input 衰减后的电平。

### C.4 1176 默认 Input/Output 位置（UA 1176LN 黑脸实测）

- 用户实测：UA 1176LN 黑脸从 DAW 加载后 **Input = 24、Output = 18**（不是 24/24）。
- 原因：黑脸（Rev E）输出变压器（B11148）比早期版本高约 12dB，输出需要放低一点
  才能回到相同的 unity 工作点。
- 我们的单一 FET 模式默认值就取 **Input=24、Output=18**，与用户参考的 1176LN 黑脸一致。

### C.5 1176 Attack / Release 的 1–7 反向刻度（内部时间必须写明）

1176 的 Attack/Release 是连续电位器，面板印 1–7，**7 最快、1 最慢**（反向）。
范围：

- Attack：20μs（7）↔ 800μs（1）
- Release：50ms（7）↔ 1100ms（1）

内部按对数刻度定义（7 个刻度的参考时间，单位见列）：

| 刻度 | Attack | Release |
|------|--------|---------|
| 1（最慢） | 800μs | 1100ms |
| 2 | 433μs | 657ms |
| 3 | 234μs | 393ms |
| 4（12 点） | 126μs | 235ms |
| 5 | 68μs | 140ms |
| 6 | 37μs | 84ms |
| 7（最快） | 20μs | 50ms |

注：硬件未发布逐档毫秒表，上表是**对数刻度的工程参考值**，连续旋钮在两端之间平滑变化；
1176AE 另有 10ms“SLO”慢启动档（可作后续扩展，不放进首版）。

### C.6 Opto 的“响应风格”实现策略

共性骨架固定（10ms 启动 + 双阶段释放 + 电平依赖比率 + 记忆 + EL 阈值 + 反馈 Gain）。
各家风格差异只来自“启动/释放曲线的细微倾斜”：

- UAD：启动偏快、释放偏慢（压瞬态明显）。
- Waves：启动偏慢、释放前快后慢（保瞬态/子音）。
- Warm/中性：照原机 10ms / 60ms+0.5~5s。

实现策略：

1. 先按中性骨架实现，把“启动时间、双阶段释放的快/慢比例、比率随电平的斜率”做成内部可调常量。
2. 不设硬性的 UAD/Waves 二选一，而是留一个“响应特性”参数（或内部常量），
   在 REAPER 试听中由用户反馈调成我们自己的风格。

### C.7 Headroom（HR）的真相：是 UAD 插件独有特性，不是原机

- 原机 1176 没有 Headroom；1176LN/SE Legacy、Waves CLA-76 也没有。
- **HR 是 UAD 1176 Classic Limiter Collection（Rev A / Rev E / AE）才有的插件独有控制**。
- 官方定义：HR 调整“内部工作参考电平”，让插件**不会那么容易被推进压缩**；
  也用于“最佳操作电平匹配”，或创造性地扩展处理器的动态/饱和范围。
- HR 档位：**4 / 8 / 12 / 16 / 20 / 24 / 28 dB**。
- 方向：**HR 越低 → 电路被驱动得越狠 → 更饱和**；HR 越高 → 越不容易压缩。

结论：我们已有 Headroom（范围 4~28dB、默认 16）与 UAD HR 完全同源、同语义，
  正好印证用户早先“不想动 Input 又要减压缩量就调 Headroom”的理解是对的。
  实现时 Headroom 应作为“内部参考电平偏移”加进阈值，不改 Input 驱动。

### C.8 各版本/各家 1176 默认 Input/Output 对比

| 型号 | Input 默认 | Output 默认 | 说明 |
|------|-----------|------------|------|
| UA 1176LN 黑脸 | 24 | 18 | ~45dB 系统增益，最受推崇的 LN 时代 |
| Waves CLA-76（黑脸） | 30 | 18 | Waves 自家校准的黑脸模型 |
| UA 1176 Rev A（蓝条） | 48 | 14 | 早期原始版，增益结构不同、失真更高 |

规律：**默认 Input/Output 编码了该硬件版本的增益结构与阈值锚点**。
  - 输入级增益低/阈值高的版本（蓝条）需要更高 Input（更少衰减）驱动；
  - 输出级增益高的版本需要更低 Output 位置维持 unity。
  - 不同厂家对同一“黑脸”的校准也不同（UA 24 vs Waves 30），所以默认值不是通用常数。

我们的单一 FET 模式取 UA 1176LN 黑脸为基准：**Input=24、Output=18**。

## 附录 D：四种拓扑的本质区别与我们的设计定位（更高视角）

压缩器的“音色性格”来自三个可区分的维度，而不是旋钮多少：

| 维度 | Clean（纯数字） | VCA | FET（1176） | Opto（LA-2A） |
|------|----------------|-----|-------------|----------------|
| 检测 | 前馈 | 前馈 | **反馈** | **反馈** |
| 时间常数 | 固定、用户全控 | 固定、用户全控 | 程序依赖释放 | 程序依赖 + 记忆效应 |
| 增益元件 | 线性数字增益 | VCA（可放大可衰减） | FET 压控电阻（只衰减、非线性） | 光电 CdS（只衰减） |
| 比率 | 用户设定 | 用户设定 | 按钮固定档 | 电平涌现（约 3:1→更高） |
| 染色 | 无（透明） | 少（干净） | 强（FET 谐波 grit） | 温（管染色） |
| 擅长的活 | 手术式精确、透明 | 抓峰值、母线 glue、低频控制 | 打击乐 punch、加攻击性 | 人声/贝斯整平、自然顺滑 |

一句话定位：

- **Clean**：完全透明、可精确到拐点/前瞻，做“看不见的压缩”。
- **VCA**：抓得快、放得准、干净，做峰值控制与总线 glue——工作马。
- **FET**：最快攻击、反馈式、带 grit，做 punch 与攻击性、给声音“冲劲”。
- **Opto**：慢启动、双阶段释放、带记忆，做顺滑整平与“音乐性”。

设计铁律（避免重蹈“换名字”覆辙）：

1. 每种模式必须有自己的**检测拓扑**（前馈 vs 反馈），不能共用一套检测。
2. 每种模式必须有自己的**时间常数行为**（固定 vs 程序依赖 vs 程序依赖+记忆）。
3. 每种模式必须有自己的**增益元件特性**（能否放大、是否非线性、染色方向）。
4. 比率来源必须不同（用户设 / 按钮档 / 电平涌现）。

这四点就是四种模式“本质区别”的实现锚点，也是我们区别于“只换名字”的工程标准。
