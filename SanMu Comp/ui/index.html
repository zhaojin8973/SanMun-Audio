Help manual

Controls and shortcuts
Knobs and values
Drag vertically or scroll to adjust. Double-click or Command/Ctrl-click to reset.
Keyboard
Arrow keys adjust a focused knob. Home / End reach its limits. Enter edits or confirms a value; Escape cancels.
FET scales
FET timing uses 1–7: clockwise is faster. INPUT and OUTPUT retain the attenuation scale.
A/B and bypass
A/B keeps two sound settings. Copy transfers the current set to the other slot. BYP bypasses compression.
Reading the graph
IN is input, OUT is output, and GR is gain reduction. The graph shows the last 2 seconds. GR 6/12/24 dB changes only its vertical scale.
IN / OUT
IN/OUT ×2 doubles the visual level difference, using a shared 0 to −30 dBFS range.
Display and peaks
Curves use light visual smoothing; meters and hover values show raw readings. Freezing the graph leaves audio and meters running. Clear peaks resets held peaks and clip indicators.
Target analysis
When ready, settings are applied automatically if you have not adjusted them during analysis.
